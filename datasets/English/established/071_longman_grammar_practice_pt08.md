## Grammar points

### 8.1 Prepositions, adverb particles and conjunctions

**8.1A Words usable as either preposition or adverb particle.** A large set of "small words" function
as prepositions (requiring a noun/pronoun object, grammatically bound to a noun) or as adverb
particles (no object, grammatically bound to the verb) depending on whether an object follows, p.106.

**8.1B Words restricted to one function only.** A separate, smaller set of words functions *only* as
a preposition (always requires an object) and another set functions *only* as an adverb particle
(never takes an object) — see the Vocabulary table, p.106.

**8.1C Words usable as either preposition or conjunction.** A small set (after, as, before, since,
till/until) takes a noun/pronoun object as a preposition, or a full clause as a conjunction, p.107.

**8.1D Object pronouns after prepositions.** The object form of a pronoun (not the subject form) is
required after any preposition, including in compound subjects ("Between you and me," not "*between
you and I*"), p.107.

### 8.2 Prepositions of movement and position; prepositions of time

**8.2A At a point, in an area, on a surface.** *To/from* show direction of movement; *into/out of*
show movement with entry/exit; once movement is complete, *at/in/on* show static position — *at* for
a meeting point or (with certain nouns) "inside"; *in* for enclosure; *on* for a surface. Specific
noun-classes consistently combine with *at* (public places/buildings, addresses, zero-article
institution nouns, events) or with *in* (large geographic areas, towns, outside areas, rooms,
zero-article institution nouns in a different subset), p.108.

**8.2B Prepositions of time.** *At* marks exact clock time, meal times, point-events, festivals, and
age; *on* marks days of the week, specific dates, particular occasions, and anniversaries; *in* marks
parts of the day, months, years, seasons, centuries, and open-ended periods, p.109.

### 8.3–8.5 Particular prepositions and particles: contrasts

These three sections work through specific, commonly-confused preposition/particle pairs or small
sets, each with its own idiosyncratic distinguishing rule that must be learned individually rather
than derived from a general principle:

- **8.3 (contrasts 1), p.110:** about/on; according to/by; across/over; across/through; after/
  afterwards; around/about; at/to/against; away (+far/from); because/because of; before/in front of;
  behind, at the back (of)/back.
- **8.4 (contrasts 2), p.112:** beside/besides; between/among; but (for)/except (for); by/near/on;
  by/past; by/with/without; down/up/under/over; due to/owing to; like/as (including the explicit note
  that using *like* to introduce a clause, especially in American English, is considered incorrect
  by "a lot of native speakers" even though common in practice).
- **8.5 (contrasts 3), p.114:** of/out of/from/with (after "made"); of/off; on/in (referring to the
  body); out of/outside; over/above/on top of; under/underneath/below; with/without; with/without/
  in/of (for describing physical appearance, voice, age, wealth, or character).

### 8.6 Phrasal verbs: Type 1, verb + preposition (transitive)

**8.6A The four-type phrasal-verb taxonomy.** The source defines four structural types of
verb+preposition/particle combination, which recur through the rest of the chapter: Type 1 = verb +
preposition, transitive, inseparable (*listen to*); Type 2 = verb + particle, transitive, separable
(*take off*); Type 3 = verb + particle, intransitive (*sit down*); Type 4 = verb + particle +
preposition, transitive (*run out of*), p.116.

**8.6B–C Type 1, non-idiomatic.** Type 1 verbs used in their literal/normal sense, each fixed to a
specific preposition by convention (e.g. *agree with*, *suffer from*) — both as simple verb+preposition
and as verb+object+preposition+object patterns, p.116.

**8.6D Type 1, idiomatic.** A closed set of Type 1 phrasal verbs whose combined meaning cannot be
derived from the literal senses of verb + preposition — see the Vocabulary table, p.117.

### 8.7 Phrasal verbs: Type 2, verb + particle (transitive)

**8.7A Type 1 vs. Type 2 separability.** The core structural distinction between the two transitive
types: a Type 1 preposition can never be separated from its verb ("*looking the camera at*" is
ungrammatical), while a Type 2 particle is "mobile" — it can go either before or after a noun object,
but must follow a pronoun object (give it away, never "*give away it*"), p.118.

**8.7B Particles that systematically extend a verb's meaning.** Beyond pure idiom, a single particle
(out, away, up, down, in...) can add a fairly systematic semantic nuance to an otherwise literal verb
— distance, detachment, disappearance, "tidying away," entry, exit, completion, reduction, and
several others — functioning almost like a derivational morpheme across many different verb stems,
p.118.

**8.7C Type 2, idiomatic.** A closed set of Type 2 phrasal verbs whose combined meaning is
non-compositional — see the Vocabulary table, p.119.

### 8.8 Phrasal verbs: Type 3 (intransitive) and Type 4 (verb + particle + preposition)

**8.8A Type 3, non-idiomatic.** Intransitive particle verbs used in their plain, literal sense
(*hurry up, sit down, stand up*) — contrasted explicitly with Type 1, which cannot drop its
preposition ("*Look!*" is fine as Type 3-style intransitive use, but not as a Type-1-style "*Look
at!*"), p.120.

**8.8B Type 3, idiomatic.** A closed set of intransitive phrasal verbs whose meaning cannot be
derived from their parts — see the Vocabulary table, p.120.

**8.8C Type 4, non-idiomatic.** The three-element verb + particle + preposition pattern used in its
literal sense (*walk up to the top*), p.120.

**8.8D Type 4, idiomatic.** A closed set of Type 4 phrasal verbs whose combined meaning is
non-compositional — see the Vocabulary table, p.121.
