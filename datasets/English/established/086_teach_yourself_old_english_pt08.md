## Grammar points

### The seven classes of Old English strong verbs, consolidated

A single reference table gives the model principal-parts set (present / past singular / past plural
/ past participle) for a representative verb of each of the seven strong-verb classes, the
systematic framework dictionaries use to classify any OE strong verb: Class I *drifan* "drive"
(drifð, draf, drifon, gedrifen); Class II *ceosan* "choose" (cyst, ceas, curon, gecoren); Class III
*singan* "sing" (singð, sang, sungon, gesungen — already met in full in `pt03`); Class IV *cuman*
"come" (cymð, com, comon, gecumen — already met in full in `pt05`); Class V *gifan* "give" (gifð,
geaf, geafon, gegifen); Class VI *swerian* "swear" (swereð, swor, sworon, gesworen); Class VII
*cnawan* "know" (cnæwð, cneow, cneowon, gecnawen). The book pairs each class with a Modern English
descendant showing the same historical ablaut-vowel pattern still partly visible today (drive/drove/
driven, choose/chose/chosen, sing/sang/sung, come/came/come, give/gave/given, swear/swore/sworn,
know/knew/known) — concrete evidence that Modern English's "irregular" strong verbs are the direct,
if eroded, continuation of this fully systematic Old English seven-class system, not a random
assortment of exceptions. Class VII is noted as historically reduplicating in origin, distinguishing
it structurally from the vowel-gradation (ablaut) mechanism driving Classes I–VI. p.280.

### A consolidated place-name gazetteer (Appendix II map)

A labeled map of southern Britain in Old English names functions as a capstone cross-reference for
the place-name-element material taught piecemeal across the book (`pt01`'s -ceaster/-burh/-tun,
`pt03`'s -ley/-ford/sheep-compounds, `pt04`'s -mere/landscape terms): major towns (*Eoforwic* York,
*Ceaster* Chester, *Wigoraceaster* Worcester, *Hrofesceaster* Rochester, *Cantwaraburh* Canterbury,
*Glæstingaburh* Glastonbury, *Lundene* London, *Oxenaford* Oxford, *Exanceaster* Exeter,
*Cingestun* Kingston, *Ceapstow* Chepstow, *Abbandun* Abingdon, *Cruland* Crowland, *Ramesige*
Ramsey, *Hæglesac* Hastings, *Corfesgeat* Corfe); named sites from the book's own study texts
(*Cwichelmeshlæw* Cwichelm's Barrow); and the major named peoples/regions (*Norðhymbre*
Northumbria, *Mierce* Mercia, *Eastengle* East Anglia, *West-Seaxe* Wessex, *Cent* Kent, *Wealas*
the Welsh, *West-Wealas* the West Welsh/Cornish, *Wiht* Isle of Wight) — visually tying together the
ethnonym-based national-naming pattern taught in `pt01`'s grammar points with the concrete
geography those ethnonyms actually cover. p.281.
