## Grammar points

### Idiomatic-preposition error list (Ch.6)

The source gives a ~15-item chart of incorrect-preposition errors paired with their correct forms
(captured individually in the Vocabulary table above). This is framed as a common-*error* list rather
than a plain collocation glossary (contrast with `064_complete_idiots_guide_grammar_pt01.md`'s ~30-item
*correct*-collocation list, which overlaps on only a few items — e.g. *similar to*, *interested in* —
and is otherwise non-overlapping), so it is kept in full as a genuinely distinct resource for
error-pattern modeling (p.81–82).

### Commonly-misspelled-word sets, by error mechanism (Ch.6)

The source groups frequent English misspellings by the phonological mechanism that causes them, each
with the resulting misspelling given alongside the correct form: **missing letters/syllables** (a
sound gets dropped in speech, e.g. *accidentally* → "accidently," *asked* → "ast"/"axed," *broccoli*
→ "brocoli"); **extra letters** (an unneeded vowel gets inserted in speech, e.g. *athlete* →
"athalete," *lightning* → "lightening," *mischievous* → "mischievious"); and **transposed letters**
(mispronunciation scrambles letter order, e.g. in *aesthetic, bureaucrat, entrepreneur, lingerie,
rhythm*). None of these specific word-sets were found duplicated elsewhere in this project's English
`established/` files as of this extraction (checked directly against CMOS's own spelling-error
glossary, which does not include this list) (pp.83–85).

**Skipped as redundant:** the chapter's confusable-word-pairs list (*air/err, altar/alter, ascent/
assent, capital/Capitol,* etc.) — spot-checked and confirmed already present in CMOS's confusable-word
glossary (`010_cmos_ch05_grammar_and_usage_pt10.md`). The chapter's Latin/Greek-plural table
(*alumnus/alumni, criterion/criteria,* etc.) is likewise already captured via CMOS and Oxford spelling
chapters.

### Semantic classification of conjunctions (Ch.7, Ch.9)

The book twice tabulates **which logical relationship each subordinating conjunction expresses** —
condition (*unless, if, provided that*), reason (*because, as*), choice (*rather than, whether*),
contrast (*though, although, even though*), location (*where, wherever*), result/effect (*so that, in
order that*), and time (*while, once, when, after, before, until*) — and separately tabulates each
**coordinating conjunction's** own meaning/function: *and* = addition (to link ideas), *but*/*yet* =
contrast (however), *for* = cause (as a result), *nor* = reinforced negative, *or* = choice
(possibility), *so* = result (therefore). This functional mapping of conjunction → semantic
relationship is a compact, independently useful classification not found tabulated this explicitly
elsewhere in the corpus, and is directly relevant to this project's interest in how a conlang's own
closed-class connective inventory might map onto the same relationship space (pp.106–107, 132, 135).

### Elements of style and style-descriptor vocabulary (Ch.12)

The book defines a writer's **style** as a set of choices across eleven dimensions: description,
dialogue, figures of speech, parallel structure, punctuation, purpose, sentence length, sentence
structure, tone, topic, voice, and word choice (ranging from slang/vernacular/everyday speech to
elevated diction). It then gives a flat list of twenty adjectives used to characterize an overall
style (captured in the Vocabulary table above: *formal, informal, stiff, grand, allusive, elevated,
academic, relaxed, heroic, ironic, colloquial, breezy, familiar, rich, serious, technical, sensory,
abstract, plain, ornate*). This register-descriptor vocabulary is not reproduced in `064`'s summary
of the same author's other book and is worth retaining as its own small controlled vocabulary for
describing a text's register along axes other than the formal↔informal spectrum alone (p.186).

### Four purposes of writing (Ch.12)

A four-way taxonomy of **why** a document is written, each with its own genre examples: **exposition**
(to explain/show/tell — manuals, recipes, business letters, reports, textbooks, news stories, press
releases); **persuasion** (to convince — critical reviews, resumes, cover letters, job evaluations,
letters of recommendation/complaint, editorials, speeches); **description** (to describe — poems,
journals); and **narration** (to tell a story — autobiographies, biographies, anecdotes, oral
histories, short stories, novels). A document can serve more than one purpose, but one usually
dominates (e.g. a complaint letter describes and explains but is fundamentally persuasive). This is
framed differently, with different genre examples, from `064_complete_idiots_guide_grammar_pt02.md`'s
own four-modes-of-discourse model (exposition/narration/argumentation/description) by the same
author — worth cross-referencing rather than treating as a duplicate, since the genre-example lists
only partly overlap (p.188–189).

### Audience analysis via the "Big Three" (Ch.9, Ch.12)

A simpler, recurring three-factor checklist the book applies whenever choosing how to coordinate
ideas or pitch a document's style: **audience** (readers and their expectations), **purpose** (why
you are writing), and **style** (personal choices in diction and sentence structure). This is a
coarser frame than `064`'s own four-way primary/secondary/gatekeeper/watchdog audience model from the
same author's other book — likely a simplified, earlier-chapter-appropriate version of the same
underlying idea rather than independent content (p.133, 187).

### Two independent register illustrations not quoted in `064` (Ch.13)

The book quotes two primary-source passages to illustrate register points that `064_complete_idiots_
guide_grammar_pt02.md`'s own diction-spectrum coverage states only abstractly:
- **Elevated diction**: an excerpt from Jonathan Edwards' sermon "Sinners in the Hands of an Angry
  God" (early 18th century), chosen to show abstract vocabulary, a serious tone, and sustained
  figurative language (a bow-and-arrow metaphor for God's wrath; a spider simile for human
  insignificance) — illustrating the same "elevated diction" tier `064` defines only by genre
  (legal documents, deeds, wills) without a worked literary example (p.198–199).
- **Vernacular/dialect**: a different Mark Twain excerpt than the one quoted in `064` — this one from
  *Life on the Mississippi* ("Say, Jim, I'm a-goin' home for a few days... I hain't b'en there for a
  right smart while") rather than `064`'s "Jumping Frog" passage — a second, independent attestation
  of Twain's use of eye-dialect spelling and dropped-g/h contractions to signal regional vernacular in
  print (p.200).

Both are kept as additional corroborating evidence for register points already established via `064`,
consistent with this project's standing rule that an independently-chosen illustration of an
already-captured point is worth a brief note even when the underlying grammar point is not new.
