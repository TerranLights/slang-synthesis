## Grammar points

### Latin/Greek-derived irregular plurals (pp. 163–168)

Several English nouns borrowed from Latin or Greek keep their source language's own singular/plural
marking rather than the regular English "-s" pattern, which the source treats as a recurring source of
error. Error 76 (*medium/media*) and error 77 (*datum/data*) are parallel cases: both source nouns use
an "-um"/"-a" singular/plural pairing, and both show the plural form sometimes taking a singular verb
in collective-sense usage — the source explicitly says this judgment call is more broadly tolerated for
"data" than for "media," and separately flags an emerging regularized plural "mediums" as a real, 
ongoing but still-nonstandard change. Error 78 (*alumnus/alumni/alumna/alumnae*) lays out a four-way
gendered Latin paradigm, with the book's own answer key noting that some less-conservative speakers
instead reach for the informal gender-neutral clipping "alums." Error 79 (*criterion/criteria*)
follows the same "-on"/"-a" Greek pattern as error 80 (*phenomenon/phenomena*), both of which the source
treats as still firmly irregular (regularized "-s" plurals like "criterias"/"phenomenons" are flagged
as simply wrong, unlike the more contested "mediums" case). Error 81 (*memorandum/memoranda*) follows
the Latin "-um"/"-a" pattern again, with the casual clipping "memo(s)" noted as fully acceptable in
everyday speech regardless of the full word's correct plural.
