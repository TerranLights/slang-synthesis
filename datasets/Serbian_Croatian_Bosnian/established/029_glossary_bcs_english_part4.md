# Serbian/Croatian/Bosnian — Established Vocabulary/Grammar: BCS-English Glossary, part 4 of 5 (po- through sta-)

**Source:** Alexander & Elias-Bursać, *Bosnian, Croatian, Serbian, a Textbook with Exercises and Basic
Grammar* (2nd ed., 2010), BCS-English Glossary, PDF pages 448–459 (printed pages 427–438).

**Coverage note:** exhaustive — every headword entry in the assigned page range is captured, per the
dense-glossary exception to the normal sampling rule (see `00_Reference_Extraction_Spec.md`). This
source has a clean PDF text layer (`pdftotext` produced usable text), so no vision-reading was needed;
Vision Reading Confidence is `n/a` throughout. The glossary is a two-column layout; columns were
extracted separately (left column, then right column) per page to preserve correct alphabetical
reading order. The very first entry on page 448 (`posvèćujem se`) is a mid-entry continuation whose
headword (`posvetiti se`) began on the previous page, outside this dispatch's range — flagged in its
own row rather than silently dropped. The range ends mid-entry at `stalan` on page 459 (right column,
last line); the entry itself is complete as printed, and the next glossary page continues into part 5.

**Dialect/aspect tag conventions used below:** `[B]`/`[C]`/`[S]` mark Bosnian/Croatian/Serbian-specific
forms; `[E]`/`[J]` mark Ekavian/Ijekavian pronunciation variants (Ekavian is the standard Serbian
reflex, Ijekavian the standard Bosnian/Croatian/Montenegrin reflex of jat). Where the source pairs a
perfective/imperfective (P)/(I) verb form under one headword with a "see X" cross-reference, that pair
is treated as a single vocabulary item (one row) per standard bilingual-dictionary practice. Where the
source gives two separate headwords for the same lexeme differing only by dialect tag (e.g. `prelep
[E]` vs `prelijep [J]`), each headword is its own row, since the spec requires every explicit
dialectal annotation to be captured. A few gender markers in the source print as apparently
inconsistent with the gloss (e.g. `profesor f` glossed "m., general"; `pozdrav f` for a form that is
usually masculine; `proslava n` for a form that is usually feminine) — these are transcribed exactly
as printed, flagged in Notes rather than silently corrected.
