# Serbian/Croatian/Bosnian — Established Vocabulary: Serbian-English Glossary, Part 1 (A–I)

**Source:** Celia Hawkesworth with Jelena Ćalić, *Colloquial Serbian: The Complete Course for
Beginners* (Routledge, 2006), "Serbian-English glossary," printed pp. 345–349 (PDF pages 177–179,
right/spread columns; PDF page-to-print-page offset for this scan is roughly `printed_left_page =
2×PDF_page − 10`, confirmed against several spread pages — each PDF page is a two-page spread scan,
not a single book page). This file (part 1) covers printed pp. 345–349, letters A through I (`izvaditi`).
Stops well before the "English-Serbian glossary" (printed pp. 368–380ish, not extracted — redundant
per established project precedent).

**Source has no text layer — vision-read from page scans.** Pages were rendered at 150 DPI via
`pdftoppm` and read visually. Per the extraction spec's vision-reading guard: every page in this
range was checked for handwritten marginalia (pencil/pen annotation, underlining, previous-owner
notes) distinct from the printed typeface. **None was found on any page in this file's range** — all
content is clean, consistently-typeset print, no marginalia to exclude.

**Format of this glossary (per the book's own header note, paraphrased, not quoted in full):** the
glossary does not contain every word introduced in the units, but "all the more common ones." The
unit number where each word first appears is given in square brackets (retained in the Notes column
as a citation, not as frequency data — per the extraction spec, lesson/unit-ordering is not real
frequency data). This is a monolingual-course glossary (Serbian only, no B/C/S comparative tags like
the sister Croatian-and-Serbian textbook's glossary already in this dataset at `established/073`) —
so Attested Region / Geographic Scope are `—` throughout unless a word is explicitly marked
otherwise in-page (none were in this range).

**Relationship to `established/073` (sister book's Croatian-and-Serbian glossary):** genuine overlap
in core vocabulary is expected and was not treated as a reason to skip entries here — per the
coverage rule, glossaries get exhaustive-coverage treatment as a distinct alphabetical listing with
its own entries, unit-number citations, and (for a few words) different phrasing/gloss choices than
the sister book.

**Columns held constant for every row below:** Weight/Frequency `—`; Attested Era `contemporary
(source published 2006)`; Attested Region `—`; Geographic Scope `—`; Source Type `dictionary`;
Transcription Confidence `n/a`. Vision Reading Confidence is set per-row — `verified` for the large
majority (print is clean and consistently legible throughout this range), `plausible_unverified`
flagged individually for a handful of entries with minor ambiguity (noted in the Notes column).
