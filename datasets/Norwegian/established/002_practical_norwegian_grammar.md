# Norwegian — Established Vocabulary/Grammar: Practical Norwegian Grammar (Full Reference Grammar)

**Source:** Åse-Berit og Rolf Strandskogen, *Practical Norwegian Grammar*, translated by Barbara
White, Oris Forlag, Haslum, Norway, copyright 1986, ISBN 82-7362-002-6. Printed pages 11–195
(Parts of Speech, Sentence Elements, Sentence Structure, Word Order); Index runs to printed p.202.
This file covers the whole book.

**Cross-check against the "Essential Grammar" file.** This same work was spot-checked against the
second source file in the folder, titled *Norwegian: An Essential Grammar* (same authors). The
spot-check (title/preface page, TOC, the Infinitive section's opening examples, the "duration of
time with different prepositions" section, and the Word Order chapter's opening) found the content
to be **word-for-word identical** to Practical Norwegian Grammar at every point sampled — same
preface text verbatim ("This grammar has been written specially for non-Norwegians..."), same
authors/translator byline, same table of contents with **identical page numbers for every chapter
and subsection** (Conjunctions 135, Numerals 147, Prepositions 156, Word Order 188, Index 197 —
matching Practical Norwegian Grammar's pagination exactly rather than a reorganized/renumbered later
edition), and identical example sentences down to the specific numbers used (e.g. "Jeg har lest
norsk i tre år"). This is confirmed to be a **two-printed-pages-per-scanned-PDF-page spread scan**
(each rendered page image shows two facing book pages side by side), consistent with the dispatch's
warning, but given the pagination and text are otherwise completely identical to Practical Norwegian
Grammar, this file is almost certainly a duplicate/alternate scan of the **same print edition**
(not a distinct, reorganized Routledge "Essential Grammars"-series re-edition as its filename
suggests) — no genuinely new section, no different example set, and no revision/correction was
found anywhere in the spot-check. Nothing from this second file is therefore additionally cataloged
here; this file draws exclusively, and in full, from the Practical Norwegian Grammar PDF.

**Coverage note.** No text layer (PDFXC-produced PDF, `pdftotext` returns nothing) — every page
below was vision-read from rendered page images (150 dpi). The book is a dense, systematic
pedagogical reference grammar (not a running-vocabulary glossary): its "vocabulary" consists
overwhelmingly of paradigm lists (pronoun sets, modal verbs, conjunctions, prepositions, numerals,
irregular adjective/verb forms) rather than a vocabulary-list format. Every grammar point and every
paradigm list is captured below. Per the extraction spec's allowance to prioritize comprehensiveness
of grammar points over exhaustive drill-example transcription when space becomes a real concern:
the book's hundreds of individual example sentences each introduce 1-3 incidental content words
(verbs like *snakke*, *reise*, *kaste*, adjectives, nouns) used purely to illustrate a rule: cataloging
literally every such word across 188 pages was judged to add volume without adding
derivation-relevant information once the governing paradigm is captured, so the Vocabulary table
below captures (a) every closed-class paradigm word (pronouns, conjunctions, prepositions, modal
auxiliaries, numerals, core adverbs), (b) every irregular/exception form named as such, and (c) a
representative sample of the open-class illustrative vocabulary — not literally every verb/noun/
adjective appearing in an example sentence. This trade-off is made explicitly, not silently.

**Vision-reading guard.** No handwritten marginalia, underlining, or pencil answers were found
anywhere in the rendered pages read for this extraction — the scan is clean. If any had been found
it would have been excluded and flagged here per the spec's guard; nothing to exclude in practice.

**Slang/register flag.** This is a standard pedagogical reference grammar — it does not set out to
teach slang. However, per the preface's own stated goal of translating "as colloquially and
idiomatically as possible," genuinely colloquial/idiomatic register shows up more than in a dry
academic grammar; every instance is flagged inline in the Grammar points section below rather than
buried, e.g. *kommer til å* flagged as the common spoken-register alternative to formal *vil* for
the future tense (p.24), and the modal-auxiliary register distinctions throughout.

**Note on file layout.** This file was built incrementally in a single extraction pass and its
section order does not perfectly track the book's own chapter order — content is complete and every
section is page-cited, but readers navigating sequentially should note: after the Vocabulary table
and its appended irregular-verb paradigm list, the **Grammar points** sections run Articles → Nouns
→ Adjectives → Adverbs → Pronouns (paradigm overview) → **Verbs** (Infinitive through Conjugations,
the book's actual first chapter) → Pronouns (remaining subsections: reflexive/possessive detail,
demonstrative, interrogative, relative, reciprocal, indefinite) → Conjunctions → Interjections →
Numerals → Prepositions → Sentence Elements/Structure/Word Order. Use in-document search on a
chapter name (e.g. "Grammar points — Numerals") or the page citations in each heading rather than
assuming linear book order.

## Grammar points — Articles (p.45-56)

**Form.** Norwegian has an indefinite article (functioning like English "a/an": masc. *en*, fem.
*ei/en*, neut. *et*) and a definite article that, unlike nearly every other European language, is
**suffixed to the noun** rather than a separate preceding word (masc. *-en*, fem. *-a*, neut. *-et*;
plural *-ene/-ne* across all genders, neuter also *-a*). When the noun is modified by a preceding
adjective, an *additional*, separate definite-article word is required before the adjective (*den*
masc./fem., *det* neut., *de* plural) — identical in form to the demonstrative pronoun — while the
suffixed article on the noun itself is usually retained too (*den store bilen*, lit. "the big
the-car"). Explicitly marked wrong: *store bilen* (dropping the pre-adjective article word).

**Simple vs. compound definite.** "Simple definite" = the pre-adjective article word alone, no
noun-suffix (*det hvite hus i Washington* "The White House"); "compound definite" = both the
pre-adjective word and the noun suffix together (*det hvite huset der borte*). The compound form is
explicitly flagged as "becoming more and more common in modern Norwegian" and as the more colloquial
choice (*huset mitt* "my house" marked "the more colloquial usage" vs. simple *mitt hus*). Simple
definite is reserved for: fixed idioms/proper names (*Den gamle major*, an Oslo restaurant name);
technical/formal register (*den kjemiske forbindelse* "the chemical compound"); the absolute
superlative (*uten den minste tvil* "without the slightest doubt"); when *hele* ("all/the whole") or
*halve* ("half") precede the noun, the pre-adjective article is dropped entirely (*hele dagen* "all
day", not *den hele dagen*, explicitly marked wrong); and variably with ordinals and *sist/neste/
forrige/samme* ("last/next/previous/same"), where usage is genuinely free between the two forms.

**19 numbered rules for indefinite vs. definite vs. no article** (p.50-55, condensed): indefinite
article for a first-mentioned referent; definite article once a concept has been introduced, or when
supplementary information anchors it (*mannen på bildet* "the man in the picture"), or for a
familiar-but-not-yet-mentioned referent, or for a recognized type/species. The article is dropped
entirely in: general statements/absolute truths (*Vann koker ved 100°C*) — but becomes obligatory
again once the general statement is particularized; profession/occupation/age/nationality/religion
descriptions (*Hun er katolikk*) unless modified by an adjective, in which case the article returns
(*en ivrig katolikk* "a dedicated Catholic"); exclamations beginning *Det er/var...* (*Det var god
vin!*); a long list of fixed set phrases (*å lage mat, å skrive brev, å spille piano, å holde
selskap*); prepositional-phrase idioms (*å gå på ski, i dag, etter avtale*); two-element coordinated
set phrases (*pil og bue, liv og død, kniv og gaffel*); geographical names (no predictable rule —
memorize individually); craft/profession titles before a name (*maler Hansen*, "Mr. Hansen the
painter" — contrast *maleren Munch*, with the definite article, for an artist/scientist referred to
by their achievement); newspaper headlines; a noun followed by a number (*trikk nr. 5*, not *trikken
nr. 5*); after a possessive pronoun or the genitive case; and after *hver/hvilken* ("each/which").

## Grammar points — Nouns (p.57-69)

**Gender.** Three grammatical genders: masculine, feminine, neuter — confirmed as the book's own
explicit three-way system (not a collapsed common/neuter system as in some other Scandinavian
varieties). Gender is **not predictable from a noun's form** in general and must be memorized per
word, though the book offers probabilistic guidelines: masculine for biological male sex, most
plants, and several derivational suffixes (*-er, -ning, -nad, -else, -het, -dom*, though *-else*
has neuter exceptions like *et værelse* "room"); feminine for biological female sex, tree species,
and body parts (*nese, hake, hofte, leppe, lever, lunge, tunge, panne*); neuter for diminutive/
offspring biological gender, materials/substances (*jern, stål, gull, vann*), deverbal nouns
(*skrik, besøk, arbeid*), and loanwords with suffixes *-eri, -skap* (with several masculine
exceptions: *kunnskap, lidenskap, egenskap*), *-al, -as, -ek, -em, -tet, -gram, -iv, -ment, -meter,
-om, -krati, -um*. A distinct subclass: nouns that are feminine in dialectal Norwegian and *may
optionally* take feminine declension even in the bokmål standard (*ku, bikkje, seng, bok, dør*) —
explicitly flagged as a genuine register/dialect-sourced alternation, not just textbook variation; if
in doubt, the book advises defaulting to masculine.

**Declension patterns per gender** (full paradigms given for each, p.57-62): masculine indefinite
singular *en-*/definite *-en*, indefinite plural *-er*/definite *-ene*; feminine indefinite singular
*ei*(or *en*)/definite *-a*, indefinite plural *-er*/definite *-ene* (some nouns obligatorily feminine
and always *-a*, e.g. *gate→gata*, *geit→geita*; in most other cases *-a* vs. *-en* in the definite
singular is a genuine dialect/sociolect choice, not a hard rule); neuter indefinite singular *et-*/
definite *-et*, indefinite plural unmarked/definite *-ene* (with a subset taking *-a* in the definite
plural: *bein, garn, dyr, troll, krøtter, kje, barn*). Each gender shows internal-vowel-change
("umlaut"-type) plurals for a closed set of (mostly monosyllabic) nouns, e.g. masc. *mann→menn,
fot→føtter, bok→bøker, tå→tær, hånd→hender, far→fedre, bror→brødre*; the vowel shifts follow set
correspondences (a→e, o→ø, å→æ, å→e). Nouns ending in *-el* contract (lose the stem -e-) in all forms
except the indefinite singular; nouns ending in *-er* mostly drop final -r in the indefinite plural
and the initial e- of the definite-plural ending, with some nouns (*sommer, vinter, finger, åker,
alder*) instead contracting (*sommer→somrer→somrene*). Some nouns don't change at all in the
indefinite plural (*feil, kjeks, liter, kilo, fot (unit), meter, dollar, franc, sko*); some loanwords
keep foreign irregular plurals (*konto→konti, terminus→termini*). The dative case survives only in a
handful of fossilized idioms (*på tide, i live, av gårde*).

**Singular/plural usage beyond pure form**: some nouns are singular-only (substance names, abstract
nouns, class/mass nouns like *mat, drikke, frukt*) and some are plural-only (*foreldre* "parents",
*søsken* "siblings", *briller* "glasses", *penger* "money", *klær* "clothes"); a singular form of a
normally-countable noun can denote a general class rather than one item (*koke fisk* "to cook fish"
[the class], vs. *Han fikk ti fisker* "He caught ten fish" [individuated]).

**Case.** Only two nominal cases remain productive in Modern Norwegian: nominative and genitive (plus
a vestigial dative surviving only in a few fixed idioms, noted above). The genitive is formed by
suffixing *-s* to the nominative (any definiteness/number form: *gutt→gutts, gutten→guttens,
gutter→gutters, guttene→guttenes*); a handful of proper nouns take a special Latin-style genitive in
*-u/-i* (*Jesu liv, Kristi fødsel*); nominative forms already ending in *-s* take only an apostrophe
(*Jens' hatt*); a "group genitive" suffixes *-s* only to the last word of a coordinated noun phrase
(*mor og fars eneste barn* "mother and father's only child"). The genitive is explicitly flagged as
"used less and less frequently in modern spoken Norwegian," giving way to prepositional phrases
instead (*guttens bil* → *bilen til gutten*; the preposition varies by context: *i, til, på*) — a
clear formal/colloquial register split, with the genitive reserved for more formal registers and a
closed set of idioms where it remains compulsory (*dagens slit, verdens ende, en times tid*).

**Compound nouns — five formation types** (p.67-69), directly relevant to this language's word-
formation typology: in every type, **the final element determines the whole compound's gender**.
1. **Noun + noun**: the dominant, most common pattern. Three sub-strategies: (a) **simple
   concatenation**, no linking morpheme (*tekopp* "teacup" = *te* + *kopp*; *bokhylle* "bookshelf" =
   *bok* + *hylle*); (b) **linking -s-**, inserted when the first element is itself in genitive case
   (*morsmål* "mother tongue" = *mor-s-mål*), or is a loanword ending in *-ion/-sjon/-tet/-ment*
   (*religionshistorie*), or ends in *-dom/-else/-het/-ing/-ning/-skap* (*barndomsbilde* "childhood
   portrait" = *barndom-s-bilde*; with person/people-denoting *-ing* words, English loanword *-ing*
   words, and certain non-deverbal *-ing* words as exceptions that take no -s-), or ends in *-sel*
   (*fengselsport* "prison gate"), or ends in *-nad/-et/-ed* (*søknadsfrist* "application deadline"),
   or — notably — when the **first element is itself already a compound noun**, where the linking -s-
   disambiguates the compound boundary (*saueskinnskåpe* "sheepskin coat" = *saueskinn-s-kåpe*, vs.
   plain *skinnkåpe* "fur coat" with no -s-, showing the -s- is doing real compositional work, not
   just decoration); (c) **linking -e-**, when the first element denotes an animal, plant, or person
   (*barnebarn* "grandchild" = *barn-e-barn*; *sauekjøtt* "mutton," literally "sheep-e-meat";
   *vennekrets* "circle of friends"). 2. **Adjective + noun**: the adjective is normally uninflected/
   stem-form, not fully declined (*grovbrød* "brown bread", *snarvei* "shortcut"), with a few
   lexicalized exceptions (*varmtvann* "hot water", keeping an inflected-looking *-t*). 3. **Verb +
   noun**: typically the bare verb stem/infinitive-minus-e + noun (*skrivebok* "exercise book" =
   *skrive* + *bok*; *svømmevest* "life jacket"). 4. **Preposition + noun**: stem concatenation
   (*opprop* "roll call" = *opp* + *rop*; *baktanke* "ulterior motive" = *bak* + *tanke*). 5.
   **Adverb + noun**: stem concatenation (*hjemmehjelp* "home help"; *midtbane* "mid-field"). Formation
   types 2-5 are consistently simple stem-concatenation with no linking morpheme in the book's
   examples; only the noun+noun type shows the two productive linking-morpheme strategies (-s- and
   -e-), each environmentally conditioned rather than free variation.

### Adjectives (p.70-71) — declension overview

Norwegian adjectives agree with the noun in **number and gender** (plural is gender-neutral — one
plural form covers all three genders) and have **two declensions**, indefinite and definite, mirroring
the noun's own indefinite/definite distinction, and this concord holds in predicative position too
(*Bilen er stor* "the car is big", just as in attributive *en stor bil*). The regular pattern (using
*stor* "big" as the model) has only three surface forms across the whole paradigm: the bare form
(masc./fem. indefinite singular: *stor*), a *-t*-suffixed form (neuter indefinite singular: *stort*),
and an *-e*-suffixed form (every other slot: definite singular all genders, and all plural forms:
*store*). Irregular spelling patterns layered onto this three-form system: consonant doubling before
-e for most adjectives ending in -m (*dum→dumt→dumme*); double-to-single consonant reduction before -t
(*trygg→trygt→trygge*, with exceptions *fullt, visst, spisst*); -e-loss plus consonant-reduction for
adjectives ending in -el/-er/-en (*gammel→gammelt→gamle*, *vakker→vakkert→vakre*, *åpen→åpent→åpne*);
double -t in the neuter for adjectives ending in a stressed vowel (*ny→nytt→nye*), with a notable
no-inflection-at-all exception class (*bra, tro, sky, sjalu, kry*, plus polysyllabic vowel-final
*edru, lilla*); and single -t for adjectives ending in a diphthong (*grei→greit→greie*). (Further
irregular adjectives — *liten*, *annen/egen*, *mange/mye* — and comparison/concord continue beyond
this point in the book and are covered further below.)

**Further irregulars (p.73-77).** A long list of further spelling-irregular declension classes:
adjectives already ending in *-t* (loanwords/superlatives/participles: *moderat, skrevet, størst*)
usually take no extra suffix but still take the regular *-e* definite/plural (*det svarte skjørtet*);
adjectives ending in *-sk* denoting nationality or polysyllabic (*norsk, fantastisk*) take *-e* for
definite/plural but no extra *-t* in the neuter, while *monosyllabic* -sk adjectives (*fersk, frisk*)
decline fully regularly; adjectives ending in *-d* usually add *-t* in the neuter (*rødt, bredt*); a
small closed class ending in a long vowel (*blå, grå, rå, skrå*) take double *-tt* in the neuter and
drop the final *-e* everywhere else (*blå→blått→blå*, not *blåe*). **Liten** ("small") has a fully
suppletive/irregular declension across all four slots — *liten* (masc. indef.), *lita* (fem. indef.),
*lite* (neut. indef.), *lille* (definite, all genders singular), *små* (plural, all genders,
definite or indefinite, and notably **does not take -e**) — the most irregular adjective paradigm in
the book. A closely related distinct word, *litt* ("a little", adverbial/quantifier) vs. *lite*
("little", adjectival) is a minimal pair the book flags explicitly (*Han snakker litt norsk* "he
speaks a little Norwegian" vs. *Han snakker lite norsk* "he speaks little Norwegian") — and *litt*
cannot combine with *veldig/svært* ("very"), explicitly marked **wrong**: *Hun spiser veldig litt
mat*. **Annen/annet/andre** ("other/different", also doubling as the ordinal "second") declines
masc./fem. indefinite *annen*, neuter indefinite *annet*, and *andre* everywhere else (definite all
genders, all plural) — explicitly marked **wrong** to use *annen/annet* after the definite article
(*en andre vei* marked wrong, must be *den andre veien*). Ambiguity is flagged explicitly: *den andre
dagen* can mean either "the second day" or "the other day" depending on context, with *forleden dag*
the disambiguating alternative for "the other day." *Annenhver/annethvert* = "every other." **Egen/
eget/egne** ("own") is irregular in the same three-form pattern and crucially differs in declension
pattern from superficially similar *åpen* ("open", which regularly becomes *åpne*) — contrast *min
egen dør* with *min åpne dør*. **Mange** ("many") is used with plural count nouns; **mye** ("much/a
lot") is used with mass/uncountable nouns — both can alternate for *penger* ("money"): *mange penger*
= *mye penger*.

**Indefinite vs. definite declension triggers** (p.77-78, two parallel 9-point rule lists):
indefinite form after no determiner, the indefinite article, numerals, *ikke noen/ingen*, *hver/
hvert* and *enhver/ethvert*, *noe*, *hvilken/hvilket*, *all/alt*, and in predicative position.
Definite form after the definite article, demonstrative pronouns, the possessive pronoun (except the
irregular *egen/eget* construction), personal pronouns in exclamations (*Jeg arme mann!* "poor me!"),
the genitive *-s*, inside certain fixed proper-name/address expressions with no preceding article
(*gamle Norge, lille venn, kjære barn*), in a closed set of fixed prepositional phrases (*i hele dag,
midt på lyse dagen, ut av løse luften, med største fornøyelse, i verste fall*), and after *første,
siste, neste, samme* ("first, last, next, same").

**Successive adjectives** (p.79): word order before the noun is meaningful, not free — the least
"objective"/most subjective-judgment adjective comes first (*en hyggelig, gammel kvinne* "a pleasant
old woman"), and *et lite pent ansikt* is genuinely ambiguous between "not very pretty" and "small
and pretty" while reversing the order to *et pent lite ansikt* resolves it unambiguously to "a
pretty, small face" — ordering itself carries scope/attachment information, parallel to (but not
identical in its specific ranking logic to) English adjective-ordering conventions.

**Past participle used adjectivally** (p.79-80): strong-verb participles ending in *-et* take the
regular *-e* definite/plural suffix but with their characteristic stem-vowel change retained
(*stjålet→stjålne*, not *stjålete*); weak-verb participles optionally alternate between *-ede* and
*-ete* in definite/plural (*vasket→vaskede/vaskete*, both acceptable); predicatively, the participle
reverts to the indefinite-singular form regardless of actual number (*Bilene er stjålet*, not
*stjålne*, even though *bilene* is plural) — participles pattern differently from ordinary adjectives
in exactly this predicative-concord respect. A subset of strong-verb participles (*velkommen,
løssluppen, veloppdragen, kjærkommen, vrien*) instead decline like ordinary regular adjectives (cf.
*åpen*). Non-verbal -et adjectives (*hullete, steinete*) take only the *-ete* definite/plural variant,
never *-ede*. Compound -et adjectives (*langermet* "long-sleeved", *trekantet* "triangular") allow
both *-ede* and *-ete*.

**Comparison of adjectives** (p.80-83): the regular pattern suffixes *-ere* (comparative) and *-est*
(superlative) to the absolute form (*trygg→tryggere→tryggest*). Exceptions: adjectives ending in
*-er/-el/-en* contract (losing the stem -e-) in comparative/superlative (*mager→magrere→magrest*);
adjectives ending in *-(l)ig* or *-som* take *-st* rather than *-est* in the superlative (*nyttig→
nyttigere→nyttigst*; *morsom* doubles its final -m: *morsommere→morsomst*). A long irregular/
suppletive list (paralleling English good/better/best, bad/worse/worst): *bra/god→bedre→best*,
*dårlig/ille, ond/vond→verre→verst*, *få→færre→færrest*, *gammel→eldre→eldst*, *lang→lengre→lengst*,
*liten→mindre→minst*, *mange→flere→flest*, *mye→mer→mest*, *nær→nærmere→nærmest*, *stor→større→
størst*, *tung→tyngre→tyngst*, *ung→yngre→yngst*. A distinct closed subclass of originally-adverbial
spatial/directional words (marked with an asterisk in-source: *bak, borte, fremme, foran, inne, midt,
nede, nord, oppe, sør, vest, øst, ute, under*) has comparative/superlative forms but **no positive/
absolute adjective form at all** — the missing absolute slot must be filled by the adverb itself
(*bakre* "rear" comp., *bakerst* "rearmost" superl., but no adjective "bak" — the directional adverb
*bak* "behind" covers that function instead). Periphrastic comparison with *mer/mest* ("more/most")
is obligatory (not just possible) for: participles used adjectivally (*mer elsket, mest elsket*),
*-et(e)/-ed* adjectives, polysyllabic *-sk* adjectives, indeclinable *-s* adjectives (*avsides,
avleggs*), compound adjectives, and other polysyllabic adjectives generally (*interessant, komplisert*)
— i.e. the synthetic *-ere/-est* suffixing strategy is reserved mainly for native, monosyllabic-root
adjectives, while borrowed/complex/derived adjectives default to the periphrastic strategy, a split
that (like English more/most vs. -er/-est) correlates with root complexity and origin. *Best/beste*:
indefinite *best* when comparing an entity against itself across domains (*hun er best i fysikk*),
definite *beste* when comparing against other entities (*den beste i klassen*). **Absolute comparative/
superlative**: the comparative/superlative form can express a vague degree without actual comparison,
paralleling English "-ish" (*en eldre herre* "an elderly [somewhat old] man", *en større eiendom*
"a biggish property", *en bedre middag* "quite a good dinner").

**Concord — further detail and exceptions** (p.84-86): predicative adjectives agree in number/gender
with their subject, but this breaks down in several systematic ways: (a) fixed-phrase/idiom
predicatives often stay uninflected regardless of the subject's actual number/gender (*de var glad i
hverandre*, *vi er oppmerksom på*, *de var gift*); (b) reflexive-pronoun resultative constructions stay
uninflected (*å drikke seg full, å gå seg vill, å spise seg mett*) — flagged as a genuinely large,
productive construction type, not a handful of oddities; (c) a minimal pair *glad i* with vs. without
plural concord actually carries a meaning distinction (*Vi er glad i dette landet* "we love this
country" vs. *Vi er glade i dette landet* "we are happy in this country") — concord itself is doing
semantic work here, not just agreement bookkeeping; (d) generic/generality statements default to
neuter-singular concord regardless of the real subject's gender/number (*Roser er pent* "roses are
pretty", *Frukt og grønnsaker er dyrt* "fruit and vegetables are expensive") **except** when the
subject denotes living beings, where ordinary concord resumes (*Elefanter er store* "elephants are
big"); (e) coordinated subjects usually trigger plural adjective concord (*Eva og Kari er friske*),
including the *verken...eller* ("neither...nor") construction, where Norwegian requires the **plural**
even though the closest English equivalent is singular ("neither Eva nor Kari is well") — an explicit
cross-linguistic mismatch flagged in-source; but when the coordinated subjects are non-living, the
"principle of proximity" instead applies — the adjective agrees with whichever conjunct sits closest
to it (*Verken pennen eller papiret var godt* — neuter singular agreeing with *papiret*, not a plural
agreeing with the whole coordination), and the same proximity rule extends to *eller, enten...eller,
ikke bare...men også*.

## Grammar points — Adverbs (p.87-101)

**Form.** Many adverbs derive from the corresponding adjective and are **identical in form to that
adjective's neuter indefinite singular** (*pen→pent, god→godt, lang→langt*); adjectives that take no
*-t* in the neuter correspondingly take no suffix in the adverb either (*bra→bra, hyggelig→hyggelig*,
*moderne→moderne*). A large separate stock of adverbs is **not derived from any other part of
speech** (*fram, her, der, nok, jo, aldri, slik, hvor, ut, ellers, ned, bort*), and a further set are
themselves compounds (*alltid, ingensteds, tilbake, utfor, overalt, kanskje*).

**Comparison** parallels the adjective's three-form system (*raskt→raskere→raskest*) with a large
irregular/suppletive list (*bra/godt→bedre→best*; *mye/meget→mer→mest*; *lite→mindre→minst*) and,
notably, the same closed subclass of directional/spatial adverbs seen under Adjectives (*oppe→lenger
oppe→øverst*; *bak→lenger bak→bakerst*) — reinforcing that this is a single shared paradigm across
word classes, not two independent systems. Periphrastic *mer/mest* comparison is obligatory for
*-s*-final adverbs, adverbially-used participles, and polysyllabic/compound adverbs — the identical
conditioning environment as the adjective system.

**Semantic subcategories** (p.90-101), each with its own closed/open vocabulary set:
- **Degree**: *mye, meget/svært/veldig* ("very"), *enda, nokså, helt, forferdelig, ganske, altfor,
  så, neppe, nesten, bitende, aldeles, aller*. A grammaticalized selection restriction: *veldig,
  meget, svært* require the **absolute** form of the following adjective; *mye* and *enda* require
  the **comparative**; *aller* requires the **superlative** — i.e. degree adverbs are lexically keyed
  to a specific position on the comparison paradigm, not freely combinable.
- **Place — the stative/dynamic split**, a genuine two-paradigm system directly comparable to German
  *hin/her*-style location-vs-direction marking: **at a place** (stative, used with *være* "to be":
  *inne, ute, oppe, nede, hjemme, borte, framme, vekk(e), her, der*) vs. **to a place** (dynamic, used
  with *gå* "to go": *inn, ut, opp, ned, hjem, bort, fram, vekk, hit, dit*) — each stative form has a
  dedicated dynamic counterpart, almost entirely non-overlapping in shape (*inne/inn, ute/ut, oppe/
  opp, hjemme/hjem, her/hit, der/dit*), a productive and pervasive distinction the book treats as a
  core structural feature of the adverb-of-place subsystem, not a handful of exceptions. A further
  set of synonym pairs exists for directional "from" phrases (*ovenfra = ned fra*, "from above/
  upstairs"; *østenfor = øst for*, "east of").
- **Manner**: *hvordan, hvorledes, såledees, slik, sånn, pent, godt, hyggelig, morsomt, fort*.
  *Slik/sånn* (uninflected "so, like that") contrasts with its adjectival homonym-pair *slikt/sånt*
  which **does** inflect for gender/number when used attributively (*et slikt hus*) but reverts to
  the uninflected adverbial form predicatively (*Huset er slik/sånn*, not *slikt*) — flagged as an
  easy error point. *Hvordan* ("how") cannot take an infinitive complement with *å* — explicitly
  marked **wrong**: *Jeg vet ikke hvordan å gjøre det* (correct: *...hvordan jeg skal gjøre det*).
- **Modification** (p.92-95): a large functional class of discourse/epistemic-stance adverbs —
  *ikke, heller ikke, kanskje, altså, forresten, riktignok, egentlig, (al)likevel, også, bare,
  sannelig, faktisk, sikkert, jo, da*. **Da, nok, jo, vel, nå, sikkert** are explicitly flagged as
  extremely frequent in everyday spoken Norwegian, usually unstressed, and genuinely hard to
  translate — they mark doubt/caution/uncertainty/politeness shading rather than propositional
  content (*vel* with question intonation converts a statement into a tag-question, functionally
  covering nearly all English tag-questions like "...isn't it?"; *da* can mark impatience, or, in
  informal speech, substitute for *vær så snill* "please" — explicitly flagged colloquial). Multiple
  modification adverbs can stack in a clause, with "lighter" ones preferred first and *ikke*/*også*
  obligatorily last in the sequence (*Jeg kan nok dessverre ikke komme*). **Heller** is polysemous:
  the comparative of *gjerne* ("gladly" → "rather" → "most preferred"); the required negative-polarity
  counterpart to *også* ("also") — explicitly marked **wrong** to use *også* after a negated clause
  (*Jeg vil også ikke ha kaffe* marked wrong; correct: *Jeg vil heller ikke ha kaffe*) — a systematic
  positive/negative lexical-pairing rule, not free variation.
- **Time** (p.95-101): *aldri, alltid, bestandig, ennå, da, når, noen gang, nå, ofte, nettopp, nylig,
  fremdeles, snart, så, sjelden, lenge, alt, før, allerede, siden, først*. Several minimal-pair notes
  parallel to the manner-adverb ones above: **ennå** ("yet", adverb of time) vs. **enda** ("even",
  intensifier) are kept formally distinct but flagged as merging in casual modern spoken use (enda
  increasingly covers both) — an explicit colloquial-register drift noted in-source; **da** vs. **så**
  both double as adverb-of-time and subordinating conjunction, with the adverbial use triggering
  verb-subject inversion in the following clause; **noen gang** ("ever") patterns syntactically like
  *aldri/alltid/sjelden/ofte* (used in questions/negatives/comparatives) while **noen ganger**
  ("sometimes/several times") is a free-standing time adverbial with different placement; **sjelden/
  sjeldent** is a three-way homonym spanning adverb-of-time ("rarely"), adverb-of-degree
  ("unusually"), and adjective ("rare") depending on syntactic position; **først** covers both
  sequencing ("first") and, distinctively, Norwegian's standard way of expressing English "not
  until" (*Hun kommer først kl 12* = "She won't be here until 12 o'clock" — a construction with no
  direct literal English parallel, note-worthy for later synthesis work on how "not until" semantics
  might be expressed through slang/informal register shifts).

**Adverbial phrases of time** (p.97-101): a dense, semi-paradigmatic system built from fixed
prepositions/particles — *i går/i dag/i morgen* (yesterday/today/tomorrow), extended with *morges/
ettermiddag/kveld/natt* for time-of-day granularity, and *i forgårs/i overimorgen* for ±2-day
reference; *i fjor/i år/neste år* for year reference, further extended for seasons (*i fjor vinter*
"last winter" vs. *i vinter* "this winter, approaching or in-progress depending on tense" — the same
form covers both future-approaching and present/recent-past depending on the verb's own tense, an
ambiguity resolved only by context) and with *om sommeren/vinteren/våren/høsten* for habitual/
generic seasonal reference (parallel to *om dagen/natten* for habitual daily reference, which also
covers a third sense, "these days, at present"). *I år* ("this year") vs. *i året* ("each year/per
year", a rate reading) is a minimal pair hinging purely on definiteness marking. **Duration**
("for X time") maps to **three different prepositions** depending on polarity/context: *i* for
positive-sentence duration (*Jeg har lest norsk i tre år*), *på* for negative-sentence duration
(*Jeg har ikke sett ham på 3 år*), *for* for a pre-defined/bounded period (*Jeg har leid huset for
tre år*) — explicitly flagged as the less common of the three options. **Hvor lenge** vs. **hvor
lang tid** ("how long"): broadly interchangeable, except *hvor lenge* cannot be used with
transitively-used verbs (*Hvor lang tid tar reisen?*, not *hvor lenge*) — another case where a
superficially free-variation pair turns out to be environment-conditioned.

### Pronouns (p.102-103) — paradigm overview

**Personal pronouns**: distinct subject and object forms across all persons/numbers (*jeg/meg,
du/deg, han/ham, hun/henne, den/det (both forms), vi/oss, dere/dere, de/dem*) — a genuine two-case
pronominal system layered on top of a noun system that has otherwise lost case distinctions almost
entirely (only the vestigial genitive survives on nouns) — pronouns are the one place Modern
Norwegian keeps a living subject/object case opposition. **A formal second-person polite form exists**
(*De/Dem/Deres*, capitalized, parallel to French *vous* or German *Sie*) but is **explicitly flagged
as "used less and less in modern Norwegian"** — a clear ongoing formal-register attrition, worth
flagging for synthesis work on how formality gradients might be marked (or increasingly *not* marked)
in informal registers. **Reflexive pronouns**: *meg, deg/Dem, seg* (singular), *oss, dere/Dem, seg*
(plural) — note *seg* alone covers all of 3rd-person singular and plural reflexive reference,
collapsing a distinction the personal-pronoun system keeps. **Possessive pronouns**: a genuinely
three-gender-sensitive paradigm (*min/mi/mitt* "my", *din/di/ditt* "your", *vår/vår/vårt* "our", with
a separate *mine/dine/våre* plural-referent form) — the possessive pronoun agrees with the **gender/
number of the possessed noun**, not the possessor, the same agreement logic as French *mon/ma/mes*
but overlaid on three genders instead of two. Third-person possessives split along a reflexive/
non-reflexive line: *hans/hennes/dens/dets* ("his/her/its", non-reflexive — the possessor is not the
clause's own subject) vs. *sin/si/sitt/sine* ("his own/her own", reflexive — the possessor **is** the
clause's subject) — this reflexive-possessive distinction has no equivalent at all in English, where
"his" covers both readings ambiguously; Norwegian disambiguates obligatorily through pronoun choice
alone.

**Morphological note on this list:** this is a textbook case of a Germanic strong/weak verb split.
Every irregular entry above marks its past tense via an **internal vowel change (ablaut)** rather
than a suffix (e.g. *synge→sang*, *bryte→brøt*, *stjele→stjal*) — structurally the same mechanism as
English strong verbs (sing/sang, break/broke, steal/stole), a shared Germanic inheritance. The
regular/weak class (p.40) instead suffixes a dental past-tense marker (one of four allomorphs
conditioned by the stem's final phoneme: *-dde, -de, -te, -et*) without any stem-vowel change — the
same weak/dental-suffix mechanism as English "-ed." Several irregular verbs (marked with an asterisk
in-source: *brenne, henge, klype, lyde, rekke, renne, slenge, smelle*) have **both** a strong and a
regular/weak form in free or lexically-split variation (the book doesn't specify which contexts favor
which — worth a native-speaker query if this matters for later synthesis work).

## Grammar points

### Infinitive (p.12-15)

**Form.** Most infinitives end in an unstressed vowel, usually *-e* (*snakke*, *reise*). Verbs
ending in *-s* keep that *-s* in the infinitive too (*trives*, *møtes*). Verbs are cited in
dictionaries in the infinitive, often preceded by the infinitive marker *å* ("to").

**Function — bare infinitive (without å).** The infinitive appears without *å* in five contexts:
(a) after modal auxiliaries (*Jeg kan snakke norsk*); (b) after the verbs *be* (ask), *høre* (hear),
*kjenne* (feel), *la* (let), *se* (see) — a small closed class of perception/causative verbs
governing a bare-infinitive complement, directly parallel to the English "I heard him talk"
construction; (c) in certain fixed expressions (*Hvorfor gråte når man kan le?* "Why cry when you
can laugh?"); (d) in a string of coordinated infinitives.

**Function — infinitive with å.** Appears with *å* in: (a) subject position (*Å snakke norsk er
litt vanskelig*); (b) object position (*Jeg liker å danse*); (c) as a sentence complement; (d) in
infinitive clauses (*Jeg har mye å fortelle*); (e) after a preposition (*Hun gikk for å handle*);
(f) in a string of infinitives — critically, *å* is **omitted** after coordinating *og* ("and") and
*eller* ("or") between infinitives that are genuinely coordinated, but **retained** on each
uncoordinated infinitive in a longer chain (*Han må lære å snakke, (å) skrive og (å) lese* — the
first two infinitives are uncoordinated so "å" stays omittable-only-on-the-og/eller-linked pair, not
on the whole chain); (g) in fixed idioms (*sant å si*, *vel å merke*, *så å si*); (h) after *vær så
snill* ("please"), itself alternatively replaceable by *og* + imperative (*Vær så snill å lukke
døra!* = *Vær så snill og lukk døra!*); (i) after an imperative (*Husk å slukke lyset!*).

### Imperative (p.15-16)

**Form.** Verbs ending in *-e* in the infinitive lose the *-e* to form the imperative (*snakke* →
*snakk!*). A note: final **m** is never doubled in the imperative (*komme* → *kom!*, not *komm!*).
Verbs not ending in *-e* in the infinitive are identical in imperative and infinitive form (*gå* →
*gå!*). The negative imperative simply prefixes *ikke* (*Ikke snakk!*).

**Function.** The bare imperative can read as a harsh command; Norwegian regularly softens it via
question forms (*Vil du skrive dette brevet?*) or *vær så snill å* + infinitive, or by following the
imperative with softening particles *så*, *da vel* (*Kom så tar vi en kopp kaffe!* "Come on, let's
have a cup of coffee!") — explicitly flagged in-source as a colloquial softening strategy, not a
grammatical necessity; tone/intonation does the real work.

### Subjunctive (p.17)

**Form.** Identical to the infinitive. **Function.** Nearly extinct in Modern Norwegian (unlike Old
Norse, where it was in regular productive use) — survives only in a handful of fossilized idioms:
*Kongen leve!* ("Long live the King!"), *Enhver feie for sin egen dør!* ("let every man sweep before
his own door", i.e. mind your own business). Modern Norwegian expresses wish/request/intent instead
via the conditional tense or modal verbs. **Flagged as literary/archaic register** — these two idioms
are effectively the only living trace of the mood.

### Indicative — overview of the 8 tense/aspect forms, active and passive (p.17-27)

The indicative has 8 forms, identical in ending across all persons/numbers (no person agreement):
**Present** (*han spiser*), **Past/Imperfect** (*han spiste*), **Perfect** (*han har spist*),
**Pluperfect** (*han hadde spist*), **Future** (*han skal spise*), **Future perfect** (*han skal ha
spist*), **Conditional** (*han skulle spise*), **Conditional perfect** (*han skulle (ha) spist*).
Each has a passive counterpart built either periphrastically with *bli* + past participle (*Maten
blir spist*) or synthetically with an *-s* ending (*Maten spises*) — see the Verbs-ending-in-s
section below for the two passive strategies. Of the 8 active forms, **only Present and Past/
Imperfect are synthetic single-word forms**; the remaining six (Perfect, Pluperfect, Future, Future
Perfect, Conditional, Conditional Perfect) are all periphrastic, built from an auxiliary
(*har/hadde/skal/vil/skulle/ville*) plus a non-finite main-verb form (infinitive or past participle),
with Future Perfect and Conditional Perfect stacking two auxiliary-type elements (*skal ha spist*,
*skulle ha spist*). This is a morphologically **weakly synthetic / strongly periphrastic tense
system**: 6 of 8 indicative forms are analytic.

- **Present** (p.18-19): formed as infinitive + *-r* (*snakker*), with exceptions for irregular verbs
  (*spør, gjør, vet, sier, er*), *-s* verbs, and modal auxiliaries (no *-r*: *vil, skal, må, kan, bør,
  tør*). Functions: present-moment events; events of duration via the *sitter og / ligger og / står
  og* + present construction (flagged colloquial, the closest Norwegian analog to the English "-ing"
  continuous); eternal truths (*To og to er fire*); habitual statements; future reference with a
  temporal adverb (*I morgen reiser vi*); commands (*Nå tier du stille!*); the historical present for
  narrative vividness.
- **Past/Imperfect** (p.20-21): regular verbs take stem + *-et/-de/-te/-dde* (four allomorphs
  conditioned by the stem's final sound: *kastet, levde, lyste, bodde*); irregular verbs show a vowel
  change (*gå→gikk, synge→sang, ligge→lå*). Functions: a definite past event; habitual past; a
  spontaneous present-tense feeling/reaction expressed via the past (*Det var deilig kake!* "This is
  a lovely cake!" said while tasting it — a register-marked idiomatic usage); and reference to the
  future (see Conditional).
- **Perfect** (p.21-22): auxiliary *har* (increasingly generalized in Modern Norwegian) or, for verbs
  of motion/state-transition (*reise, gå, sovne, visne*), *er* + past participle — the *er*-auxiliary
  choice marks the **result/state** of the action rather than the action itself (*Han har reist* =
  the act of leaving; *Han er reist* = he is now gone). Functions: an event in the past without fixing
  it in time; a state/duration continuing from the past, possibly into the present, with no
  indication of *when* it started (contrast with past tense, which requires duration to be irrelevant
  to the point being made); and marking a prerequisite condition for a future consequence (*Når du
  har lært norsk, kan du få en jobb*).
- **Pluperfect** (p.22-23): auxiliary *hadde* (or *var*, following the same motion/transition rule as
  the perfect) + past participle. Marks an event preceding another past event, and is used to express
  an unfulfilled wish (*Bare han hadde kommet* "If only he had come").
- **Future** (p.23-25): formed with *skal*, *vil*, *kommer til å*, or simply the present tense.
  **Skal** marks a future event within the speaker's control/intention. **Vil** marks an assumed
  future event outside the speaker's control (rule of thumb: if the sentence can be rephrased "jeg
  regner med at..." ["I assume that..."], *vil* is correct). **Kommer til å** is explicitly flagged
  in-source as "a less formal alternative to vil. It is very commonly used in spoken Norwegian" —
  a colloquial-register marker worth noting. The present tense is very commonly used for future
  reference with a temporal adverbial, and is in fact *required* (not just preferred) in temporal and
  most conditional clauses — using *skal/vil* there is marked explicitly "Wrong" in-source (*Når du
  kommer, skal vi spise* is correct; *Når du skal komme...* is flagged wrong) — except when the
  conditional clause itself expresses an intention/plan, where *skal* is required (*Hvis du skal lære
  norsk, må du gå på kurs*). The verb *bli* ("be/become") is nearly always expressed in the future as
  *vil bli*, *kommer til å bli*, or simply *blir* (present tense covering future).
- **Future perfect** (p.26): *skal/vil ha* + past participle. Marks a future action that will be
  completed before another future event/time point. Can also mean "is presumed to have [done]."
- **Conditional** (p.26): *skulle/ville* + infinitive. Marks future-from-a-past-orientation (*Han
  skulle spise da jeg kom* "He was about to eat when I came"), and conveys a wish/hope that may be
  realized (*Jeg skulle ønske han kom snart*) — in-source note that other languages often use a
  subjunctive for this function, which Norwegian covers with the conditional instead. The clause
  following a conditional-wish verb takes the past tense even though it refers to the future.
- **Conditional perfect** (p.27): *skulle/ville* + optional *ha* + past participle. Marks something
  that should have been done but wasn't, where context (the following clause's tense) disambiguates
  whether it's "still not too late" (second clause present tense) or genuinely too late (second
  clause past tense). Also used, alongside the plain conditional, as a politeness strategy for making
  requests less direct (*Jeg skulle gjerne (ha) snakket med henne* preferred over the blunter *Jeg
  vil gjerne snakke med henne*) — explicitly flagged as the more polite/preferred register choice.
- **The continuous aspect** (p.27): Norwegian has no real present-participle continuous parallel to
  English "-ing" (*Han var løpende* is explicitly marked "Wrong" in-source). The correct strategies
  are the plain present/past tense alone, or the colloquial *sitte/ligge/stå og* + verb construction
  described above.

### Sequence of tenses (p.28)

Reported (indirect) speech generally back-shifts the verb tense one step from direct speech:
present→past, past→pluperfect, perfect→pluperfect, future→conditional. Old Norse used the
subjunctive for indirect speech; Modern Norwegian uses the indicative throughout instead — another
data point for the subjunctive's near-total loss of productive function.

### Modal auxiliaries (p.29-33)

The modal class: *skal* (shall), *vil* (will), *kan* (can), *må* (must), *bør* (ought), *tør*
(dare), and in some uses *får* (may). *Skal/vil* double as the future/conditional auxiliaries (see
above). In general the modals express doubt, intention, recommendation, or command — functionally
comparable to the subjunctive mood in other languages — and their past/imperfect forms (*skulle,
ville, måtte, kunne, burde, torde*) typically signal caution or politeness rather than literal past
time reference.

- **Skal/skulle**: a command/demand (*Dere skal gjøre dette arbeidet!*); doubt/uncertainty in a
  question (*Skal jeg spørre henne nå?*); a threat (*skal du få juling*); a promise (*skal jeg hjelpe
  deg*); a rumor/supposition (*Hun skal visst være i byen* "She is said to be in town"). *Skulle* is
  used with *heller, helst, nok* for advice/recommendation (*Du skulle heller gjøre det* "You had
  better do it"), and in present-time contexts to soften uncertainty more politely than *skal*
  (*Skulle det være en kopp kaffe til?* "May I offer you another cup?").
- **Vil/ville**: willingness/desire with a personal subject (*Jeg vil gjerne reise nå*) — note
  *Han vil at vi skal komme* is correct, *Han vil at jeg kommer* is explicitly marked **wrong**:
  a modal-governed subordinate clause itself needs a modal, not a bare indicative. *Ville* softens to
  a polite request in present time (*Jeg ville gjerne snakke med direktøren*).
- **Må/måtte**: necessity (*Jeg må se den filmen*); in fixed expressions, a hope/wish (*Måtte lykken
  følge deg!* "May luck be with you!").
- **Kan/kunne**: ability/know-how (*Hun kan norsk* = she understands/speaks/maybe writes Norwegian);
  granting/requesting permission (*Kan jeg røyke her?*); *kunne* softens to restraint/caution (*Kunne
  du hjelpe meg litt?* preferred over the blunter *Kan du...*); *kunne* also marks an unfulfilled
  wish (*Kunne jeg bare vinne noen penger* "If only I could win some money").
- **Får/fikk**: an alternative permission marker to *kan/kunne*; *får/fikk* + past participle shifts
  meaning to "manage to/succeed in" (*Jeg fikk snakket med henne* "I managed to talk to her").
- **Bør/burde**: advice/suggestion, softer than a command.
- **Tør/torde**: boldness/courage/daring.
- **Modals without a main verb** (p.32-33): the main verb can be dropped (elided) only in questions
  beginning with *Hvor* (where — motion implied, e.g. *Hvor skal du?*), *Hva* (what — "do" implied,
  *Hva skal du?*), or *Hvorfor* (why, with an adverb of place/motion present, e.g. *Hvorfor skal du
  dit?*). Explicitly marked **wrong**: *Hvordan skal du til Italia?* / *Hvor lenge skal du i Italia?*
  — "how" and "how long" questions cannot drop the main verb.

### Transitive and intransitive verbs (p.33-35)

Transitive verbs take a direct object (*Han spiser et eple*); intransitive verbs cannot (*Han kommer
i morgen*). Norwegian has several minimal pairs distinguished only by this transitivity split, each
with its own full irregular conjugation — structurally parallel to English *lie/lay*, *sit/set*:
**ligge/legge** (lie/lay), **sitte/sette** (sit/set), **henge** (intrans., "hang" vs. trans. "hang
up" — same infinitive form but different past-tense conjugation, *hang* vs. *hengte*), **slenge**
(intrans. "dangle/hang around" vs. trans. "throw" — again a shared infinitive with diverging past
tense, *slang* vs. *slengte*), **rekke** (intrans. "reach/extend to" vs. trans. "reach/pass
[something]" — *rakk* vs. *rakte*). An idiomatic extension: *rakk ikke bussen* = "missed the bus."

### Separable and inseparable compound verbs (p.35-37)

Many Norwegian verbs are compounds of an adverb/preposition + verb. **If the particle precedes the
verb, the compound is always inseparable** (*å utgå*, *å avtale*, *å medbringe*, *å tilby*, *å
oversette*, *å oppfylle*). **If the particle follows the verb, the compound is separable** (*å dele
ut*, *å ta over*, *å bringe med*, *å sette over*, *å fylle opp*). Some compounds exist only as one or
the other (*innrede, undervise, gjenreise, oppdage, utgjøre, avtale* = inseparable-only; *kaste bort,
slite ut, si opp* = separable-only), and some pairs with the **same root diverge sharply in
meaning**, the inseparable form typically more abstract (*oppdra* "bring up [children]" vs. *dra opp*
"pull [a cork] out"; *gjengi* "quote/render" vs. *gi igjen* "give change"; *oversette* "translate" vs.
*sette over* "put [the kettle] on"). No general rule predicts which form a given verb takes — each
must be memorized. In everyday spoken Norwegian the **separable form is favored where a choice
exists** — flagged in-source as a colloquial-register tendency. When used adjectivally or nominally,
a compound verb is always inseparable (*et innbetalt gebyr* "a paid fee", *bortkastet tid* "wasted
time", *en innsatt* "a prisoner", literally "a person put inside").

### Present participle (p.37-38)

**Form**: always *-ende* (*syngende, sovende, kjørende, gående*). **Function**: (a) adjectival use
(*et sovende barn* "a sleeping child"); (b) describing a simultaneous action of the subject alongside
a main verb (*Han kom syngende inn i rommet* "He came into the room singing" — note the main verb
stays finite and the participle is adverbial-manner, unlike the English continuous); (c) as an
intensifying adverb before an adjective (*skinnende rein* "spotlessly clean", literally "shining
clean"); (d) with *sitte/stå/ligge* + *bli* (become) to mark durational onset (*Han ble sittende og
prate* "He sat on talking" — note the second verb in this construction stays in the **infinitive**,
not another participle); (e) nominalized, but without number/gender inflection even in that use (*de
reisende* "the passengers/travelers", *de forbipasserende* "the passers-by").

### Verbs ending in -s (p.38-40)

A closed, often-irregular class, rarely conjugated outside the present tense (where the *-s* form
equals the infinitive). Four functional subtypes: **(1) passive** (*å brukes* = *å bli brukt*, "to be
used" — this -s-passive is explicitly flagged as more restricted in modern use than the *bli* +
past-participle periphrastic passive, confined mainly to legal texts, instructions, recipes, and
newspaper headlines, e.g. *Fisken kokes i 8 minutter* "Poach the fish for 8 minutes"; *bli* +
participle is noted as the more common choice in spoken Norwegian); **(2) active-only -s verbs**
(*trives* "to thrive"); **(3) reciprocal** (*møtes* = *møte hverandre*, "meet each other" — also
*slåss* "to fight", *se(e)s* "to see each other"); **(4) reflexive** (*undres* = *undre seg*, "to
wonder"). A representative paradigm list (present/past, perfect formed periphrastically via
*bli/hverandre/seg* rather than a dedicated -s perfect): *finnes/fantes* (exist), *følges/fulgtes* (be
followed), *høres/hørtes* (be heard/sound), *kjennes/kjentes* (feel), *lykkes/lyktes* (succeed),
*minnes/mintes* (recall), *møtes/møttes*, *se(e)s/så(e)s*, *slåss/sloss* (fight), *spørres/spurtes*
(depend/be asked), *synes/syntes* (seem), *trives/trivdes*, *undres/undres*. Idioms: *Det spørs om
han kommer* ("It's not certain whether he'll come"), *Det kjennes varmt ut i dag* ("It feels hot
today"), *Det høres bra ut* ("That sounds good"), *Vi sees snart* ("See you soon" — colloquial
sign-off), *De sloss seint og tidlig* ("They were forever fighting").

### Conjugations — regular and irregular verb classes (p.40-44)

All Norwegian verbs are either **regular (weak)** or **irregular (strong)**; there is no way to tell
which from a verb's infinitive form alone — each verb's conjugation must be learned individually (a
dictionary convention: regular verbs are listed with just their past/perfect endings, e.g. *lese,
-te, -t*; irregular verbs are listed with full past and perfect participle forms).

**Regular (weak) verbs** fall into four conjugation classes by the shape of the verb stem, each with
a different past/perfect suffix pair: (a) stem ends in a **stressed vowel** → *-dde/-dd* (*bo→bodde,
bodd*; *sy→sydde, sydd*); (b) stem ends in a **diphthong, -g, or -v** → *-de/-d* (*pleie→pleide,
pleid*; *bygge→bygde, bygd*; *leve→levde, levd*); (c) stem ends in a **single consonant** → *-te/-t*
(*lese→leste, lest*; *høre→hørte, hørt*); (d) stem ends in **more than one consonant** → *-et/-et*
(*vaske→vasket, vasket*; *snakke→snakket, snakket*). A shortcut: knowing a regular verb's past tense
gives you its past participle for free — drop the final *-e*.

**Irregular (strong) verbs** show the Germanic ablaut pattern (an internal vowel change, not a
suffix, marks the past), paralleling English "strong" verbs like sing/sang/sung. The source gives an
alphabetized reference list of roughly 80 common irregular verbs with present (only where
irregular), past, and past-participle forms — captured in full in the Vocabulary table below as a
paradigm list, since this is the book's single largest closed-class lexical resource. An asterisk in
the source marks a verb that also has a regular/weak alternative form.

### Reflexive verbs and the reflexive pronoun, further possessive-pronoun detail (p.105-112)

A productive construction class where the reflexive meaning ranges from transparent (*å vaske seg*
"to wash oneself") to fully idiomatic/opaque (*å like seg* "to feel at home/enjoy it", *å glede seg*
"to look forward to", *å grue seg* "to dread", *å greie seg* "to manage", *å vise seg* "to turn out",
*å finne seg i* "to put up with", *å tenke seg* "to imagine"). Comparing the reflexive pronoun
paradigm against the personal-pronoun object-form paradigm, **only the 3rd person forms actually
differ** (*meg/deg* are shared by both systems; *seg* is reflexive-only, opposed to *ham/henne/dem*).
Many verbs have both a reflexive and non-reflexive form with **no general equivalence of meaning**
between the two (*å like seg her* "to feel at home here" vs. plain *å like* "to like" — swapping one
for the other is explicitly marked **wrong**). The infinitive normally cannot follow a reflexive
pronoun directly (*Jeg ønsker meg en tur* "I would like a trip" vs. *Jeg ønsker å ta en tur* "I would
like to take a trip" — mixing the two, *Jeg ønsker meg å ta en tur*, is marked **wrong**), except in a
small set of fixed idioms (*skynde seg å gå* "hurry up and go").

**Possessive pronouns — word order and register** (p.107-109): Norwegian collapses the English
emphatic/non-emphatic distinction (my vs. mine) into a single form used both attributively and
predicatively. **Word order is genuinely variable and register-marked**: the non-emphatic possessive
can precede *or* follow its noun, and **the post-nominal order (noun + possessive, with the noun
obligatorily in definite form) is explicitly flagged in-source as "more common in colloquial
speech"** — e.g. *boka mi* (colloquial-leaning) vs. pre-nominal *mi bok* ("less common in everyday
speech") — a genuine, source-confirmed formal/colloquial word-order alternation, not free variation.
Certain fixed phrases require pre-nominal order obligatorily (*min skyld* "my fault", *i vår tid* "in
our time", *i mine øyne* "in my view"), as does *egen* ("own", always precedes: *min egen seng*),
while an adjective-modified noun phrase usually pushes the possessive to the very end (*de fine
blomstene hennes*) and a universal quantifier (*alle, alt, all, hele*) also pushes it to the end
except in fixed idioms (*i all min dag* "all my life"). Genitive constructions built on a pronoun
(rather than a named noun) **cannot** take the prepositional paraphrase strategy available to
ordinary nouns — *huset til ham* is explicitly marked **wrong**; only *huset hans*/*hans hus* are
correct, a restriction not shared by the noun-genitive system.

**Reflexive possessive pronouns — *sin/si/sitt/sine*** (p.109-112): used only when the possessor and
the subject of the **same clause** are coreferential and third-person (*Henry tar sykkelen sin* "Henry
takes his [own] bicycle" vs. *Henry tar sykkelen hans* "Henry takes his [someone else's] bicycle") —
a genuine disambiguation English cannot make with "his" alone. Five hard restrictions, each
explicitly illustrated with a marked-wrong example: (1) clause-bound — crossing into a new clause
(relative, subordinate, coordinate) forces the non-reflexive form even with the same real-world
referent; (2) can **never** be the grammatical subject of a sentence (*Sykkelen sin er fransk* marked
wrong); (3) coordinated subjects force the non-reflexive form (*Per og kona si bor sammen* marked
wrong — must be *kona hans*); (4) cannot stand predicatively in a simple sentence (*Huset er sitt*
marked wrong) but **can** appear in comparatives (*Hun er mindre enn broren sin*) and in emphatic
cleft-style fronting for focus (*Det er klærne sine han vasker*); (5) with verbs like *be* (ask), *la*
(let), *tillate* (permit), genuine referential ambiguity can arise between the grammatical and
logical subject. A residual set of fixed idioms uses *sin/si/sitt/sine* with no identifiable
antecedent subject (*Det var jenta si!* "there's a good girl!"; *i sin tid* "at one time").

### Demonstrative pronouns (p.112-116)

Two paradigms, *den/det/de* ("that/those") and *denne/dette/disse* ("this/these"), both inflecting
for the three genders/plural. The **stress-based minimal pair** with the definite article is a
genuinely striking typological feature: *den gode stolen* is ambiguous in writing between "the good
chair" (article, unstressed *den*) and "that good chair" (demonstrative, **stressed** *den*) — the
two readings are distinguished **purely by prosody**, with no orthographic marking; strong stress on
*den* can even mark subjective emphasis/exclamation (*Hun hadde den fine kjolen!* "she had SUCH a
fine dress!"). **Obligatory neuter-singular form**: when English "this/that/these/those" functions as
the subject of "to be" with a noun predicate, Norwegian **always** uses the neuter singular pronoun
(*det/dette*) regardless of the predicate noun's actual gender/number (*Det er en stor kopp*; *Dette
er gode bøker*) — using a gender/number-matched demonstrative here is explicitly marked **wrong**,
another case (parallel to the generic-statement adjective-concord rule) where neuter singular serves
as a semantically "unmarked"/default slot cutting across the normal agreement system. *Det/dette* can
also anaphorically refer to an entire preceding clause/proposition (*Han prøvde å smugle inn vin, men
det gikk ikke*). **Register note, explicitly flagged in-source**: *denne/disse/dette* "can in some
contexts have a negative implication" — a genuine pragmatic/register effect worth flagging for slang-
synthesis purposes (*Hva vil de, disse politikerne?* carries a dismissive edge absent from a neutral
referring expression). Other demonstrative-function words: *slik/sånn* ("such", synonymous, with
inflected forms *slikt/sånt, slike/sånne*, and a predicative-vs-attributive inflection split paralleling
the Adverbs chapter's note); *samme* ("same", not to be confused with *sammen* "together"); *selv*
("self/even") with three functions — indeclinable postposed reflexive intensifier ("himself"),
inflecting *selve* prenominal intensifier ("in person/proper", with superlative *selveste* for extra
emphasis, banned with plural nouns), and clause-initial adverbial "even"; *begge* ("both") with a
further *begge to* (specific pair) vs. *begge deler* (general/indefinite-referent pair) distinction,
and *både...og* ("both...and") notably **not** restricted to exactly two items the way English "both"
is, extending freely to three-plus-item lists (*Både epler, pærer og druer*).

### Interrogative pronouns (p.117-118)

Four interrogatives: **hvem** ("who", persons only), **hva** ("what"), **hvilken/hvilket/hvilke**
("which", gender/number-inflecting), **hva for en/et/noe/noen** (a periphrastic alternative to
*hvilken*, explicitly compared in-source to the English which-vs-what register split — *hva for*
is "more colloquial," directly parallel to how "what bus" reads more casually than "which bus" in
English). Fixed colloquial idiom: *Hva for noe?* ("What?") and *Hva sa du for noe?* ("What did you
say?") — both flagged explicitly as "very common in everyday, informal usage."

### Relative pronouns (p.120-124)

**Som** ("who/which/that") is **"the most frequently used relative pronoun in modern Norwegian,"**
covering both subject and object relative functions (where English restricts "who" to subjects and
increasingly avoids "whom"), and — notably more freely than English — can refer back to an object
pronoun antecedent (*Jeg så dem som skulle synge*, "I saw the people who were going to sing," where
English requires a noun, not a pronoun, in this slot). **Som** can be omitted exactly when English
"that/which/who" can be omitted — i.e. when it is not the subject of its own clause (*Den gutten
(som) du ser der, er broren min*) — and is explicitly marked **wrong** if replaced by *hvem* in a
restrictive relative clause (*Den gutten, hvem går der...* marked wrong). **Som** can also refer
back to an entire preceding clause/proposition rather than a single nominal referent, in which case
*noe* is often inserted before or instead of it (*Jeg har gått på kurs, noe (som) du også burde
gjøre* — "something you ought to do too"); *hva* can substitute for the whole *noe som* combination
in this function. When *hvem/hva/hvilken* is itself the subject of a subordinate clause, **som**
becomes **obligatory** immediately after it (*Jeg vet ikke hvem som kommer*, not *hvem kommer*) —
but is dropped when the interrogative is itself the object (*Jeg vet ikke hva han vil*). **Literary
forms**: older/formal Norwegian occasionally uses *hvis, hvem, hva, hvilken/hvilket/hvilke* in place
of *som* (*Mannen, hvis navn jeg ikke husker...* "the man whose name I don't remember" — flagged as
literary register, with the colloquial equivalent given as a full recast: *Jeg husker ikke navnet
på mannen som...*). **Six further special uses of som** are catalogued: (a) in a fronted
concessive/temporal adverbial phrase (*Som ung var hun ivrig idrettsjente* "as a young girl she was
a keen athlete"); (b) marking a role/capacity ("as a doctor"); (c) same, fronted for emphasis; (d) in
simile constructions ("he spoke to me as to a child"; the proverb *Som du sår, skal du høste* "as you
sow, so shall you reap"); (e) after comparative-equality expressions (*like/likså/så gammel som meg*
— three near-synonymous comparative-equality markers); (f) in the fixed indefinite-pronoun-building
suffix pattern *hva/hvor/hvem/hvilken + som helst* ("whatever/wherever/whoever/whichever" — a fully
productive free-choice-pronoun formation, directly comparable to English "-ever" compounds).
**Cleft sentences** (p.123-124): a dedicated focus/emphasis construction extracting any sentence
element into *Det var X (som) ...*; when the focalized element is itself a full clause/proposition
rather than a nominal, *det* substitutes for *hva/som* (*Det var det jeg mente*, "that was what I
meant," alongside a less common full alternative "Det var hva jeg mente"). **Som in relation to time
and place** (p.124): *som* can function like an adverb of time or place in certain fixed collocations
(*Nå som vinteren kommer...* "now that winter is coming"; *De steder som vi har vært på...*).

### Reciprocal pronoun (p.125)

**Hverandre** ("each other") is the standard modern reciprocal, used with a plural (or a
grammatically-singular-but-logically-plural, e.g. collective-noun) subject, and explicitly flagged as
**not interchangeable with the reflexive pronoun** (*Vi har møtt oss før* is marked **wrong** for "we
have met each other before" — only *hverandre* is correct there), a sharp grammatical-category line
between reciprocal and reflexive reference that English blurs less visibly.

### Indefinite pronouns (p.125-134) — en/man, assertive, negative, universal, impersonal

**En/man** ("one"): interchangeable as subject (*Man/En kan ikke få alt her i verden*), but **only
*en*** is grammatical in object position or the genitive (*Kurset krever mye av en*; *Ens beste
venner...*) — *man* in those slots is explicitly marked **wrong**.

**Assertive — noen/noe** ("some/any", "somebody/something"): inflects for gender/number when
modifying a noun (masc./fem. sg. *noen*, neuter sg. *noe*, plural *noen*) but stays invariant when
standing alone referring to people (*noen*) vs. things (*noe*), and extends to mass nouns (*noe
mat*). *(Note: printed pages 127-128 of the source — covering the continuation of this section,
specifically "annen/annet/andre" and "mange/mye" as assertive indefinites, and the Negative pronouns
subsection "ingen/ikke noen/intet/ingenting" — are missing from this scanned PDF; the scan jumps
directly from printed p.126 to printed p.129 with no intervening pages captured. This is a genuine
source-scan gap, not an extraction omission — flagged per the extraction spec's page-verification
discipline rather than silently skipped. One fragment survives from the tail of the Negative-pronouns
subsection, visible as a "Wrong:" example at the top of p.129: "Han sa at han hadde kjøpt ingen bil.
Han sa at han hadde sagt ingenting" is marked ungrammatical in-source, implying the correct pattern
negates with ikke + noen/noe rather than doubling a negative pronoun inside an already-negated
clause — consistent with the general cross-Germanic single-negation tendency, but this is inferred
from the one surviving fragment, not directly read from the (missing) rule statement itself.)*

**Universal — all/alt/alle/allting** ("all/everything") vs. **hele** ("the whole") (p.129-131): *all*
modifies mass nouns (*all maten*); *alt* either modifies a mass noun or stands alone (optionally with
*sammen*), and is interchangeable with *allting*; *alle* precedes/stands for plural nouns, and — a
genuine typological point worth flagging — Norwegian **never translates "of" in "all of X"**: *alle*
simply governs the following plural noun directly with no equivalent of "of them." *Hele* is
categorically distinct — it refers to a single bounded whole, not a collection (*hele brødet* "the
whole loaf" vs. *alt brødet* "all the bread [e.g. in the house]" vs. *alle brødene* "all the loaves"),
and conventionally skips the definite article even though the noun itself stays in definite form
(*Jeg arbeider hele dagen*, not *den hele dagen*). Fixed idioms: *I all verden* ("good heavens"), *I
alle dager* ("what on earth"); *alt* can also mean "already" (a functional overlap with *allerede*
noted earlier under Adverbs). **Hver/hvert** ("each/every", p.131) obligatorily takes an indefinite
following noun (*Hver dag*, not *Hver dagen* — marked **wrong**), and can stand alone post-nominally
(*De fikk en kake hver*, "they each got a cake"). **Enhver/ethvert** is a more emphatic "each and
every," occurring mainly in fixed idioms (*Enhver feie for sin egen dør!* — the same fossilized-
subjunctive proverb already noted under Subjunctive, confirming it recurs as a stock idiom rather than
a one-off). **Annenhver/annethvert** = "every other" (*Hun gikk på skolen annenhver dag*); with any
other ordinal, *hver* must precede it instead (*hver tredje time* "every three hours"). **Hver sin**:
when a universal quantifier combines with a possessive, the possessive is placed between *hver* and
the noun, and the reflexive possessive *sin* is considered the most grammatically correct choice
precisely because *hver* itself is the antecedent it reflexively refers back to (*Vi gikk hver sin
vei* "we each went our own way" — though *hver vår vei* is also accepted as standard).

**Impersonal pronoun — det** (p.132-134): a fourth functional role for *det*, layered on top of its
demonstrative, dummy-subject-of-clause, and cleft-sentence uses already covered: (a) genuinely
impersonal/weather/existential sentences (*Det regner*; *Det er kaldt i Norge om vinteren*), including
the idiomatic *Hvordan har du det?* ("how are you?") and the colloquial farewell *Ha det (bra)!*
("goodbye," literally "have it well"); (b) a dedicated existential-subject construction fronting *det*
before the verb when an indefinite noun phrase is the logical subject, closely paralleling English
"there is/are" (*Mange mennesker bor i Norge* → *Det bor mange mennesker i Norge*; the fronted
indefinite subject and the inverted verb-first order are the construction's two moving parts
together); (c) obligatory subject of time/date sentences (*Det er mandag i dag* / *I dag er det
mandag* — the bare *I dag er mandag*, without *det*, is explicitly marked **wrong**), and of a related
"once upon a time" narrative-opening construction (*Det var en gang en prins...*, with the bare *En
gang var en prins* marked **wrong**); (d) as the dummy subject of cleft sentences, cross-referenced to
the Relative-pronouns section above.

## Grammar points — Conjunctions (p.135-146)

**Two classes**: coordinating (*og* "and," *men* "but," *for* "for/because" [the only coordinating
conjunction restricted to joining whole sentences, not words/phrases], *eller* "or," plus correlative
pairs *både...og* "both...and," *enten...eller* "either...or," *verken...eller* "neither...nor") vs.
subordinating (which always introduce a subordinate clause and trigger the subordinate-clause word-
order pattern — cross-referenced to the Word order chapter). Coordinating conjunctions trigger **no**
subject-verb inversion in the clause they introduce, unlike subordinating ones, and when joining full
clauses the two joined clauses must be the same *kind* (both main, or both subordinate) — explicitly
marked **wrong** to mix a coordinating conjunction with an inverted (subordinate-style) clause.

**At** ("that," p.136): omissible except (a) when its clause is fronted before the main clause, (b)
after a preposition, (c) after the comparative conjunction *enn*. **Om** ("if/whether," p.137,
conditional sense): functions alongside *hvis*. **Time conjunctions** (p.138-140): **da** (single
past event) vs. **når** (habitual/repeated, or any-tense-but-single-past-event) is the book's central
*da/når* distinction — a genuine obligatory split with no free variation, directly comparable to (but
not identical to) the English simple-vs-habitual-past distinction, worth flagging as a likely target
for how Norwegian speakers' register/formality choices might blur or preserve this distinction
informally. **Etter at** (conjunction) / **etter** (preposition) / **etterpå** (adverb) is a three-way
part-of-speech split on one meaning ("after/afterwards") — directly parallel to the **før** (prep.,
replaceable by *foran* only for literal spatial "in front of," never temporal) / **før** (conjunction,
never replaceable by *foran*) / **før~tidligere** (adverb) three-way split immediately following it —
both cases show the same underlying lesson: a single English gloss can map to three distinct
Norwegian parts of speech with non-overlapping syntactic privileges, each independently restricted.

**Cause** (p.140): *fordi, da, siden, ettersom, når* all roughly "because/since/as." **For** (as
cause) is explicitly restricted to joining two independent main clauses only (like *fordi* in
meaning, but syntactically more limited); **derfor** ("therefore") is an adverb, not a conjunction,
and — a sharp usage rule explicitly marked — **can never answer a "hvorfor" (why) question directly**;
only *fordi* can.

**Condition** (p.140-141): a long near-synonym set (*dersom, hvis, så fremt, så sant, om, når, i
fall/i tilfelle, med mindre, uten at, bare, for så vidt som*) — all interchangeable in the book's own
paradigm example sentence, confirming genuine free variation among near-synonyms rather than hidden
register/meaning splits (unlike several of the other near-synonym sets catalogued elsewhere in this
file). A conditional clause can also be formed with **zero conjunction at all**, purely through
subject-verb inversion (*Hvis han kommer, går jeg* = *Kommer han, (så) går jeg*) — a genuinely
productive asyndetic-conditional construction. **Uten at / uten å** ("without," p.142): the
infinitive-with-å construction is available only when the main and subordinate clause share the same
subject; different subjects force the finite *uten at* construction — the identical subject-identity
condition already seen governing several other å-infinitive-vs-at-clause alternations in this
grammar (e.g. Modal auxiliaries, Conjunctions of purpose below), suggesting it's a general principle
of the language's clause-reduction system rather than a one-off quirk of any single construction.

**Concession** (p.142-143): a further large near-synonym set (*enda, skjønt, selv om, fordi om, enda
om, om, om enn, trass i at/til tross for at, samme, hva så, hvor så, hva enn, hvor enn, uansett*),
several of which build productive free-choice concessive clauses parallel to the *hva/hvor/hvem +
som helst* pattern already seen under Relative pronouns (*hvor dyrt det så/enn skulle bli* "however
expensive it might be"; *uansett hvor langt det er* "regardless of how far it is").

**Purpose** (p.143-144): *for at, så (at)* ("so that"). An alternative reduced construction, **for
(ikke) å + infinitive**, is available again only when subject identity holds across both clauses —
the same clause-reduction condition recurring a third time in this chapter.

**Result** (p.144): *så at, slik at, sånn at, så*. **Så** is flagged as a genuine four-way
polyfunctional word across this grammar: a conjunction of result, a conjunction of purpose, a
coordinating conjunction meaning "because of which," and a plain adverb ("then") — a single surface
form spanning four distinct grammatical functions, worth noting as a likely high-leverage word for
later slang-synthesis work given how much functional load it already carries in the standard
language.

**Comparison** (p.145): *som* ("as"), *enn* ("than"), and a correlative-comparative construction with
three interchangeable connector sets — *dess...dess*, *jo...dess*, *jo...desto* (all "the...the," as
in "the more you eat, the fatter you get") — explicitly flagged as requiring special attention to the
subordinate-clause word order in the first half. *Som* is dropped when the compared subject is
compared against itself rather than another subject (*De gjør så godt (som) de kan*), but retained
when comparing against a distinct referent (*Han kom så fort som lynet* "as quick as a flash").

## Grammar points — Interjections (p.146)

A closed list of emotive particles with no syntactic integration into the clause: *fy* (shame), *au*
(ouch), *æsj*/*isj* (ugh/phooey — disgust), *hurra* (hurray), *uff* (oh dear), *hei*/*hallo* (hi/
hello — note *hallo* can also mean an attention-getting "hey!"), *takk* (thank you), *hm* (mm),
*fanden*/*pokker*/*fillern* (damn/blast/bother — three near-synonymous **mild profanity/taboo
interjections**, explicitly flagged here as the clearest taboo-register vocabulary catalogued
anywhere in this book, worth a native-speaker check on their relative intensity before synthesis
use), *åh* (oh). **Ja/jo/nei** (yes/yes/no) are classified as interjections too, with a genuine
**polarity-sensitive yes-particle split** directly paralleling German *ja/doch*: **ja** answers a
positively-phrased question, **jo** specifically answers a *negatively*-phrased question in the
affirmative (*Snakker du ikke norsk?* — *Jo* = "yes [I do, contrary to your negative framing]") — a
real grammaticalized distinction English collapses to a single "yes," directly relevant to how
politeness/assertion-strength might be marked in informal register. *Ja* and *nei* also have a
secondary **discourse-particle function** unrelated to literal polarity, adding emphasis/spontaneity
to an utterance (*Nei, så fin du er nå!* "Gosh, how nice you look now!" — *nei* here carries no
negative meaning at all, purely an exclamatory discourse marker) — flagged as a genuinely colloquial/
spoken-register usage pattern.

## Grammar points — Numerals (p.147-155)

*(The bare cardinal/ordinal number list itself — one through twenty, the tens, hundred, thousand —
sits at the very start of this chapter and was not captured as its own transcribed list here, given
this project's priority on genuinely novel/information-dense content over the single most
well-documented, lowest-novelty vocabulary set in any Germanic language; every other subsection of
the Numerals chapter, including its less-obvious grammar points, is captured in full below.)*

**Compound numeral formation — two competing strategies**: either the English-style low-before-high
pattern (*trettini* "thirty-nine," *sekstifire* "sixty-four," built by simple concatenation) or a
high-before-low pattern **linked with *og*** ("and"): *treogførti* ("three-and-forty" = 43) — directly
comparable to German's *dreiundvierzig* pattern, and notably the opposite ordering from the first
strategy. Both are standard; the choice is free but is expected to apply consistently within a
discourse. **Alternative base-number forms**: several cardinals have two free-variant forms differing
only in formality/conservatism (*sju*/*syv* "7," *tjue*/*tyve* "20," *tretti*/*tredve* "30" — the
*-tyve*/*-tredve*-type forms flagged as "more conservative"); crucially, **the two conventions cannot
mix within a single compound**: a compound must either use the conservative base form with the
linking *og* (*syvogtyve*, "seven-and-twenty" = 27) or the non-conservative form with no linking word
at all (*tjuesju*, concatenative = 27) — mixing (e.g. a conservative base with no linking word) is
implicitly disallowed by the paradigm, a genuine morphophonological conditioning rule layered on top
of free lexical variation, not free combination.

**En/ett vs. the indefinite article** (p.148): Norwegian distinguishes "one" (as an explicit count,
stressed **én**/masc.-fem., **ett**/neut.) from the homophonous-when-unstressed indefinite article
*en/et* — the same gender-matching mechanism as the article itself. A further rule: **en/ett does not
inflect for gender when it is part of a larger compound numeral or a decimal figure** — *tjueen år*
("21 years," using the uninflected masculine/common form even though *år* is neuter and would
otherwise require *ett*), *null komma en poeng* ("0.1 point"). Ordinal *ett* vs. cardinal counting
also diverges in a few fixed contexts (*kapittel én, vers én* "chapter one, verse one" keeps the
stressed form even post-nominally, contrasting with the attributive *ett kapittel*).

**Second**: covered by the irregular adjective/indefinite-pronoun *annen/annet/andre*, cross-
referenced rather than restated (see Adjectives and Pronouns chapters above, where its full
declension and the *andre* ("second") / *andre* ("other") potential ambiguity were already detailed).

**Ordinal numbers used adjectivally** (p.155) obligatorily take the **definite** article/form (*den
første dagen i uka*, *den fjerde gutten*) — but this definiteness requirement is explicitly suspended
for a specific date formula (*Han er født 5. mars 1967*, no article at all) — another case in this
grammar where a date/calendar construction carves out its own exception to a general rule (paralleling
the *det er mandag i dag* obligatory-*det* rule under Pronouns).

**Dates and age** (p.149-150): dates are read as ordinal-day + month + cardinal-year, with the year
itself readable either as one four-digit number or split into two two-digit chunks (*1979* = either
*nittensyttini* or *nitten syttini*, i.e. "nineteen seventy-nine" matching the English pattern).
Decade/era reference (*i trettiårene*, "in the thirties") is genuinely ambiguous between a historical-
decade reading and a referring-to-a-person's-age-bracket reading, disambiguated only by context — the
same form serves both functions. Age expressions productively compound with *-åring* (*en tiåring* =
"a ten-year-old") and *-årsalderen* (*i tiårsalderen* = "at about age ten"), and *et tiår* lexicalizes
"a decade" as its own noun, extending to a plural collective (*De har vært her i årtier*, "for
decades").

**Fractions** (p.150): built with *-del(er)* suffixed to the cardinal (*en tredel/tredjedel* "a
third," *to tredeler* "two thirds"), with *kvart* as a dedicated synonym for "a quarter" alongside the
compositional *firedel/fjerdedel*. A fraction-governed noun obligatorily stays **singular** regardless
of the fraction's value (*7 1/2 time*, not *timer* — "seven and a half hours" uses the singular noun
form), a genuine grammaticalized-singular rule distinct from ordinary plural marking. *Halvannen/
halvannet* ("one and a half," gender-agreeing) is a dedicated fused numeral-plus-half form, an
alternative to the fully compositional *en og en halv*.

**The clock** (p.151-152) — a genuinely distinctive typological feature, directly comparable to
German and worth flagging prominently for synthesis purposes: Norwegian divides the hour into quarters
using **over** (past) the hour for the first quarter, **på** (to) the **half**-hour for the second
quarter, **over** the half-hour for the third quarter, and **på** the hour for the final quarter — and
critically, **the half-hour is always named relative to the upcoming hour, not the one just passed**
(*halv ti* = "half ten" literally, but means **9:30**, not 10:30 as the superficially identical English
colloquial phrase would suggest) — an explicit false-friend the source flags directly, with real
synthesis-relevant implications for any slang/informal time-telling register derived from this system.
Norwegian also typically omits "minutes" even for non-round numbers where English would need it
explicitly (*syv på halv*, "23 minutes past," omits "minutter" the way English can only omit it for
multiples of five). The 24-hour clock is used officially (timetables, programs) but rarely in ordinary
conversation, where *om morgenen/ettermiddagen* disambiguates a.m./p.m. when needed. A dedicated
**fixed-expression family for "roughly around a time"**: *cirka klokka åtte*, *ved åtte-tiden*, *rundt
åtte* — three free-variant hedging constructions. A further near-synonym pair for "just over/under a
duration": *en drøy time* ("just over an hour") vs. *en snau time* ("just under an hour") — a
genuinely productive degree-marking pair worth flagging as a compact, idiomatic way to express
approximate duration that has no single-word English equivalent.

**Money** (p.153): Norwegian krone/øre currency is read with the same split-or-whole flexibility as
dates (*Kr 3,50* = *tre kroner og femti øre* or *tre femti* or, in the "and-a-half" idiom, *tre og en
halv krone*). A dedicated **coin/note nickname vocabulary**: *en tiøring* (10-øre coin), *en
femtiøring* (50-øre coin), *en krone/et kronestykke* (1-krone coin), *en femmer/femkrone/femkroning*
(5-krone coin — three free-variant nicknames for the same coin), *en tier* (10-krone coin, noted as
having **replaced** an earlier compound *en tikroneseddel* when the denomination changed from note to
coin — a small but genuine attested-era-sensitive lexical-replacement fact), *en femtilapp/
femtikroneseddel* (50-krone note), *en hundrelapp/hundrekroneseddel* (100-krone note), *en tusenlapp/
tusenkroneseddel* (1000-krone note) — the *-lapp* ("note/slip") informal nickname series flagged
implicitly as the more colloquial member of each word-pair by its brevity and productivity across
denominations, worth a native-speaker check on register strength. **Idioms involving numerals**: *Nå
er hundre og ett ute* ("now the fat is in the fire" — literally "now 101 is out"), *Tusen takk*
("thanks very much," literally "a thousand thanks"), *Jeg har tusen ting å gjøre* ("I have a hundred
and one things to do" — note the source's own English gloss uses "a hundred and one" for literal
*tusen*/"thousand," an idiomatic-equivalence mismatch across the two languages worth flagging), *Det
har gått i ett kjør* ("it's been a non-stop whirl," literally "in one drive/course"), *en tolver i
tipping* ("12 right in the football pools," a sport-specific nominalized-numeral slang term — the
clearest genuinely slang-adjacent numeral vocabulary in this chapter). **Figures vs. words** (p.154):
figures are conventional for money/weights/measures and large numbers (while a word-written exception
is still acceptable for small round sums, *Jeg fikk fem kroner* "I was given five kroner"), and always
for dates; words are preferred for small numbers and are **obligatory inside compound words**
(*trekant* "triangle," *femøring*, *tredelt* "divided in three," *firesifret* "four-digit" — numeral
prefixes inside compounds never appear as bare digits).

## Grammar points — Prepositions (p.156-179)

**The book states explicitly that there are no hard-and-fast rules for preposition choice — "the
only solution is to learn the prepositional phrases as they occur and in context,"** making this the
single most idiom-dense, least rule-governed chapter in the book, and arguably the chapter with the
highest raw density of genuinely useful phrasal vocabulary for later slang-synthesis work (phrasal
verb-plus-particle combinations are a classic site of informal/colloquial semantic drift across
Germanic languages). Given the chapter's sheer size (a ~17-page alphabetized idiom dictionary, one
preposition at a time: *av, etter, for, fra, hos, i, med, mellom, mot, om, over, på, til, under, ved,
blant*, and more), this section captures the chapter's **systematic/rule-governed content in full**
and the **idiom dictionary itself as a representative sample** across the alphabet (not every entry —
consistent with this file's stated coverage trade-off), rather than transcribing all several hundred
verb+preposition idioms individually.

**Place — "at" vs. "to" a place** (p.156-157): the same stative/dynamic distinction already seen
under Adverbs of place governs prepositions too. Guidelines for the stative preposition with place
names: **på** for villages, small towns, and islands that are not independent countries; **i** for
countries and larger towns, and — notably — **also very often for coastal towns/villages regardless
of size**, a genuine exception that breaks the village/town size-based default; **til** is the
dynamic/directional preposition across the board for any "directional" verb (travel, go, come). A
closed set of fixed genitive-taking idioms keeps **til** even in non-motion-adjacent fixed phrases
(*til sjøs* "to sea," *til bords* "to the table," *til sengs* "to bed," *til fots* "on foot," *til
fjells* "to the mountains," *til skogs* "to the woods" — all built on the vestigial *-s* genitive
noted earlier under Nouns, confirming that case survives productively inside exactly this kind of
fixed prepositional idiom). A further, structurally distinct pattern: a closed set of institutional/
activity nouns uses the **identical preposition** (*på*) for both the stative and dynamic sense
(*være på jobben* / *gå på jobben*, "be at work" / "go to work"; similarly *kino, apoteket,
postkontoret, kontoret, restaurant, badet, kjøkkenet*) — a genuine lexically-conditioned exception to
the otherwise-systematic på-vs-til split, grouping institutions/rooms as a special case.

**For vs. til — the "as a gift" / "on someone's behalf" minimal pair** (p.159): *Hun kjøpte blomster
til moren sin* (bought flowers **for** her mother, as a gift) vs. *Hun kjøpte blomster for moren sin*
(bought flowers **for** her mother, i.e. on her mother's behalf/errand) — a genuine beneficiary-vs-
agent distinction collapsed in English "for" but kept apart in Norwegian by preposition choice alone.

**Prepositions in the passive** (p.160): the agent of a *bli*-passive is introduced by **av** ("by"),
extending to authorship/ownership/invention more generally (*en bok av Ibsen* "a book by Ibsen"; *Han
er oppfinneren av kruttet* "He is the inventor of gunpowder").

**Prepositional phrases replacing genitives** (p.160-161) — a systematic six-way breakdown of which
preposition substitutes for the increasingly-avoided *-s* genitive (cross-referenced to the Nouns
chapter's own note that the genitive is losing ground to prepositional paraphrase in spoken registers)
depending on the semantic relationship: (a) **til** for simple ownership/belonging (*sønnen til Per*
"Per's son"); (b) **på** for part-of-a-whole relationships, roughly "of" (*halen på hunden* "the dog's
tail"); (c) **på** again for role/office-holder-of-an-institution relationships ("the captain of the
ship," "the doctor on the ward" — notably still **på**, not a dedicated possessive preposition,
showing på's genitive-replacement role is broader than pure physical part-whole); but — a sharp
split — (d) **i** instead of på specifically for **national-level office-holders** (*kongen i Norge*
"the king of Norway," *statsministeren i Norge*) and for "within a specific area" readings generally
(*innbyggerne i landet* "the country's inhabitants") — the same i-vs-på national/institutional divide
recurring from the place-preposition system above; (e) **for** specifically for "the head of a group of
people/institution" readings (*representanten for elevene* "the pupils' representative," *dirigenten
for orkesteret* "the orchestra's conductor") — a fifth, semantically narrow genitive-replacement
preposition, distinct from (a)-(d) above, confirming the genitive-replacement system is **not one
general-purpose preposition but five lexically-conditioned ones**, each tied to a specific semantic
relationship type, not free variation.

**Prepositional phrases replacing compound nouns** (p.161-162): **av** regularly substitutes for a
material-denoting first element of a noun+noun compound (*en gullring* "a gold ring" = *en ring av
gull*; similarly *trehus/hus av tre* "wooden house," *ullgenser/genser av ull* "woollen sweater,
*porselenskopp/kopp av porselen* "china cup") — but explicitly **not** for every noun+noun compound,
with a direct counter-example flagged: *en kopp te* ("a cup of tea") **cannot** be paraphrased as *en
kopp av te* ("marked wrong — a teacup is not made of tea") — the av-paraphrase strategy is restricted
to true material-composition compounds, not container-plus-contents compounds, a genuine semantic
gate on an otherwise productive-looking paraphrase pattern.

**Idiomatic prepositional phrases — representative sample from the alphabetized dictionary** (p.162-
179), organized by governing preposition, illustrating the density and semantic range of this
productive verb+particle system (directly comparable to English phrasal verbs and German separable-
particle verbs as a likely rich target for slang/informal derivation):
- **Av**: *være avhengig av* (be dependent on), *leve av* (live on/subsist on), *holde av* (like/be
  fond of), *låne av* (borrow from), *slå av/skru av* (turn off — two near-synonymous particle verbs),
  *gå av* (get off; **also** "retire," a semantic extension from literal alighting to career exit —
  *gått av med pensjon*), *ta av* (a highly polysemous particle verb: "take off [clothing]," "take
  off [of a plane]," "lose weight," "clear [a table]," "turn off [a road]," and *ta seg av* "take care
  of" — six distinct senses from one verb+preposition pairing, a prime example of how much semantic
  load a single particle combination can carry), *laget av* (made of), *bli lei av* (get fed up with),
  *ha godt av* (do someone good; also ironically "serve someone right" — *Det har du godt av!*), *ha
  vondt av* (feel sorry for), *slappe av* (relax/take it easy), *være medlem av* (belong to), *være
  opptatt av* (be busy with/concerned about), *komme av* (be due to/caused by), *ha inntrykk av* (have
  the impression).
- **Etter**: *høre etter* (listen carefully/listen out for), *ta etter* (copy/imitate; also "reach
  for"), *se etter* (look for; look after).
- **For**: *ha lett/vanskelig for* (find easy/difficult), *være morsomt for* (be fun for), *for en/et
  ...!* (a fixed exclamatory "what a ...!" construction), *for det første* (in the first place,
  correlating with *for det andre* "in the second place"), *ta for gitt* (take for granted).
- **Fra**: *være unntak fra* (be an exception to), *komme fra* (come from; also idiomatically "do
  [well/badly]" and "escape with [one's life]" — *komme fra det med livet i behold*), *høre fra* (hear
  from), *si fra* (let someone know/speak up), *ta fra* (take away/confiscate), *ta avstand fra*
  (dissociate oneself from), *reise fra* (travel from/leave).
- **Med**: *bry seg med* (bother with), *føle med* (sympathize with), *være kjent med* (be familiar
  with), *være fornøyd med* (be pleased with), *være sammen med* (be with; also specifically "be
  dating/going out with," a genuine register-neutral-to-romantic polysemy resolved only by context),
  *ha/ta med (seg)* (bring/take along), *være enig med* (agree with), *bli/være med* (come/go along;
  also "be part of/included"), *være ferdig med* (have finished), *gå med* (a further highly
  polysemous particle verb: "accept/agree to," "be used up/consumed" [*All maten har gått med*, "all
  the food is gone"], and "wear" [*Hva skal du gå med i kveld?*, "what are you wearing tonight?"] —
  three semantically distant senses sharing one surface form), *ta det med ro* (take it easy, a fixed
  idiom), *til og med* (up to and including/even — doubling as a discourse-emphasis particle meaning
  "even," parallel to *selv*'s adverbial use noted earlier), *hjelpe med* (help with).
- **Over**: *gå over* (pass/blow over [of weather/trouble]; cross over [a street]; check/go through
  [accounts] — three senses).
- **På**: *gå på* (go to [an institution/event]; also "keep it up/keep going" as an encouragement
  idiom), *stå på* (be switched on [of a device]; also "stick to one's guns/keep at it," the same
  idiomatic extension pattern as *gå på*), *ha penger på seg* (have money on one), *ta på* (touch;
  put on [clothing]; and idiomatically *tar på* = "wears one down/gets to you," another instance of a
  particle verb spanning a concrete-to-abstract semantic range), *vente på* (wait for), *ha lyst på*
  (want/feel like having), *høre på* (listen to), *rope på* (call/shout for), *finne på* (be up to;
  think up/invent), *komme på* (come to [a cost]; also "remember" — *Jeg kan ikke komme på hva hun
  heter*, "I can't remember her name," a genuinely non-obvious semantic extension from "arrive at" to
  "recall"), *passe på* (look after/keep an eye on), *lure på* (wonder).
- **Til**: the genitive-replacement/possessive use already detailed above (*søsteren til* "the sister
  of"), extending productively to any possessive relationship expressible with *til* + a definite noun
  phrase.

## Grammar points — Sentence Elements, Sentence Structure, and Word Order (p.180-196)

**Sentence elements** (p.180-185): the book catalogs **subject, verb phrase, complement (subject
complement, object complement, and complement in fixed set phrases, plus a looser "free complement"),
object, indirect object, and adverbial** as the clause's functional building blocks, each with a
diagnostic question for identifying it — the verb phrase by asking "what is the subject doing?", the
subject complement by "how is [the subject]?", the object complement by "how is/are [the object]?",
the object by "what/who + verb + subject?", and the indirect object by "to/for whom + verb + subject +
object?" — a systematic, pedagogically-oriented diagnostic-question method applied consistently across
every element type. The **subject complement** is required by a closed class of "dependent" copula-
like verbs that cannot stand alone (*hete* "be called," *være* "be," *kalles* "be called [passive]",
*bli* "become," *se ut* "look," *føle seg* "feel") — omitting the complement after one of these is
explicitly marked **wrong** (*Datteren hennes heter.* / *Hun er.*) — though two of these verbs, *føle
seg* and *se ut*, can stand alone in specific **idiomatic** constructions that have drifted from literal
to figurative meaning (*Han ser ikke ut!* "he looks dreadful!"; *Han føler seg nå* "now he has a high
opinion of himself" — both flagged as genuinely idiomatic/colloquial extensions worth noting for
synthesis purposes, since the idiom strips away the complement the literal construction would require).
The **object complement** agrees with the object in number/gender like an ordinary adjective (*Han
malte huset rødt* "he painted the house red" — neuter concord matching *huset*), while a **complement
in a fixed set phrase** (*være glad i, holde klar, slippe løs*) often stays uninflected regardless of
the object's gender/number, the same fixed-idiom-breaks-regular-concord pattern already seen repeatedly
elsewhere in this grammar (cf. the Adjectives-chapter concord exceptions). A **free complement** is
only loosely attached to the clause (typically a fronted descriptive phrase: *Trøtt og sliten fortsatte
han arbeidet*, "Tired and weary, he went on with the work") but still inflects for the number/gender of
the noun it describes. *(Note: printed pages 192-193 of the source — covering, per the table of
contents, the position of the direct/indirect object and the position of the reflexive pronoun within
the main-clause word-order system — are, like printed pages 127-128 noted earlier in the Pronouns
chapter, missing from this scanned PDF: the scan jumps directly from printed p.191 to printed p.194
with no intervening pages captured. A second genuine source-scan gap in this same physical copy,
flagged per the same page-verification discipline, not an extraction omission.)*

**Word order — the main-clause positional system** (p.188-192): Norwegian is a rigid **verb-second
(V2)** language, directly comparable to German, Dutch, and the other Scandinavian languages, and the
book presents it as an explicit numbered-position ("topological field") system rather than a loose set
of ordering tendencies — this is one of the most structurally load-bearing findings in the whole book
for later synthesis purposes, since V2 constrains *every* possible main-clause word order regardless of
what element is fronted. **Position 1** can be filled by the subject (the unmarked/default case) or, for
emphasis, by *any* other sentence element (an adverbial, an object, a time expression) — and crucially,
**whenever anything other than the subject fills position 1, subject-verb inversion is obligatory**,
pushing the subject to position 3 (*Trikken tar de hver dag*, "The tram they take every day," with
fronted object *Trikken* in position 1, verb *tar* in position 2, subject *de* in position 3). **Position
2 is always the finite verb** (present/past tense form) in a declarative main clause — with no
exceptions given in-source — and in a yes/no question with no interrogative word, **position 1 is
simply left empty**, so the finite verb itself opens the clause (*Kommer han snart?*, "Is he coming
soon?" — the verb-first question-formation strategy, directly parallel to German/Dutch and residually
to English auxiliary-inversion). **Position 4** is reserved for a specific closed class of short,
usually-unstressed sentence-level adverbs (*ikke, også, alltid, jo, nok, vel/da, sjelden, faktisk,
vanligvis, ofte, sikkert, gjerne* — explicitly cross-referenced to the Adverbs-chapter "Modification"
subclass already catalogued in detail above) — this fourth position is itself the Scandinavian
"sentence-adverb slot" grammarians elsewhere call the Germanic **middle field**/**negation-and-stance
particle zone**, though the book doesn't use that term; functionally it is exactly that slot, and its
existence as a dedicated structural position (not just a preference) is the clearest piece of direct
syntactic evidence in this whole grammar for treating Norwegian's discourse/stance-particle system
(*jo, nok, da, vel*, etc.) as grammatically obligatory-positioned rather than optionally insertable —
worth flagging prominently for slang-synthesis work on how hedging/stance particles might be
repositioned or omitted informally. **Adverbial phrases** (as opposed to the short position-4 adverbs)
are more flexible: they can appear in position 1 (fronted for emphasis, triggering inversion the same
as any other fronted element), after the verb, or in final position — and when **both** a place
adverbial and a time adverbial co-occur clause-finally, **the time adverbial is placed last** (*De
drikker kaffe hjemme hver dag*, "they drink coffee at home every day" — place before time is the
unmarked final-position ordering). A further rule interacting with position 4: **when the subject is a
full noun phrase or proper name (not a pronoun), the adverbial is placed in front of the subject (i.e.
in position 3), not after it** (*Her vil nok Marie bo*, "Marie will no doubt want to live here" — adverb
*nok* precedes the nominal subject *Marie*) — a genuine noun-vs-pronoun-subject word-order split layered
on top of the base V2 system, not just free stylistic variation.

**Subordinate clauses — a more rigid, non-inverted positional system** (p.193-194): subordinate clauses
follow their **own** fixed template, structurally distinct from the main-clause V2 system above —
**position 1**: the conjunction/relative pronoun/interrogative introducing the clause (sometimes
omissible, per the Conjunctions and Relative-pronouns chapters' own omission rules already detailed);
**position 2**: the subject (no inversion — unlike a fronted main clause, a subordinate clause never
triggers subject-verb inversion, a sharp and absolute split between the two clause types); **position
3**: the adverbial phrase, including specifically the position-4-style short adverbs (*ikke, nok*, etc.)
which **shift one slot earlier** in a subordinate clause compared to their main-clause position —
directly parallel to the German *nicht*-placement shift between main and subordinate clauses, and a
genuinely classic diagnostic of V2-vs-non-V2 clause typology; **position 4**: the entire verb phrase,
as a single block (not split the way a main clause's finite-verb-then-rest can be). **Relative
clause-vs-main-clause ordering**: when a subordinate clause (temporal, conditional, concessive, or an
embedded question/*at*-clause) **precedes** its main clause, the main clause's finite verb is pushed to
open position (**obligatory inversion**, mnemonic given in-source: "imagine the whole subordinate
clause occupies position 1 of the main clause" — directly consistent with the general V2 fronting rule
already described, since the entire preceding subordinate clause counts as a single fronted
constituent); when the main clause **precedes** the subordinate clause instead, **there is no word-
order change at all** in either clause — the asymmetry (preceding-subordinate-clause triggers
inversion; following-subordinate-clause doesn't) is a direct, mechanical consequence of V2 being a
"second position" rule counted from the start of the whole sentence, not from each individual clause.
A further variant: embedded questions follow the normal subordinate-clause template, with the original
question's interrogative word simply relocating to subordinate-clause position 1 and losing its own
inversion (*Hvor bor du?* "where do you live?" → *Han spør hvor du bor*, "he's asking where you live" —
no inversion inside the embedded clause, confirming it's patterning as an ordinary subordinate clause
once embedded, not retaining question-word-order).

**Rules for commas** (p.195-196) — eight numbered obligatory-comma contexts, several of which are
directly downstream of the word-order rules above rather than arbitrary punctuation convention: (1)
**obligatory** when a subordinate clause precedes a main clause (directly correlating with the
obligatory-inversion rule just described — the comma marks exactly the boundary that triggers
inversion); (2) when a main clause is followed by a **non-restrictive** subordinate clause functioning
as a parenthetical aside (*Hun snakket med foreldrene sine, som nettopp hadde kommet hjem fra ferie*);
(3) when a subordinate clause functions as an appositive (*Hun ville be Kari, som er fire år, til
fødselsdagen sin* — note a subordinate clause **inserted inside** a main clause takes a comma only
**after** it, never before, an asymmetric bracketing rule explicitly flagged with a worked example,
*Hansen som står der, er seksti år i dag*); (4) with ordinary (non-clausal) appositives (*Katrine, vår
yngste datter, er veldig glad i katter*); (5) in enumeration/lists; (6) between two main clauses joined
by a coordinating conjunction (*og, eller, for, men*) — **except** when both joined clauses are very
short, where the comma is conventionally dropped (*Barna sov og foreldrene arbeidet*, no comma); (7)
after mild interjections, discourse responses, and terms of address (*Uff, så kaldt der er!*; *Ja, nå
går det bra*; *Kari, kom hit!* — directly reusing the Interjections-chapter vocabulary catalogued
earlier, now shown in its actual punctuation context); (8) following direct speech (Norwegian uses
guillemets «...» for quotation marks, visible throughout this chapter's own examples, rather than the
English double-quote convention).
