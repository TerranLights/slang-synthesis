# Norwegian — Established Vocabulary/Grammar: Linguaphone Norwegian Course — Kurs + Handbook (Part 1 of 4)

**Source.** The Linguaphone Institute, *Norwegian Course* (Kurs, Norwegian-only lesson/dialogue text) and
*Norwegian Course Handbook* (Instructions, Vocabularies, Explanatory notes; 1st published 1964, 3rd
revised edition 1986; English-medium, written for English-speaking learners). Extracted as a matched
pair per dispatch instructions: the Kurs supplies the Norwegian lesson text itself, the Handbook
supplies the English-medium vocabulary lists and grammar/usage notes keyed to the same lesson (Leksjon)
numbers. This file (Part 1 of 4) covers the Handbook's "Vocabularies and text of sounds section"
(contents p.15), **Innledning (Introduction) through Leksjon 17** — Handbook pp.26–37.

**Confirmed vision-only.** Neither PDF has an embedded text layer (`pdffonts` returns zero fonts on
both; `pdftotext` yields exactly one char per PDF page = blank form-feed). Both rendered via
`pdftoppm -r 120 -png` and read visually. **Scan is two-printed-pages-per-image spreads** (confirmed:
PDF page 3 of the Handbook shows printed pages 26–27), consistent with this project's known spread-scan
gotcha — page-range estimates below are from direct inspection of the printed page numbers, not
arithmetic offset. No handwritten marginalia was found on any page read for this file; all content
is typeset print.

**Non-redundant-supplement scoping (applies to all 4 parts of this file).** This project already has
comprehensive Norwegian grammar coverage from `001_norwegian_verbs_and_essentials_of_grammar.md` and
`002_practical_norwegian_grammar.md` (alphabet/IPA/pronunciation, all verb tenses, nouns incl. the
3-gender common/feminine/neuter system, all pronoun classes, adjectives, adverbs incl. modal
particles *jo/nok/da/visst/vel*, word order incl. inversion/adverb-placement rules, numerals, and
more — see those files' own headers for full scope) and from `003_phonology_of_norwegian.md`
(including Tone I/Tone II pitch-accent). Spot-checks across this Handbook's "Explanatory notes"
(pp.73–188) and "Appendix: Outline of Norwegian Grammar" (pp.189–222) confirmed these sections mostly
re-teach the same systematic grammar points already captured (verb present tense, imperative,
negation placement, noun plural classes, 3-gender declension, compound-verb separable/inseparable
prefixes, sentence-modifier particles, inversion/word-order rules) — **these are NOT re-tabulated
here.** What IS extracted (across Parts 1–3: the full lesson-by-lesson vocabulary; Part 4: a curated
set of idiom/register/usage-note findings that are genuinely new, not systematic-grammar restatement)
is the course's real point of distinctiveness versus the two existing reference grammars: dense,
everyday-situation vocabulary tied to realistic dialogue scenarios (dense word count was 4-5x the
grammar references for topics like household items, meals, shopping, travel, trades/occupations), plus
scattered idiom and register notes including an explicit "colloquial" tag and a "touch of slang" tag
(see Part 4). The Handbook's own "Notes on Pronunciation" (IPA phoneme-by-phoneme word lists,
pp.62–72 within the vocab-section page range) is likewise skipped as redundant with
`003_phonology_of_norwegian.md`, which already covers the full vowel/consonant/diphthong inventory and
the Tone I/II pitch-accent system in more systematic detail.

**Register note.** Every dialogue sampled across this course uses the formal pronoun **De** (never the
informal **du**) in the practical lesson dialogues — **du** appears only in the two literary poem texts
captured in Part 3. This is consistent with the course's original 1964 publication date (predating
Norway's broad du-reform of public address) and is itself a register data point: this course models an
older, more formal default register than most of this project's other Norwegian sources.
