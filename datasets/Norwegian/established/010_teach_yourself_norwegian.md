# Norwegian — Established Vocabulary/Grammar: Teach Yourself Norwegian (Part 1 of 3 — Introduction, Pronunciation, Units 1–6, pp. 1–87)

**Source:** Margaretha Danbolt Simons, *Teach Yourself Norwegian* (Teach Yourself Books; first published UK 1997 by Hodder & Stoughton, London; first published US 1997 by NTC Publishing Group, Lincolnwood, Illinois; this physical copy's impression numbers run 2000–2004; Library of Congress Catalog Card Number 96-68476). Course textbook covering 16 narrative units following two central characters, John (English) and Bente (Norwegian), plus front-matter Pronunciation chapter, back-matter Grammar appendix, and Norwegian–English Vocabulary. This part covers the Introduction, Pronunciation chapter, and Units 1–6 (pp. 1–87). Parts 2 and 3 (`010b_...md`, `010c_...md`) cover the rest of the book.

**Non-redundant-supplement scoping (checked against existing Norwegian `established/` files before extraction):** this project already has comprehensive Norwegian grammar coverage from `001_norwegian_verbs_and_essentials_of_grammar.md` (full verb-paradigm appendix, ~225 verbs, plus core grammar chs. 1–25), `002_practical_norwegian_grammar.md` (systematic case-by-case grammar reference), and `003_phonology_of_norwegian.md` (vowel/consonant inventories, stress, tonal accents, orthography-phonology correspondence). Accordingly:
- **The Pronunciation chapter (pp. 4–9)** — alphabet letter names, vowel/consonant length rules, diphthongs, silent consonants, stress, and the two-tone pitch-accent system — is **skipped as grammar content**: 001 already tabulates the full alphabet with IPA, and 003 already covers vowel length/gemination, consonant inventory, stress assignment, and tonal accents comprehensively and in more depth. This book's treatment is a strict subset with no new rule or exception found. The handful of single-word pronunciation examples in this chapter (e.g. *hat/hatt*, *rom*, *hjem*, *tak/takk*) are pedagogical minimal pairs illustrating rules already captured, not an independent vocabulary list the book itself presents as such (no Ordliste box), so they are not re-tabulated as vocabulary either.
- **Core sentence-grammar explanations already fully covered by 001/002** (personal pronouns, the en/et/(ei) three-gender system and indefinite article, basic present-tense -r rule, simple statement/question/negative word order, adjective agreement with en/et-word + definite/indefinite + singular/plural) are paraphrased only briefly below, not re-tabulated in full — 001 and 002 already give fuller, more systematic paradigm tables for all of these.
- **Kept as genuinely new/deeper:** the book's own pedagogical adjective-agreement worked table (Unit 3–4, a 4-column indefinite/definite × singular/plural layout not given in exactly this form elsewhere), the **liten** (small) irregular-adjective full paradigm, the **her/der vs. hit/dit** stationary-vs-movement adverb-pair explanation, the relative pronoun **som**, and all vocabulary (per the coverage rule, vocabulary is never treated as redundant across books).
- **Vocabulary is extracted comprehensively and completely**, per-unit, from every Ordliste (vocabulary box) in this part of the book, regardless of grammar-topic overlap.

**Vision-reading guard:** this source has no text layer (confirmed via `pdftotext`, which produced only placeholder/near-empty output across all 129 pages) and was entirely vision-read from page images rendered at 150 DPI. **The PDF's 129 physical pages are two-printed-page spreads, not one page per image.** The spread offset was verified empirically by reading the printed page numbers in each image's footer (not assumed from a fixed arithmetic formula): PDF pages 1–2 are unnumbered front matter (title page, acknowledgements, contents); from PDF page 3 onward the mapping is consistently *left printed page = 2×(PDF page) − 6*, *right printed page = 2×(PDF page) − 5* (verified against directly-read footer numbers at multiple checkpoints spanning the whole book, e.g. PDF p.5→printed 4/5, PDF p.8→10/11, PDF p.60→114/115, PDF p.90→174/175, PDF p.120→234/235). No non-monotonic page ordering was found. **No handwritten marginalia was found anywhere in this book** — this appears to be an unused/clean copy; all pages inspected show only consistent printed typeset content. (One stylistic note: the informal letter in Unit 12, Tekst 5, is deliberately printed in a cursive/handwriting-style typeface to represent an in-story casual letter — this is the book's own typeset design choice, not a reader's handwritten annotation, confirmed by its consistent font rendering and its own "Tekst 5" printed header.)

## Grammar points

### Nationalities and adjectives ending in -ig (Unit 2, p.28)

Adjectives for nationalities (e.g. **norsk**, **engelsk**) and adjectives ending in **-ig** (e.g. **kjedelig**) take no added **-t** ending with et-words, unlike regular adjectives. Cf. 001/002 for the general et-word **-t** rule; this is the book's list of named exceptions to it.

### Liten (small) — full irregular paradigm (Unit 3, p.42–43)

**Liten** is flagged as a notably irregular adjective. Full four-form paradigm given: indefinite en-word **liten** (en liten bil), indefinite et-word **lite** (et lite glass), definite singular **lille** (den lille bilen / det lille glasset), plural (both definite and indefinite) **små** (mange små biler / de små bilene). This is a fuller four-way paradigm than a simple en/et/plural note would give — worth capturing because the stem changes completely across forms (liten → lite → lille → små), unlike a regular adjective's simple ending alternation.

### Relative pronoun som (Unit 3, p.41)

The relative pronoun **som** ("who/which/that") is used identically regardless of whether the antecedent is a person, animal, or object — no gender/case distinction, unlike English's who/which split. Example: *Trikken som går til Frognerparken, er stor* ("The tram which goes to the Frogner Park is big").

### her/der vs. hit/dit — stationary vs. movement adverb pairs (Unit 4, p.57; reinforced Unit 6 p.83)

Norwegian distinguishes location from direction with two separate adverb sets: **her** (here, stationary) / **hit** (to here, movement) and **der** (there, stationary) / **dit** (to there, movement). The book extends this into a small closed paradigm in Unit 6: **opp/oppe** (up/upstairs), **ned/nede** (down/downstairs), **ut/ute** (out/outside), **inn/inne** (in/inside), **hjem/hjemme** (home/at home) — each pair's first member marks movement toward, the second a static location. English collapses this distinction (e.g. "home" serves both "I'm going home" and "I'm at home"), so this is a genuine structural point for a conlang borrowing or avoiding this mechanism.

### The archaic ones-before-tens counting system (Unit 6, p.73)

Alongside the modern tens-before-ones numeral system (tjueen = "twenty-one"), there survives a fully parallel archaic system built on **tyve** (20) and **tredve** (30) instead of **tjue**/**tretti**, which — if used at all — requires switching to a German-style "ones conjunction tens" order throughout: *en og tyve* ("one and twenty" = 21), *to og tyve* ("two and twenty" = 22). The book explicitly warns that a speaker who starts with tyve/tredve must stay consistent with this inverted counting convention for the whole number, rather than mixing it with the modern tjue/tretti-based ordering.
