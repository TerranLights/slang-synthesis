## Cross-dialect comparison trio — read this note first

This file is one of three coded **consistently** so the same concept can be compared across Spain,
Mexico, and Latin America at a glance:
- **039** — The Rough Guide Spanish Phrasebook → Spain
- **040 (this file)** — The Rough Guide Mexican Spanish Phrasebook → Mexico
- **041** — The Rough Guide Latin American Spanish Phrasebook → pan-regional Latin America, with
  internal country tagging (Arg, Mex, Col, Rpl, Ven, Ch, Pe, Cu, CAm, etc.)

Shared-concept rows carry a parallel entry in the sibling file(s), cross-referenced by file number
in the Notes column. The headline contrasts (full table given in 039; repeated here for this file's
own standalone reference):

| Concept | Spain (039) | Mexico (this file) | Latin America (041) |
|---|---|---|---|
| "swearword" (the noun) | palabrota | **grosería** | grosería |
| answering the phone | ¿Dígame?/¿Diga? | **¿Bueno?** ("good") | ¿Aló? (SAm) / bueno elsewhere |
| "to fuck" (taboo) | *not this verb* — coger = neutral "to catch/take" | **coger = taboo "to fuck"** | coger = taboo "to fuck" (same as Mexico) |
| flagship taboo "to fuck" verb | joder (excl. "fuck!") | **chingar** (flagship, highly productive family of derivatives) | chingar *and* tirar both attested |
| "zero" pronunciation | cero [thairo] (distinción) | cero **[sairo]** (seseo) | cero [sairo] (seseo) |
| 2nd-person plural | vosotros (fam) vs ustedes (pol) | **ustedes only** — no vosotros, no fam/pol plural split | ustedes generally; vos (voseo) productive in Rpl/CAm zone, see 002 |

The most important single contrast this book supplies is the **chingar word-family**: Mexican
Spanish builds an entire productive derivational cluster around this one taboo root (chingar "to
fuck", ¡chinga tu madre! "fuck off!", ¡qué chingadera! "what a fuck-up!", un chingo de "loads of",
plus the elsewhere-attested chingada/chingón forms) in a way that has no single-root equivalent in
either the Spain or Latin America lists extracted here — this is a `morphological_play` /
`taboo_inversion` goldmine for this project's slang-mechanics analysis.

**Non-redundant-supplement note:** As with 039, this project's general grammar corpus (001-015)
already covers the standard tú/usted/ustedes paradigm, so this file does not re-teach it — it only
flags that Mexican Spanish (like most of Spanish America) collapses the plural familiar/polite
distinction that Spain keeps (vosotros vs ustedes). Core basic numbers/dates/everyday A-Z vocabulary
already well covered elsewhere is skipped; the focus here is the "Colloquial Spanish" slang list
and Mexico-specific lexical items with no Spain equivalent.
