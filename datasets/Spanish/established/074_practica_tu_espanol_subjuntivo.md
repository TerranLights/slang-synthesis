# Spanish — Established Vocabulary/Grammar: Practica Tu Español — El Subjuntivo (full book)

**Source:** Inmaculada Molina, *Practica Tu Español: El Subjuntivo* (B1 level), Sociedad General
Española de Librería (SGEL), Madrid, 1st edition 2006. Full book: Presentación (p.5), Unidad 0
"El modo subjuntivo" (pp. 6–11, conjugation of the four subjunctive tenses and their
correspondences with indicative tenses), Unidades 1–9 (pp. 12–73, one subjunctive function per
unit, each with theory boxes and practice exercises), Unidad 10 "Revisión" (pp. 74–81, review
unit, no new grammar), and Solucionario/answer key (pp. 82–88). This source has **no text layer**
(`pdftotext` returns only newline characters per page — confirmed empty) despite the triage
listing it as vision-required; the triage classification is accurate. All 45 PDF pages (each a
two-page book spread, totalling 88 printed pages) were read via vision.

**Coverage note:** This is a self-study workbook devoted entirely to the Spanish subjunctive mood
— every "unit" is one subjunctive function/trigger-category (wishes, defining relative clauses,
reactions, temporal clauses, finality, hypothesis, condition, reported commands). Per this
project's non-redundant-supplement convention, the basic present-subjunctive conjugation
paradigm (regular verbs, -ar/-er/-ir endings) already established in `established/008_...` and
`007_...` is **not** re-tabulated here; this file focuses on what those verb-tense books do not
cover in comparable depth: the full set of **trigger expressions/particles that require the
subjunctive** (and the indicative-requiring counterparts that contrast with them), the formation
of the two subjunctive past tenses (imperfecto and pluscuamperfecto, including the -ra/-se
interchangeable endings), and real example sentences showing each trigger in context. Exercise
answer-key content (Solucionario) was reviewed but not separately tabulated — it restates forms
already captured from the theory boxes and exercise prompts, per the coverage rule's "repeated
drill" exclusion; a few free-answer ("Respuesta libre") example sentences from the Solucionario
that illustrate additional natural trigger usage are folded into the Notes of the relevant trigger
row instead of given their own entries.

**Dialect note (applies to the whole file unless stated otherwise):** Peninsular Spanish — the
book consistently uses `vosotros/vosotras` as the informal second-person plural (contrasted with
`ustedes` for formal), which is the Spain-specific paradigm; Latin American Spanish collapses this
to `ustedes` for both registers. Set as **Attested Region** = "Spain (Peninsular; vosotros forms
used throughout)" for all rows below unless noted otherwise. **Attested Era** = "contemporary
(source published 2006)" for all rows. **Geographic Scope** = "—" (not further specified beyond
Peninsular Spanish) for all rows. **Source Type** = `grammar_reference`, **Transcription
Confidence** = `n/a` (vision-read, no text layer), **Vision Reading Confidence** = `high` (clean
scanned textbook, legible typeset text throughout) for all rows unless noted otherwise.

**Relationship to other Spanish `established/` files:** This is the fullest treatment in the
Spanish corpus of subjunctive *trigger expressions* specifically (as opposed to conjugation
morphology, covered in 007/008, or scattered mentions of "uses of the subjunctive" in general

When the main verb decir is in present tense + subjunctive clause, the construction can take on the force of a command/order (not just a report): "-Fernando, ¿me oyes? ¡Te digo que salgas de una vez!" A colloquial variant elides the main verb entirely, leaving just "¡Que salgas de una vez!" If decir is in conditional, the same formula instead signals a softened recommendation: "-Yo te diría que pidieras una entrevista personal con él." If decir is in the past, the construction functions as reported insistence on something already said: "-Os digo que no tengo ni idea..." |
