# Spanish — Established Vocabulary/Grammar: Tiempo para practicar el Indicativo y el Subjuntivo (non-redundant supplement)

**Source:** Mª Pilar Hernández Mercedes, *Tiempo para practicar el Indicativo y el Subjuntivo*
(colección tiempo, Español Lengua Extranjera, Edelsa/Grupo Didascalia), 167 pages. Full structure:
Presentación; Tema 1 "Morfología de los tiempos del subjuntivo" (pp. 5–28: present, present-perfect,
imperfect, pluperfect subjunctive conjugation drills); Tema 2 "Oraciones independientes" (pp.
29–42: expressing wishes, expressing doubt/probability); Tema 3 "Oraciones sustantivas" (pp. 43–72:
expressing opinion/communication, influence/feelings/wishes, constataciones y juicios de valor);
Tema 4 "Oraciones relativas" (pp. 73–85: referring to people/things/ideas, referring to place/time/
manner); Tema 5 "Oraciones adverbiales" (pp. 86–151: expressing time, finality, **cause**,
conditions I–II, **consequence**, **objection/difficulty**); Correlación de tiempos (p. 152);
Equivalencias temporales entre el modo Indicativo y el Subjuntivo (p. 155); Claves/answer key
(pp. 156–167). This source has **no text layer** (`pdftotext` returns only newline characters per
page — confirmed empty) despite being a very large file (93MB for 167 pages, high-resolution page
scans); the triage's vision-required classification is accurate. Pages were sampled via vision
rather than read exhaustively (see coverage decision below) given the book's extremely
drill-dense, low-prose structure.

**Coverage decision (non-redundant supplement, partial/sampled extraction):** This book's Tema 1
(subjunctive tense morphology) and much of Temas 2–4 (independent-clause wishes, doubt/
probability triggers, opinion/communication verbs, relative clauses) substantially duplicate
ground already established in `established/074_...` and `075_...`; those sections were visually
sampled to confirm redundancy and then **not** re-tabulated, except where this source adds a
genuinely sharper or additional rule (noted inline below). Given the scale of this book (167 pages
of near-pure drill material) and the overlap with already-extracted sources, **this file does not
claim exhaustive page-by-page coverage** — it captures the clause types and trigger-expression
sets that are new to this project's Spanish corpus, principally **Tema 5's causal, consequential,
and objection/difficulty ("concessive") clause systems**, none of which existed in the corpus
before this file, plus refinements to the already-covered doubt/probability, conditional, and
finality systems. The "PARA PRACTICAR," "PARA CONSOLIDAR," and "PARA HABLAR O ESCRIBIR" drill
sections throughout were reviewed but not tabulated (repeated-drill content per the coverage
rule); only the "Esquema"/"Regla"/"Para saber más" theory-box content is captured as vocabulary/
grammar rows.

**Relationship to other Spanish `established/` files:** This book organizes subjunctive usage by
syntactic clause type (independent / sustantiva / relativa / adverbial) rather than by communicative
function as `established/074_...` does — a genuinely different organizing scheme that happens to
converge on similar trigger-expression territory for wishes, opinion, feeling, and condition, but
diverges sharply by adding **causal clauses, consequential (result) clauses, and a much larger
concessive/objection-clause inventory** than any other Spanish `established/` file to date. The
concessive ("objeción o dificultad") system here should be read as the fuller counterpart to
`established/075_...`'s aunque-only treatment (Brodsky's book) — this source adds aun cuando, por
más que, aun a riesgo de que, por mucho/poco/nada que, por muy + adj/adv + que, así, mal que, y
mira que, none of which appear in 075. This file is also meant to be read alongside
`established/074_...` for subjunctive practice books specifically, per that file's cross-reference
note — both are B1-ish self-study workbooks on the same topic from different Spanish publishers
(SGEL vs. Edelsa), and the two converge closely on ojalá, puede que, and the si-conditional system
while diverging on causal/consequential/concessive coverage (present here, absent there) and on
exercise framing (this book favors terse rule-boxes; 074 favors longer narrated examples and
dialogue-style exercises).

**Dialect/register note (applies throughout unless stated otherwise):** Peninsular Spanish,
register-aware — this source is unusual among the Spanish corpus's grammar references for
systematically labeling individual trigger expressions by register (de uso culto / de uso coloquial
/ propio del lenguaje administrativo / de la expresión oral no formal, etc.), captured in the Notes
field below wherever given. **Attested Era** = "contemporary (source undated in extracted range;
Edelsa colección tiempo, ELE)"; **Attested Region** = "Spain (Peninsular)"; **Geographic Scope** =
`—`; **Source Type** = `grammar_reference`; **Transcription Confidence** = `n/a` (vision-read, no
text layer); **Vision Reading Confidence** = `high` (clean scanned textbook, legible typeset text
throughout) — held constant for all rows below unless a row overrides them.
