## Grammar points

### *Le/les* used as the direct object pronoun for "you" (formal)

Since Spanish has no dedicated direct object pronoun distinct from **lo/la/los/las** for the formal
"you," this book directly instructs using **le** (singular) and **les** (plural) in that slot:
**Quiero ayudarle** = "I want to help you (sing.)," **Quiero ayudarles** = "I want to help you
(pl.)" (p. 188), alongside the ordinary **lo/la/los/las** ("him/her/them"). This is worth flagging
for cross-source comparison: using **le** where a direct object pronoun would normally be **lo** is
the defining feature of **leísmo**, a well-documented regional variation in Spanish (especially
Iberian, for personal masculine direct objects) that some grammars treat as a marked regionalism
rather than the neutral default this book presents it as. No other established Spanish source
sampled so far in this project has been checked against this specific point — worth a targeted
comparison during mechanics-analysis if leísmo/loísmo variation becomes relevant to the register
work.

### Conjunction *y* → *e* before /i/-initial words

Spanish **y** ("and") is replaced by **e** immediately before any word beginning with **i** or **hi**
(but not **hie**, e.g. *y hielo* is unaffected — not stated explicitly by the book but the standard
rule), purely to avoid the vowel collision /i.i/: this parallels the already-documented **o → u**
rule before /o/-initial words in some other established sources. (p. 192, brief note only, not
elaborated by the source beyond the rule statement itself.)
