## Grammar points

### Futuro hipotético perfecto — continued review, no new tense (Lección 66)

Lección 66 is a pure review/vocabulary-expansion lesson within the future-perfect arc begun in
Lecciones 61–65 (p.1–6): no new grammatical structure, only additional `-ir`-class vocabulary drilled
into the same `habrá + past participle` frame established earlier.

### Condicional perfecto (conditional perfect), -ar verbs — Lección 67 (second half) / 68

Paraphrase: mid-way through Lección 67, the course pivots to a new tense — the "condicional perfecto"
(conditional perfect), formed with the conditional of `haber` (habría/habrías/habría/habríamos/
habrían) + past participle, expressing "would have done X." Introduced via a new Carlos/Catalina
dialogue about a co-worker's alcohol problem, drilled first with `-ar` verbs (`habría tomado`, `habrían
cantado`, `habría llegado`, `habría regañado`, `habría regresado`). Lección 68 continues the same tense
and same `-ar` verb set, adding vocabulary about explaining feelings.

### Condicional perfecto, -er verbs — Lección 70

New verb class for the same tense: `-er` verbs (`habrías comido`, `habría entendido`, `habría temido`).
Thematic vocabulary shifts to food/restaurants (new Tomás/María dialogue).

### Compound counterfactual: condicional perfecto + pluscuamperfecto de subjuntivo ("si hubiera + participio, habría + participio") — Lección 71 onward

From Lección 71 on, the course combines the conditional perfect main clause with a **past-perfect
subjunctive** `si`-clause (`si hubiera/hubieras/hubiéramos/hubieran + past participle`) to build full
past counterfactuals: "Habríamos comido... si hubiéramos llegado más temprano" ("We would have eaten...
if we had arrived earlier"). This is the first lesson in the Level III set that explicitly practices the
two-clause counterfactual structure rather than the conditional-perfect clause alone. The pattern recurs
through Lecciones 72–75 with new vocabulary (cooking, selling, drinking, shopping) layered onto the same
structure each time.
