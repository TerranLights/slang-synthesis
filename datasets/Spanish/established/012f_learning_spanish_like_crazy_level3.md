## Grammar points

### The "-ón/-ona" augmentative suffix for physical description (Bonus Lesson C)

Paraphrase: this lesson demonstrates a productive derivational pattern — appending `-ón` (masculine) /
`-ona` (feminine) to a body-part noun creates an adjective meaning "big-[body part]" or "[body-part]-y,"
used with `ser` to describe someone's physical trait as a lasting characteristic (as opposed to `estar`
for a temporary state). Confirmed across eight parallel derivations in this lesson alone:

> **cachetón/cachetona** = cachete ("cheek") + -ón/-ona — "big-cheeked"
> **cabezón/cabezona** = cabeza ("head") + -ón/-ona — "big-headed"
> **narizón/narizona** = nariz ("nose") + -ón/-ona — "big-nosed"
> **piernón/piernona** = pierna ("leg") + -ón/-ona — "big-legged"
> **ojón/ojona** = ojo ("eye") + -ón/-ona — "big-eyed"
> **orejón/orejona** = oreja ("ear") + -ón/-ona — "big-eared"
> **bocón/bocona** = boca ("mouth") + -ón/-ona — "big-mouthed" (also carries a figurative "loud-mouthed/
>   blabbermouth" sense in general colloquial Spanish, though this lesson only teaches the literal sense)
> **patón/patona** = pata ("foot," lit. an animal's foot) + -ón/-ona — "big-footed"
> **tetona** = teta ("breast," informal/vulgar) + -ona — "big-breasted" (no unmarked masculine form given,
>   since the base noun is itself gendered to female anatomy)
> **caderón/caderona** = cadera ("hip") + -ón/-ona — "big-hipped"
> **culona** = culo ("buttocks," informal/vulgar) + -ona — "big-buttocked"

This is a clean, repeated example of Spanish's fusional derivational morphology building a whole
semantic category (physical-trait adjectives) from a single productive suffix pattern — directly relevant
to this language's "fusional (inflectional)" typology profile noted in `00_Extraction_Checklist.md`, and
a plausible model for a derivational slang-formation mechanism in the synthesis phase.
