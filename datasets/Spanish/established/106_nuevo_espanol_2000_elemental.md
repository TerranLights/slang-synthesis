# Spanish — Established Vocabulary/Grammar: *Nuevo Español 2000: Nivel Elemental*

**Source:** Nieves García Fernández and Jesús Sánchez Lobato, *Nuevo Español 2000: Nivel Elemental*
(Sociedad General Española de Librería, S.A. / SGEL Educación, Alcobendas, Madrid; 5th edition,
corrected and expanded, 2007; first edition 1981). 278-page PDF, confirmed **no text layer at all**
(`pdftotext` returns empty across sampled pages) — vision-required classification from the triage
is correct. This is the companion elementary-level volume to *Español 2000: Nivel Medio*, already
extracted in Wave 4 as `091_espanol_2000_nivel_medio.md` — same author pair, same publisher, same
"Documentos" cultural-sidebar format per lesson, confirmed via the copyright page.

**Companion-volume relationship to 091:** structurally identical course design — 23 numbered
lessons (vs. 091's 21), each pairing a tight grammar focus with a page-length full-color
"Documentos" cultural/visual sidebar, plus periodic "Test de evaluación" review sections. Where 091
(Nivel Medio) picks up at imperfecto/indefinido contrast and runs through the full subjunctive
system, this Elemental volume starts from absolute scratch: ser, estar, present-tense regulars
and irregulars, demonstratives, possessives, imperative, comparatives, and only reaches the
preterite/imperfect/perfect/pluscuamperfecto/futuro system and a first taste of the present
subjunctive (lesson 23, the final lesson) by the end of the book. **The grammar progression itself
is almost entirely redundant** with this corpus's extensive existing beginner-grammar cluster
(001-022, 060-068) and was not re-extracted. What is genuinely distinctive — and not duplicated by
091, since 091's own Documentos sampling covered different lessons/topics entirely — is this
book's own set of Documentos cultural sidebars, sampled below.

**Coverage approach:** full table of contents read (all 23 lessons mapped), plus five Documentos
sidebars vision-read in full: Lesson 5 (colors' cultural connotations + gift-giving customs),
Lesson 7 (hypocoristic/affectionate name forms), Lesson 8 (Spanish meal schedule + a 20-country
Latin American "typical dish" table), and Lesson 9 (mobile phones/Internet vocabulary, incl. one
neologism). This is representative sampling of a 278-page, 23-lesson book, not exhaustive —
consistent with this wave's scope guidance given the heavy grammar-content overlap with 091 and
this corpus's broader existing beginner material.
