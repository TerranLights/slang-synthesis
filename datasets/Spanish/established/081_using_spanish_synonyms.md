# Spanish — Established Vocabulary: Using Spanish Synonyms (Batchelor, 2nd ed.)

**Source:** R. E. Batchelor, *Using Spanish Synonyms*, 2nd edition (Cambridge University Press,
2006), 753 pp. Clean text-layer PDF (`pdftotext`/`pdftotext -layout` cross-checked, no vision
reading needed). Organized as ~750 alphabetically-ordered "semantic frames," each built around a
neutral frame-title word (e.g. *abogado* "lawyer") with its synonyms grouped and explicitly
register-tagged by the author: **R3** = high formality, **R2** = neutral, **R1** = colloquial,
**R1\*** = vulgar/taboo (to be used with care), with transitional tags like R3-2 or R2-1 for items
sitting between two levels. Many entries also carry a letter tag for regional variety: **A** =
Argentinian, **M** = Mexican (the 2nd edition's major addition over the 1st). This register+region
tagging system maps directly onto this project's own Usage-Tier taxonomy (R3→`formal`, R2→`core`,
R1→`colloquial`, R1\*→`taboo`), making this book an unusually clean, author-curated register map —
exactly the kind of formal-vs-colloquial-near-synonym data this project's taxonomy work needs.

**Coverage decision: REPRESENTATIVE SAMPLING, as directed.** At 753 pages (~750 frames, averaging
~10 synonyms each, worst case ~5,000+ individual entries), full extraction is infeasible and would
be mostly redundant with general-vocabulary sources already in this corpus. This file samples
**complete semantic frames** (every synonym within the frame, preserving the register ladder
intact, rather than cherry-picking individual words out of context) rather than partial frames,
since the register *contrast within a frame* — not any single word — is the valuable unit here.
Frames were chosen by scanning across the full alphabet (sampled roughly every 50 pages from p.9
to p.600, i.e. across the full A-Z range) and selecting those with (a) the widest register spread
(ideally R3 through R1\*), (b) explicit Argentinian/Mexican regional entries, and/or (c) a taboo/
vulgar item whose register-marking itself is a finding (e.g. *concha* flagged as vulgar only in
Argentina, independently confirming the same regional taboo flagged in this corpus's `079` file
from an unrelated source — a genuine cross-source convergent finding). Frames with a flat, single-
register word list (no real register contrast) were skipped as lower-value for this project's
register-mapping purpose.

22 semantic frames are sampled below, spanning the alphabet: *abogado* (lawyer), *bajo* (low/vile),
*causa*/chance-adverbials, *chacha* (maid), *crisis* (medical-emergency euphemism ladder),
*cruce* (crossroads/traffic-circle regionalisms), *dificil*/*dificultad* (difficult/difficulty),
*envoltura*/*envase* (wrapping/container, blanket regionalisms), *glotón* (greedy), *golfo* (bay —
the *concha* taboo collision), *golpe* (blow/punch), *ley* (law), *olor* (smell — a stench-insult
euphemism chain), *prudente* (prudent), *sociedad* (society/club), *sombrero* (hat regionalisms),
*wáter* (toilet — a full euphemism register ladder).

Source Type throughout: `grammar_reference`. Transcription Confidence: `verified` (clean digital
text layer; a handful of OCR ligature artifacts — "dı́a" for "día," "fı́sica"-style accent-rendering
noise — normalized to standard orthography during extraction). Vision Reading Confidence: `n/a`.
Attested Era: `contemporary (source published 2006)` throughout. Attested Region: `—` unless the
book explicitly tags a regional restriction (A = Argentina, M = Mexico); Geographic Scope follows
accordingly. **Weight/Frequency note:** the book does not give explicit frequency counts — its
register letter (R3/R2/R1/R1\*) measures formality, not raw frequency — so the Weight/Frequency
column below is this extractor's reasonable inference (R2 items generally `high`, R3/R1 generally
`medium`, R1\* generally `low`), not a value stated by the source; this is flagged in each row's
Notes as "register-inferred."

## Copyright discipline reminder

This file samples complete semantic frames (register-tagged synonym sets) from a single
copyrighted reference work, following this project's established representative-sampling and
non-redundant-supplement conventions. Given the book's scale (~750 frames across 753 pages), only
22 frames, chosen for the breadth and interest of their register/regional contrasts, are
reproduced here, not the book's full content. No exercise content or extended prose beyond brief
usage notes is reproduced.
