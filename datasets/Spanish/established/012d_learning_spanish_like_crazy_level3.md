## Grammar points

### Presente perfecto de subjuntivo — continued (Lección 66)

Continues the same tense from `012c`'s Lecciones 63–65, now with the subjunctive trigger `aunque`
("although/even though") introducing a subjunctive clause (`aunque hayamos perdido los boletos` —
"although we may have lost the tickets"), plus more circus vocabulary.

### Imperfecto de subjuntivo (imperfect/past subjunctive), household vocabulary — Lecciones 67–68

Paraphrase: a new tense, the imperfect subjunctive, formed by taking the third-person plural preterit,
dropping `-ron`, and adding `-ra` endings (`-ara/-aras/-ara/-áramos/-aran` for `-ar` verbs) — used in a
subordinate clause after a past-tense request/demand verb (`pedir que`, `rogar que`, `decir que`, `exigir
que`). Introduced via a new Juan/Diana dialogue about household chores (`te pedí que enchufaras la
licuadora` — "I asked you to plug in the blender"). Lección 68 continues the same tense with new
vocabulary (family members, thumb-sucking, nail-biting) and shows it triggered by `decir que` as well as
`pedir que`, including with reflexive verbs (`que no se mordiera las uñas`).

### Imperfecto de subjuntivo — continued, gym vocabulary — Lecciones 69–70

Same tense, extended to more subjunctive triggers (`era importante que`, `insistió en que`, `esperaba
que`, `me sorprende que` + past subjunctive) and a new thematic vocabulary set (gym/weight-training,
locker-room items).

### "Se" construction for involuntary/accidental actions — Lecciones 71–73

Paraphrase (p.3, Lección 71): Spanish marks an action or outcome as involuntary or accidental using `se`
+ an indirect object pronoun + the verb agreeing with the *thing* affected, not the person (`se me olvidó
la clave` — lit. "the combination forgot itself on me," i.e. "I forgot the combination"). The lesson
explicitly contrasts this with the plain active form (`yo rayé el disco`, ambiguous as to whether the
scratching was deliberate) — the `se le/me/te/nos` construction specifically signals it happened by
accident. Drilled across several verbs: olvidarse, rayarse, quemarse, ensuciarse, quedarse (in the sense
of "leave something behind"), perderse, romperse, derramarse, voltearse. The construction is also
explicitly contrasted with the plain preterit form of the same verb when the speaker wants to imply the
action WAS intentional (`tú rompiste la vitrina` — "you broke the display window" [on purpose] vs. `se te
rompió la vitrina` — "you broke the display window" [by accident]).

### "Casi" + present tense for an event that almost happened in the past — Lección 72

Paraphrase: unlike English, which uses a past tense to describe something that "almost happened"
(preterit: "I almost fell"), Spanish uses the **present** tense after `casi` to express the same idea
(`casi me caigo` — literally "I almost fall," meaning "I almost fell"). The lesson explicitly calls this
out as a point of cross-linguistic mismatch, not a translation error. An alternate adverb, `por poco`, is
noted as usable in the same construction but not adopted for this lesson's own drills.

### "Debería haber + participio" (should have done something) — Lecciones 73–75 (first half)

Paraphrase: the conditional of `deber` (debería/deberías/debería/deberíamos/deberían) + `haber` +
past participle expresses "should have done X" — a distinct construction from the condicional perfecto
("would have done X") documented earlier in this file group, built on a different modal verb (`deber`,
"must/should," rather than plain `haber`). Introduced and drilled through an extended house-cleaning
dialogue and vocabulary set (Lecciones 73–74), continued in the review portion of Lección 75.

### "Podría haber + participio" (could have done something) — Lección 75 (second half)

Paraphrase: a parallel construction using `poder` ("can/to be able to") instead of `deber`: podría/
podrías/podría/podríamos/podrían + haber + past participle = "could have done X." The lesson explicitly
notes an alternate structure, `habría podido + infinitivo` (e.g. "habría podido tragar la pastilla"),
exists for the same meaning but is deliberately not taught in this lesson — a rare instance of the course
naming a grammatically valid alternative construction it has chosen to skip.
