# Spanish — Established Vocabulary: Using Spanish Vocabulary (Batchelor & San José)

**Source:** R. E. Batchelor and Miguel Ángel San José, *Using Spanish Vocabulary* (Cambridge
University Press, 2003), 797 pp. Clean text-layer PDF (`pdftotext`/`pdftotext -layout`
cross-checked, no vision reading needed). Organized into thematic "Unidades" (Units) — Unit 1 "El
Ser humano" (the human being: body, personality, speech, sleep, sexuality, personal hygiene);
Unit 2 "La Personalidad humana" (intelligence, feelings, will/duty/conscience, defects/vices/
offenses); Unit 3 food/drinks/clothes; Unit 4 health/illness/accidents/tobacco/drugs/death; Unit 5
family/home; Unit 6 city life/police/traffic; Unit 7 social/religious/legal life; Unit 8
countryside/farming/animals — each subdivided into "Nivel 1" (basic) and "Nivel 2" (advanced)
vocabulary. Like this project's companion volume *Using Spanish Synonyms* (`081`, same authorial
team's register convention), every entry can carry an inline register tag — **R3** = formal/high
register, **R2** = neutral (often left unmarked, the implicit default), **R1** = colloquial, **R1\*
** = vulgar/taboo — plus a regional letter tag, **A** = Argentinian, **M** = Mexican, when a term
is dialect-restricted. Unlike `081`'s synonym-frame structure, this book is a flat, simple-list
thematic vocabulary builder, but the same register+region tagging appears directly inline on individual
entries throughout.

**Coverage decision: REPRESENTATIVE SAMPLING, as directed.** At 797 pages this is squarely
dictionary/thematic-reference scale; full extraction is infeasible and would be heavily redundant
with this corpus's general vocabulary sources. Per the task's guidance, this file prioritizes
entries showing register distinctions — and this book's Unit 1 turned out to be an unusually dense
concentration of exactly that: register-marked body-part euphemisms, taboo sexual-organ and
lovemaking vocabulary, toilet/body-care euphemism ladders, and colloquial youth-slang terms for
"friend/kid," almost all independently cross-tagged for Argentinian/Mexican register variation.
This is directly comparable in kind to the toilet-terminology and youth-slang register ladders
already flagged as flagship findings for Dutch in this project's Phase 1 work, and to the taboo
regionalisms (*concha*, *coger*) already flagged for Spanish from `079` and `081` — this source
independently confirms and substantially deepens both of those findings (see Notes below). Given
that density, this file draws nearly all of its sample from Unit 1's subsections (General people-
terms; Tronco/body; Órganos sexuales; Hacer el amor; Cuidados corporales; Sueño; Físico y aspecto;
Habla), with a smaller supplementary sample from Unit 2's "Sentimientos desagradables" (unpleasant
feelings) and "defectos, vicios y delitos" (vices/offenses) subsections, which showed similar
register/regional richness. Skipped: the book's many flat, register-neutral thematic lists
(anatomy/organ names, food, clothing, housing, farming, etc. — these are standard vocabulary,
redundant with `047`, `049`, `050`, `054` and this project's other dictionaries) and all exercise
pages.

Source Type throughout: `grammar_reference`. Transcription Confidence: `verified` (clean digital
text layer; OCR ligature/accent artifacts, e.g. "dı́a" for "día," normalized during extraction).
Vision Reading Confidence: `n/a`. Attested Era: `contemporary (source published 2003)` throughout.
Attested Region: `—` unless the book tags A (Argentina) or M (Mexico) explicitly. **Weight/
Frequency note:** as with `081`, the book's R-codes measure register/formality, not raw frequency;
Weight/Frequency below is this extractor's reasonable register-informed inference, flagged in
Notes as "register-inferred" where not otherwise obvious.

## Copyright discipline reminder

This file samples selected register-marked vocabulary entries, concentrated in the sections
showing the richest formal-to-vulgar and regional contrasts, from a single copyrighted thematic
vocabulary reference, following this project's established representative-sampling and
non-redundant-supplement conventions. Given the book's scale (797 pages across eight thematic
units), only a fraction of its content — chosen for register/regional interest — is reproduced
here. No exercise content or extended prose is reproduced.
