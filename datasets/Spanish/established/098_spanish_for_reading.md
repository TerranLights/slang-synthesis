# Spanish for Reading: A Self-Instructional Course (Franco & Sandberg, Barron's, 1998)

Source: "Spanish for Reading A Self-Instructional Course.pdf", 368pp. Text-layer PDF, confirmed clean
via `pdftotext` sampling (front matter, TOC, Chapter 1 body) — triage classification (TEXT) upheld.

## Scope note and redundancy assessment

This is the one book in Wave 5 whose core pedagogical aim is genuinely distinct from everything
else in this corpus: it is a **programmed reading-comprehension course**, not a speaking/conversation
course. The authors state explicitly (p. ix-x) that the priority is "function words... and grammatical
signals... as opposed to... content words," because function words carry the grammatical framework a
reader needs to decode meaning, while content words can often be inferred from cognates and context.
The entire 15-chapter grammar sequence (cognates → nouns/adjectives → ser/estar → present tense →
comparisons → preterite/imperfect → subjunctive → conditional) covers the same morphosyntax already
extracted many times over in this corpus (Madrigal's Magic Key, Practice Makes Perfect series, Easy
Spanish Step-by-Step, the Wave 3 grammar workbooks, etc.), so that material is NOT re-extracted here.

What IS distinctive and extracted below:
1. The **cognate-correspondence suffix system** (Chapter 1) — a structured set of Spanish↔English
   suffix mappings (e.g., -ción→-tion, -ico→-ic/-ical) taught as a primary decoding tool for a reading
   learner. This reading-for-cognates strategy does not appear framed this systematically elsewhere in
   the corpus.
2. The explicit **true/partial/false cognate taxonomy** with its worked false-cognate list — a useful,
   compact "faux amis" trap list.
3. Minimal-pair pronunciation sets used to illustrate that stress/accent carries meaning (amo/amó,
   este/esté, papá/papa/Papa) — illustrative, kept brief since pronunciation itself is well-covered
   elsewhere.
4. Notable structural feature: each chapter ends in a literary reading passage (Juan Ramón Jiménez,
   Antonio Machado, Pablo Neruda poems, plus prose on Latin American culture/history/current affairs)
   used as the comprehension payoff for the grammar just taught — a "grammar in service of literature"
   framing not seen in the corpus's other beginner courses, most of which use invented dialogue.

Overall: moderate distinctive value concentrated almost entirely in the cognate-pattern system; the
grammar sequence itself is extensively redundant and was not re-extracted.

## Cognate taxonomy (Ch. 1 §1)

- **True cognates**: similar spelling AND similar/near-identical meaning (geología/geology, abril/April).
- **Partial cognates**: similar spelling, meaning overlaps only partly (lengua = "language" but also
  "tongue"; mayor = "major" but also "older"; único = "unique" but also "only").
- **False cognates** ("faux amis"): similar spelling, unrelated meaning. Worked examples from the text:
  actual ("at this moment," not "actual"), realizar ("to achieve," not "to become aware of"), lectura
  ("reading," not "lecture"), librería ("bookstore," not "library").
