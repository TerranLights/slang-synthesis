# Spanish — Established Vocabulary/Grammar: Spanish: Beyond the Basics Coursebook (representative-sample extraction, low-yield)

**Source:** *Spanish: Beyond the Basics* (Living Language-style coursebook, OpenOffice.org 2.0/Writer-
produced, 2006, 204-page scan). **No text layer** — despite the OpenOffice Writer producer metadata
(which normally indicates a born-digital, cleanly text-extractable PDF), `pdftotext` returns empty
across every sampled page (pp.1, 20, 50, 100, 150, 200 all blank) — the PDF appears to be a scanned
image rendering of an OpenOffice-typeset original, not a text-layer export. Triage's "vision-required"
classification is CONFIRMED correct; initial trust-but-verify check on the producer metadata was worth
doing but didn't change the outcome. Extracted via vision-reading of `pdftoppm`-rendered page images
(120 dpi), one PDF page = two printed pages per scanned spread (confirmed: PDF page 42 showed printed
pp.62-63).

**Coverage approach and finding: this book is LOW-YIELD for this corpus.** English-medium, ~20-lesson
structure (Dialogue → Notes → Grammar & Usage → Exercises → Answer Key), each lesson built around a
U.S.-market "intermediate Spanish review" dialogue (shopping, museums, car rentals, doctor's office).
Six separate lesson/page samples were vision-read across the book (Lesson 4 "Transportes urbanos,"
Lesson 6 "De compras" incl. its dialogue, Notes, and double-pronoun/negation exercises, Lesson 9
negation/tanto-tan grammar, nosotros-command ("let's") pronoun-attachment grammar) and **every single
sample was wall-to-wall core-grammar drilling** (impersonal se, acordarse de, double negation stacking,
direct+indirect object pronoun combination, nosotros commands, si-clause conditionals) — all of it
already covered in depth and with more examples across this corpus's dedicated grammar workbooks
(014, 015, 060-064, Practice Makes Perfect series, Uso de gramática series). No "Notes" section sampled
contained cultural, register, or dialect-specific content beyond a single geographic detail (below).
Given the strong, consistent redundancy signal across all six independent samples, further sampling of
this specific book was not pursued — the dispatch's redundancy-avoidance instruction was followed by
stopping early rather than padding the file with re-derived grammar points.

**Genuinely new finding:** the book's dialogues are explicitly set partly in **Puerto Rico** (Lesson 6,
"De compras," opens: "Ernesto ha decidido pasarse la tarde haciendo unas compras en Plaza Las Américas,
el centro comercial más grande del Caribe, ubicado en San Juan, Puerto Rico") — a genuine Caribbean-
Spanish geographic anchor, distinct from this book's otherwise Iberian-default grammar framing. No
lexical Caribbean-specific vocabulary (e.g., regionalisms for "bus," "coger" register) surfaced in the
sampled pages, however — the dialogue itself uses standard pan-Hispanic shopping vocabulary throughout.

**Non-redundant-supplement note:** per the above, this file intentionally contains only the handful of
items that are NOT already covered by the corpus's extensive existing grammar coverage.
