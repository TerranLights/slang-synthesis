pp. 195-200 is the "Краткий толковый словарь" (Brief Explanatory Dictionary) — a genuine
alphabetical glossary of ~110 lexical items the book's editor judged likely to trip up a learner
(archaic/dialectal words preserved in the fairy-tale texts, folklore-specific realia, set phrases).
**This is the highest-value vocabulary content in the whole book** and is extracted here in full —
each entry is a single headword plus a short one-line definition (paraphrased Russian gloss), not
narrative prose, and several entries carry the source's own explicit register tags (разг.
"colloquial", прост. "low-colloquial/vernacular", устар. "archaic/obsolete", высок. "elevated/
literary", перен. "figurative", пренебр. "disdainful/pejorative" — usually stacked, e.g.
прост.+пренебр.), which the extraction spec flags as always worth capturing. A `*` in the source
marks a fixed idiom characteristic of the fairy-tale register specifically (устойчивое сочетание,
характерное для сказки) — preserved as a Notes flag below. No handwritten marginalia found anywhere
in this source.

## Grammar points

### The dictionary's register-tagging system (pp. 195-200)

The glossary itself uses six register/usage tags, applied singly or stacked on individual entries:
устар. (устаревшее — archaic/obsolete: дровосек, курий, лекарь, хоромы, чары, чертог, чудище,
яство, and уста which stacks with высок.), высок. (высокое — elevated/literary register: краше,
уста, чертог), разг. (разговорное — colloquial: заесть, за спасибо, ломиться, мотать, пятак,
темным-темнёхонько, управиться), прост. (просторечное — low-colloquial/vernacular, a register below
разг.: небось, не все дома, нечистая сила, промашка, страшилище — plus варево and коробчонка which
stack прост./пренебр.), пренебр. (пренебрежительное — disdainful/pejorative: неуч, and the
прост.+пренебр. pair варево/коробчонка), and перен. (переносное — figurative sense: заесть). A
separate `*` marker (unrelated to register) flags a fixed idiom the editor judges characteristic of
the fairy-tale genre specifically (долго ли коротко ли; за тридевять земель; ни в сказке сказать ни
пером описать; откуда ни возьмись) — all four of these cross-confirm, word for word, the fixed
folklore formulas already identified from the book's own "особенности сказки" chapter (see
`086_chitaya_skazki.md`), giving this project independent double-sourcing on that formula set within
a single book.
