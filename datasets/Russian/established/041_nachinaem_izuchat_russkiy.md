# Russian — Established Vocabulary/Grammar: М. Н. Аникина, *Начинаем изучать русский. В Россию с любовью*

**Source:** M. N. Anikina (М. Н. Аникина), *Начинаем изучать русский. В Россию с любовью* [*Beginning
to Learn Russian: To Russia with Love*] ("Учебное пособие по русскому языку," 4th stereotyped
edition, Moscow: Русский язык, 2004). Full 74-page PDF (`Russian Learning Pack [up-to-date as of
2012]/Vol 3 of 3/12.Начинаем изучать русский. В Россию с любовью.pdf`). Despite the beginner-sounding
title, the front matter states the book targets students who have *already completed* a beginner
course ("предназначено для иностранцев, которые усвоили программу начального этапа... можно
использовать на среднем и на среднепродвинутом этапах") — this is an intermediate/upper-intermediate
conversation-and-composition course, organized into 7 thematic sections (ЗНАКОМСТВО, УЧЁБА, РАБОТА
ПОСЛЕ УЧЁБЫ, РАЗВЛЕЧЕНИЯ И УВЛЕЧЕНИЯ, КАНИКУЛЫ, etc.), each built around a first-person narrative
text followed by verb-government/vocabulary boxes, grammar drills, and discussion prompts.

**Coverage note — full 74 pages read; non-redundant-supplement scope applied.** All 74 pages were
surveyed (page-by-page preview pass plus close reads of ~20 pages), per the coverage rule. Given
Russian's Wave 1 already has 47 established/ files (~641,000 words) including several comprehensive
reference grammars (Wade's *Comprehensive Russian Grammar*, Timberlake's *Reference Grammar of
Russian*, Offord & Gogolitsyna's *Using Russian: A Guide to Contemporary Usage* as the register
flagship, plus a dedicated prefixed-motion-verb reference), this book's case-government drills,
basic aspect pairs, subordinate-clause connectives (чем...тем, в то время как, между тем как, по
мере того как), verbs-of-motion tables, and comparative-adjective/nationality vocabulary are
**skipped as redundant** — they duplicate ground already covered more systematically elsewhere.

**What was kept (genuinely new/deeper):**
1. A full, concrete **register-tiered scale of Russian personal-name forms** (official →
   neutral-official → neutral-friendly → familiar-friendly → diminutive-affectionate), with worked
   examples per tier — not previously captured this systematically in `established/`.
2. Several **systematic verb-prefix semantic families** built on a single root, each rection
   distinguished by its own government pattern and worked example (работать-family: под-/про-/от-/
   пере-/раз-/срабатываться/заработаться; внимание-attraction family: при-/от-/раз-/у-влекать).
   These go deeper than a general reference grammar's prefix chapter because each entry is paired
   with an explicit case-government question and a disambiguating example sentence.
3. **Word-formation pattern families** for abstract-noun/adjective derivation (одно-/разно-/одно-
   sameness prefixes; со- reciprocal/collective prefix), including an explicit source-marked
   false-friend pair (совместный vs. совместимый).
4. A **source-internal, register-annotated Anglicism/loanword glossary** — the book's own answer
   key glosses ~30 recent loanwords with native-Russian paraphrases, several explicitly marked "no
   Russian equivalent" (эквивалента нет) by the author. This is exactly the kind of explicit
   register/usage annotation the extraction spec prioritizes, and it is a clean, first-party
   snapshot of turn-of-the-2000s lexical borrowing pressure in colloquial/media Russian.
5. A handful of **idioms and proverbs** encountered in the narrative texts and drill answer keys,
   with the author's own paraphrase where the source itself glosses them.
6. Personality-type loanword nouns, noted briefly (small closed set, kept because bundled with #4).

**Skipped as redundant (with reason):** case-government drills for учиться/заниматься/изучать
(core, already exhaustively covered by Wade and Timberlake); verbs-of-motion prefix tables
(идти/ходить, приезжать/приехать — already a dedicated specialist source, `028_russkie_glagoly_
dvizheniya_s_pristavkami.md`); nationality noun/adjective pairs (basic, high-redundancy pattern
already attested many times over in Wave 1); active/passive-construction and subordinate-connective
grammar (чем...тем, в отличие от, по сравнению с, etc. — standard intermediate syntax, already
covered systematically in Wade Part 2 and Timberlake); occupation agent-noun suffix drills (-ист/
-ец/-щик/-ач productive-suffix list — noted as one brief grammar point below since the pattern
itself, if not the full vocabulary list, adds a compact worked example, but the vocabulary items are
not tabulated to avoid duplicating a very common pattern).

**PDF-extraction note:** The PDF (produced by I.R.I.S. OCR software, `Autoformat5,0,0,235`, from a
2011 scan) has a genuine text layer with **no font-substitution cipher** — Cyrillic renders
correctly as Cyrillic throughout, cross-checked against 30+ known word/gloss pairs across widely
separated pages (this rules out the ЙЦУКЕН-layout, cp1251-as-latin1, and 1:1-substitution ciphers
documented elsewhere in this corpus). Instead the OCR itself is moderate-to-poor quality on this
particular scan: **layout-mixing garbling**, where the two-column page layout (a left column of
numbered vocabulary/grammar boxes and a right column of drill exercises) gets partially interleaved
by both `pdftotext` and `pdftotext -layout`, and a recurring **Latin-digit/Cyrillic-look-alike
character swap** within otherwise-legible words (e.g. "1IIII" substituting for "Пс" in "Психологи-
ческим," "l" for "т," stray digits inside words) — this is uncorrelated garbling from the OCR
engine misreading small/bold/italic print, not a decodable fixed cipher, and it is heaviest on the
front-matter/preface pages (2–5) and lightest on the main lesson-box print (which uses a larger,
cleaner font). All vocabulary/grammar content extracted below was cross-checked against the
page-level `pdftotext -layout` rendering, where left-column boxed content came through cleanly
despite right-column drill-answer corruption on the same page. No handwritten marginalia was found
on any page inspected — all content read is clearly typeset/printed.

## Grammar points

### Register-tiered scale of Russian personal-name address forms (pp. 6–7, 10–11)

The source presents a five-tier scale for how a single given name is realized depending on social
register and relative closeness, worked through several parallel example names. This is presented
more concretely/systematically here than in prior extractions and is directly relevant to how
address-term register could map onto invented slang naming conventions:

1. **Strictly official**: господин/госпожа + surname (господин Петров, госпожа Петрова).
2. **Neutral-official / neutral** (junior→senior): first name + patronymic (Андрей Николаевич,
   Ирина Сергеевна).
3. **Neutral (senior→junior); neutral-friendly (peer↔peer of similar age)**: bare first name, often
   already a short form (Ира, Серёжа, Ваня, Лена, Маша, Оля, Коля — vs. full Ирина, Сергей, Иван,
   Елена, Мария, Ольга, Николай).
4. **Familiar-friendly**: first-name + `-к(а)` suffix, distinctly more casual/blunt than tier 3
   (Ирка, Ленка, Ванька, Машка, Олька, Колька, Серёжка, Димка).
5. **Diminutive-affectionate**: first-name + diminutive suffix (`-очк(а)`, `-еньк(а)`, `-ик`, etc.)
   (Ирочка, Леночка, Ванечка, Машенька, Оленька, Коленька, Дашка→[cf. narrative uses "Дашка" as tier
   4 for the recurring girlfriend character], Серёженька, Димочка).

The same scale is shown to interact with generation/formality choices independently of name
selection — e.g. a student is drilled on how they would address a rector vs. a professor vs. a
friend vs. an elder vs. a child, producing distinct forms even for names that share a root. The
book also shows the same `-к(а)`/diminutive apparatus applied productively to place names in a
related exercise (informal renamings like Ленинград↔Санкт-Петербург discussed for their own
etymological/political connotations, pp. 10–11), suggesting the affective-suffix system generalizes
beyond personal names to toponyms under certain rhetorical conditions.

### раб- (работать) prefixed-verb family: case government tied to aspectual prefix (p. 49)

Six verbs built on working root work- are each given with a distinct government pattern (rather
than a shared one), which the source treats as the actual teaching point — not just "these are all
work-related verbs" but "each prefix changes both the meaning and the required case/preposition":
подрабатывать (где? кем? какая?) — про-work (кем? где? как долго?) — от-работать (где? кем? как
долго? / что? как?) — пере-работать (что? — two distinct senses) — раз-работать (что?) —
с-работаться (с кем?) — за-работаться (intransitive, no government, purely aspectual-completive:
"work oneself into a state"). Useful worked example for the mechanics-analysis phase of how
Russian's fusional prefix+case system can carry meaning distinctions that a purely agglutinative
gloss would flatten.

### вле́к- (влечь/влекать) attention-verb family (pp. 58, 61)

Same pattern as above applied to a second root: при-влекать (кого?/что? к чему? — to attract/draw
in), от-влекать (кого? от чего? — to distract from), раз-влекать(ся) (to entertain/have fun), у-
влекать(ся) (кем?/чем? — to become keen on). The source's own answer key (p.61) groups these
together explicitly as one word-family exercise, confirming the pedagogical intent to teach the
prefix system as a system rather than as isolated verbs.

### одно-/разно- "sameness/difference" adjective-noun derivation family (p. 50)

A productive derivational pattern: `одно-` + root-based adjective/noun = "having one X" (uniform/
single-instance), with `разно-`/`много-` as the productive antonym prefix: однообразный↔разно-
образный, односторонность↔разносторонность, однозначность↔многозначность. A second sub-branch uses
`одно-` to mean "sharing the same X with someone" rather than "having only one X":
однофамилец (shares a surname), одноклассник (shares a class), одногодок (shares an age) — the
source flags this as a distinct sense of the same prefix, not just a coincidental homonymy, worth
noting for morphology work since it shows one bound prefix carrying two related-but-distinct
compositional meanings depending on the base it attaches to.

### со- reciprocal/collective-action prefix family, incl. a marked false-friend pair (p. 50)

`со-` attaches to nouns/verbs to indicate joint/shared/reciprocal action or state: соавтор,
совладелец, сотрудник, соучастник, собеседник, современник (shares an era), единомышленник (shares
a viewpoint, using един- rather than со- but grouped with the same semantic family by the source).
The source explicitly flags **совместный** ("done jointly/together," of an action) vs.
**совместимый** ("compatible," of two things that can coexist/combine) as a "words that look similar
but are different" pair under a "Внимание!" callout — worth carrying forward as a documented
false-friend risk for any invented-language derivational system modeled on Russian's со-/-мест-
morphology.

### Occupation agent-noun productive suffixes (brief note only; vocabulary not tabulated — p. 8)

The source drills three parallel occupation-formation patterns without stating them as an explicit
rule: `-ист` for a field of study/practice (физик, финансист-style; e.g. пианист/скрипач for
instrumentalists, split by instrument-type into `-ист` vs. `-ач`), and deverbal `-ец`/`-щик`/`-ник`
agent nouns (переводчик "translator" ← переводит; певец "singer" ← поёт; обманщик "cheat" ← обманы-
вает; завистник "envious person" ← завидует; борец "fighter" ← борется). This is a common,
well-attested productive pattern already documented at length elsewhere in Wave 1's morphology
coverage, so the vocabulary items themselves are not re-tabulated — flagged here only because the
instrument-type split (-ист for keyboard/wind instruments vs. -ач for bowed/brass) is a genuinely
narrower observation than the generic rule.
