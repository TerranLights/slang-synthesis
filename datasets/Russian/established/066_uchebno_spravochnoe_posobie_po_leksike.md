template: headword, brief definition/sense breakdown, then an extensive collocation/government
inventory (какой + noun, noun + чего/кому/где, verb + noun pairs) and drill exercises. Per the
coverage rule, every distinct headword (every "vocabulary item") in this page range is captured as

bulk-reproduced (copyright discipline), with the most structurally informative government patterns

is exactly the kind of grammatical fact the extraction spec asks to preserve. Drill exercises
(Упражнения) are skipped per the coverage rule — they introduce no new vocabulary/grammar beyond
what the entry itself already supplies. No handwritten marginalia found on any page in this range —

## Grammar points

### Government (управление) as the book's organizing axis

The book's entire structure is built around case government and prepositional government for each
near-synonym headword rather than free-standing grammar rules — the "grammar point" content for
this source is embedded in the Vocabulary table's Notes column above (each entry records which case
a headword governs directly or through a preposition: чего, кому, где, за что, в чём, etc.). This is
consistent with the stated purpose (p.5): "Проблема лексической и грамматической сочетаемости слов
... одна из самых сложных проблем обучения лексике" (lexical and grammatical collocability is one
of the hardest problems in teaching vocabulary) — i.e., government/collocation *is* the grammar
content here, not a separate layer.

### Register/usage annotation system (p.5)

The book's front matter (p.5, «Условные сокращения») defines a fixed abbreviation set used to flag
register/usage nuances on individual collocations within an entry (not on the headword as a whole):
`книжн.` (bookish/literary), `разг.` (colloquial), `высок.` (elevated/high register), `неодобр.`
(disapproving), `ирон.` (ironic), `шутл.` (jocular), `офиц.` (official), `перен.` (figurative),
`спец.` (specialized), plus domain tags (`анат.`, `бухг.`, `геогр.`, `медиц.`, `муз.`, `хим.`,
`юрид.`) and grammatical-form tags (`ед.`/`мн.` number, `нсв`/`св` aspect, `В.п.`/`Р.п.` case,
`кр.ф.` short form, `инф.` infinitive). This confirms the book itself carries explicit register
annotation at the collocation level — the extraction spec's "every explicit register annotation"
rule applies here at finer grain than the headword level; e.g. p.16 tags "подтасовка, фальсификация"
as `(книжн.)` within the ФАКТ entry (a bookish/formal-register near-synonym of the neutral
collocates around it), and p.36 tags a sense of ПРИЁМ's near-synonym set similarly. Future shards of
this file should flag any further register-tagged sub-collocations encountered, per this convention,
rather than only capturing headword-level register.

### Two-part entry template

Every entry follows: **headword** (bolded, with an asterisk `*` marking "this word has another sense
not covered in this Пособие," e.g. вещь*, предмет*, действие*) → **numbered senses** where the
headword is polysemous → **government/collocation inventory** per sense → (for multi-headword groups)
a **Комментарий** block in italics preceding the entries, which is the book's own explicit
near-synonym discrimination — this Комментарий text is exactly the register/nuance information most
valuable to this project's slang-mechanics work, since near-synonym discrimination is a proxy for
formality/register distinctions, and has been paraphrased into each entry's Notes above rather than
extracted as a separate grammar-points subsection (to avoid duplicating the same content twice).
