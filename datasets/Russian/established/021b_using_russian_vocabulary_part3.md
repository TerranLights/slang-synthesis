## Grammar points

### The -ëнок/-ятa suffix for young animals
A "Reference note" (paraphrased, not quoted) explains that nouns in -ëнок (gen. -ëнкa) denote the
young of animals/birds, with an irregular plural in -ятa (gen. -ят): some are transparently
cognate with the parent-animal noun (утëнок 'duckling' < у́ткa), others use a different root
entirely (ягнëнок 'lamb', тeлëнок 'calf', цыплëнок 'chick', the last from the calling-cry
цып-цып!). This is a genuine morphological pattern distinct from ordinary derivation and worth
flagging for the mechanics-analysis phase, since it's a closed, semantically-narrow suffix class.

### Consonant mutation classes drilled in this unit
пaхáть (х/ш throughout), рaзвод и́ть (д/ж 1sg), корми́ть (м/мл 1sg), смáзaть (з/ж throughout pf.),
изгото́вить/зaгрузи́ть-type (в/вл, з/ж 1sg) — all instances of general Russian consonant-mutation
classes already documented in this project's grammar-focused files; noted per-verb in the Notes
column above rather than restated as a separate block.

### Genitive-in-a/genitive-in-ov noun classes and mobile vowels
Several nouns in this unit (овëс, ячмeнь, козëл, осëл) have a mobile vowel that disappears in
oblique cases (e.g. овëс → gen. овсá), flagged individually above; ро́жь has an additionally
irregular declension pattern (gen. ржи́, instr. ро́жью) noted in its own row.
