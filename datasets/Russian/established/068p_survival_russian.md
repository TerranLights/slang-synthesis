## Coverage decision — non-redundant-supplement pattern applied, near-total overlap found

Russian's `established/` corpus already contains **193 files** as of this extraction. Before
extracting this back matter, checked prior coverage by keyword grep across `established/*.md`:

- **Case/declension paradigms** (noun, adjective, pronoun, numeral 6-case declension tables):
  67 files already contain declension content, including full paradigm tables from
  `006`/`007` (Timberlake's *A Reference Grammar of Russian*), the `001*` *Basic Modern Russian
  Grammar* shard series, `004` (SEELRC reference grammar), and multiple others — all
  substantially more granular and exhaustive than this appendix's condensed pedagogical tables
  (e.g. Timberlake covers productive *and* unproductive declension subtypes, stress-shift
  patterns, and historical alternations this appendix omits entirely).
- **Verbs of motion** (uni-directional/multi-directional pairs — идти/ходить, ехать/ездить,
  бежать/бегать, etc.): 20+ files already cover this, including a dedicated source
  (`028_russkie_glagoly_dvizheniya_s_pristavkami.md`, "Russian Verbs of Motion with Prefixes")
  that covers the same base pairs plus the full prefixed-derivative system this appendix's
  bare table doesn't touch. The base pair list in this appendix's table (идти-ходить,
  ехать-ездить, бежать-бегать, плыть-плавать, лететь-летать, брести-бродить, ползти-ползать,
  лезть-лазить, нести-носить, вести-водить, везти-возить, тащить-таскать, катить-катать,
  гнать-гонять) is a subset of what `028` already documents.
- **Particles** (пусть, бы, ли, неужели, разве, уже, даже, ещё, да, так, конечно, не, ни, etc.):
  81 files already reference particle usage.
- **Aspect-pair formal indicators** (prefixation, -ива-/-ыва- vs. no suffix, -ва- vs. no suffix,
  -а- vs. -и-/-ну-, suppletive pairs): already tabulated with comparable or greater granularity
  in `006`/`007`, `015`, `024`, `027`, `041`, `050k`/`050l`, and others.
- **Phonetics** (unstressed-vowel reduction/akanye-ikanye, hard/soft consonant pairs, final
  devoicing, voicing assimilation): already covered across numerous prior sources (`001l`,
  `001m`, `002`, `004`, `006`, `007`, `008`, `012`, `015`, `016`, `025`, `048`, `051`, and others).

Checked every subsection of this back matter against the above (nouns, adjectives, pronouns,
verbs — including aspect, imperative, conditional mood, reflexive verbs, verbs of motion —
adverbs, numerals, prepositions, conjunctions, particles; phonetics — vowel reduction rules,
consonant hard/soft pairing, voicing/devoicing rules). **No genuinely new grammar point, deeper
paradigm, or previously-uncaptured rule was found.** This appendix is explicitly a condensed
teaching-summary/quick-reference restatement of material this project has already captured in
far greater depth from dedicated grammar references (Timberlake, SEELRC, *Basic Modern Russian
Grammar*, *Big Silver Book of Russian Verbs*, etc.) — exactly the outcome the spec's
non-redundant-supplement pattern anticipates for a late-stage source in an already
well-covered language.

One citation worth preserving for provenance: the phonetics section's closing note directs
readers to Karavanova's own more detailed companion volume, *Корректировочный курс фонетики
русского языка* ("A Corrective Course in Russian Phonetics," Moscow, 1992) — not itself in this
project's corpus, flagged here only as a potential future acquisition lead, not extracted content.
