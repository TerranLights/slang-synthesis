## Grammar points

### Colloquial advice/suggestion constructions (register-marked, contrasted with formal register)

The lesson's core grammar content is a set of spoken-register constructions for giving advice,
explicitly contrasted with a parallel **(книжн.)** "bookish" register box (p. 13):

- **Conversational register** (framed box, p. 13): `кто советует кому + инфинитив`; imperative
  СВ/НСВ; `кому лучше + инфинитив`; `лучше + императив`; `а что если...`; `а не пойти ли кому +
  инфинитив СВ?`; `может быть, + гл. 2 л. буд. вр.?`; `почему бы кому не + инфинитив`; `а не +
  инфинитив СВ ли + кому?`; `пошел бы + гл. 3 л. прош. вр. СВ`.
- **Bookish/formal register** (same box): `кому рекомендуется/рекомендовано/рекомендуют + что`.
  The book explicitly frames this as the register a specialist/journalist would use (Задание 12
  has students role-play a "specialist" using only the bookish constructions), while the
  conversational forms are for peer/family advice-giving (Задание 3-6 dialogues: parent-to-child,
  friend-to-friend).
- **Aspectual distinction in advice-giving** (p. 15-16, 19): a specific concrete piece of advice
  uses **imperative SV** (perfective) — e.g. `Встретьте её в аэропорту`; a general/repeated
  recommendation uses **imperative NSV** (imperfective) — e.g. `Говорите ей только приятное`; a
  general prohibition uses **не + imperative NSV** — e.g. `Никогда не говорите, что она
  толстеет.` This SV-for-one-time/NSV-for-habitual split in advice-imperatives is presented as a
  systematic three-way table (Конкретный совет / Общий совет (императив НСВ) / Общий совет (не +
  императив НСВ)), p. 16.
- **Evaluative construction for habits**: `инфинитив НСВ + полезно/вредно` — e.g. `Обычно
  считается, что есть жирное вредно` (p. 23) — used to state whether a habitual action is
  beneficial or harmful, contrasted with the specific-advice constructions above.
