# Russian — Established Vocabulary/Grammar: *Русский язык как иностранный. Рабочая тетрадь. I сертификационный уровень* (full workbook)

**Source:** N.Yu. Tsareva, M.B. Budiltseva, I.A. Pugachev, N.M. Rumyantseva, *Русский язык как
иностранный. Рабочая тетрадь. I сертификационный уровень* ["Russian as a Foreign Language.
Workbook. First Certification Level"] (RUDN-affiliated series, ООО «ИД «Русь»-«Олимп» / Издательство
Астрель, published 2010; print run info dated 07.06.2010). Covers the entire 251-page PDF
(printed pagination runs continuously from this "Vol 2 of 3" pack's earlier books, visible page
numbers ≈122–250 inside this file; the PDF's own first ~2 pages before the first visible page
number are unnumbered continuation matter, not missing content).

**Coverage note — this is a genuinely low-grammar-content workbook, not a grammar reference.**
This book is built entirely around ~20 listening/reading comprehension texts (short biographical
sketches, cultural/scientific topics) at the TORFL-1 ("First Certification Level," ≈ B1) level. Each
unit follows the same fixed exercise pattern: (1) a "determine the meaning of these words yourself,
consult a dictionary if needed" lexical task — the book deliberately does **not** supply glosses,
since the intended audience is expected to already work these out; (2) word-family/word-formation
analysis tasks; (3) sentence-construction and paraphrase drills reusing the same lesson's vocabulary;
(4) a listening text, followed by summary/argumentative-writing prompts; several later units add a
content-plan "Таблица" (a structured fact outline of the biographical text, used as a note-taking
model, not a grammar table). There is no systematic grammar-rule exposition anywhere in the book
(no case-paradigm tables, no aspect-rule explanations, no participle-formation rules stated
explicitly) — grammar is targeted only implicitly, through what forms a given drill asks students to
manipulate. Per the coverage rule's "skip repeated drill exercises" instruction: **every unit's own
topical word list is distinct new vocabulary and is extracted below; the sentence-paraphrase drills,
full listening/reading texts, biographical narratives, and content-plan tables are skipped as
copyright-sensitive bulk narrative prose that does not itself introduce new vocabulary beyond what
each unit's own word list already captures.** Glosses in the table below are supplied by the
extractor (English translations), not the source, since the source itself gives none — flagged via
`Source Type` and the per-unit note. No handwritten marginalia was found in this copy; the PDF has a
genuine, cleanly-OCR'd (ABBYY FineReader 8.0) Cyrillic text layer throughout — no font-substitution
cipher was detected (cross-checked against dozens of known common Russian words across the whole
file; unlike several other sources in this corpus, this one decoded correctly under plain
`pdftotext -layout` from the start).

**Morpheme breakdown (illustrative — Russian is fusional, not agglutinative, so this is used
sparingly, only for chains that make a derivational pattern visible):**

> **наследственность** = на- (locative/onto- prefix, fossilized) + следств- (root, "trace/consequent," from след "trace") + - енн- (adjectival suffix) + -ость (abstract-noun suffix, "-ness/-ity") — the whole family (наследовать → наследование → наследник → наследство → наследственный → наследственность) demonstrates a single verbal root passing through act-noun, agent-noun, result-noun, adjective, and abstract-quality-noun derivations, p.169.

> **обществоведение** = о- (about) + -бщ- (root, "common," from общий) + -еств- (abstract-collective suffix) + -о- (linking vowel) + вед- (root, "to know," from ведать) + -ение (deverbal-noun suffix) — a compound built from общество ("society") + ведение ("the knowing of"), i.e. "social studies," p.150.

## Grammar points

### Prefixed motion verbs (verbs of determinate/indeterminate motion + spatial prefixes)

The workbook drills, without ever stating the rule explicitly, the standard Russian system of
adding directional prefixes to the base determinate/indeterminate motion-verb pairs (идти/ходить,
ехать/ездить). Each prefix carries a spatial meaning that composes with the verb root: при- "arrival,"
под- "approach," вы-/вой- "exit," в-/во- "entry," об- "circumvention," за- "brief detour/stopping by,"
про- "passage through," у- "departure/removal," до- "reaching a limit." The workbook's own task
(p.127) has students derive the perfective member of each pair (приходить → прийти, подходить →
подойти, etc.) and identify the semantic contribution of each prefix — this is the same
prefixed-motion-verb system this project's `028_russkie_glagoly_dvizheniya_s_pristavkami.md`
specialist source treats in much greater depth; nothing here goes beyond that source's coverage, so
only the drill's word list is recorded above, not a re-derivation of the rule.

### Reflexive -ся as a meaning-shift device, not just passive/reciprocal marking

Several units (pp.123, 145) drill pairs like хотеть/хотеться, учить/учиться, взять/взяться,
представлять/представляться where adding -ся changes the verb's argument structure and sometimes
its core meaning (e.g. "to want" → "to feel like [impersonal]"; "to teach" → "to study/learn"), not
merely marking a passive or reflexive reading. The workbook also flags (p.123) a closed class of
verbs that exist *only* in the -ся form (вспоминаться, чувствоваться, казаться, возвышаться,
вглядываться, удивляться, касаться, начинаться) — genuinely deponent-like verbs with no
non-reflexive base in the modern language.

### Verb government (case/preposition requirements) as an explicit teaching target

A recurring exercise type across units (pp.136, 195) asks students to attach the correct
interrogative case-question to a bare verb infinitive — e.g. ожидать (чего? от кого?) "genitive +
от-genitive," заниматься (чем?) "instrumental," общаться (с кем?) "instrumental with с,"
разочаровываться (в чём?) "locative with в," расстраиваться (из-за чего?) "genitive with из-за."
This is the book's closest approach to genuine grammar instruction: it never states the general rule
that Russian verbs lexically select a specific case/preposition for their complement (unlike, say,
English's uniform "to X something"), but every one of these drills is implicitly teaching exactly
that lexical-government principle, one verb at a time.

### Productive derivational suffix families (word-formation drills)

Nearly every unit includes a "word family" task (e.g. p.122's -ск-/-н-/-ов- adjective-forming
suffixes on place/thing names; p.150 and p.169's -ние/-ание deverbal-noun suffix; p.204's -ist/-олог
family for fields of study). The book teaches Russian derivational morphology entirely inductively,
through same-root word chains, never through a stated suffix-meaning rule — see the morpheme
breakdowns above for two worked examples of the pattern.
