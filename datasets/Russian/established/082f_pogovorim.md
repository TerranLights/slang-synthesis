## Grammar points

### Uncertainty/vagueness register cluster (Урок 6)

Framed box, p. 74 — the lesson's core register is describing a person's puzzling/uncharacteristic
behavior:
- **`кто какой-то + adjective`**; **`у кого какой(-ая/-ое/-ие)-то + noun`**; **`кто + verb +
  как-то + adverb`**; **`кто куда-то/где-то + verb`** — the "-то"-suffixed indefinite-pronoun
  family used specifically to express that something about a person seems subtly "off" without
  being able to pin down what, p. 74-78 (an extended dialogue and drill built entirely around this
  pattern).
- **Hedge/supposition adverbs**: `возможно, может быть, по-видимому, вероятно, наверное, пожалуй,
  видимо, очевидно, скорее всего` — presented as a synonym cluster for graded epistemic
  confidence, p. 74, 76.
- **Emphatic negation cluster** (continuing "disagreement" register from Урок 3): `никакой не +
  adj.`; `нисколько/совершенно/абсолютно/ни капельки/ничуть/вовсе/совсем не + adj./verb/adverb`;
  `никуда/нигде не + verb` — a graded set of intensified negation particles for firmly
  contradicting a suggestion, p. 74, 77.
- **Formal characterization construction**: `кто производит впечатление какого человека`; `кто
  кажется каким человеком`; `что оказалось каким`; `что говорит/свидетельствует о чем`; `что
  подтверждает/показывает что` — bookish register for describing/inferring personality from
  evidence (used for photo-based character-judgment tasks and children's-drawing psychological
  testing, p. 74, 78, 81).

### Register note: children's-drawing personality test (pp. 81-83) and EQ/IQ discourse (pp. 85-86)

Two content-rich expository sections: a "draw an uncle" child-development test (scored on
detail/proportion/recognizability) and a EQ-vs-IQ discussion citing American research — both are
0-slang, formal-register journalistic prose, useful mainly as a register contrast point (compare
the idiom-dense colloquial dialogues elsewhere in the same lesson) rather than for vocabulary
extraction; no additional glossary-flagged terms found in this stretch beyond those above.
