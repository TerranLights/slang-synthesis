## Grammar points

### Глаголы с частицей -ся (Verbs with the particle -ся) — pp. 16–17

The lesson gives a systematic four-way functional classification of -ся verbs, each with worked
transitive/intransitive (or active/passive) contrastive pairs and, notably, explicit case-government
("rection") marking on the reciprocal set — a level of rection-tagging detail not confirmed present
in this exact paired form in prior established/ files, so kept here as the non-redundant piece of
this otherwise well-covered topic:

1. **Общевозвратное значение** (general-reflexive sense) — action reflects onto the subject itself.
   Transitive/intransitive pairs given: возвращать/возвращаться, закрывать/закрываться,
   изменять/изменяться, интересовать/интересоваться, кончать/кончаться, начинать/начинаться,
   открывать/открываться, отправлять/отправляться, останавливать/останавливаться,
   прекращать/прекращаться, продолжать/продолжаться, пугать/пугаться, удивлять/удивляться,
   учить/учиться (14 pairs total).
2. **Общевозвратные глаголы, не употребляющиеся без -ся** (general-reflexives with no non-reflexive
   counterpart): бороться, гордиться, надеяться, находиться, оставаться, ошибаться, появляться,
   пытаться, смеяться, становиться, улыбаться, являться.
3. **Глаголы страдательного значения** (passive-sense -ся verbs) — active construction (nom.
   subject + verb + acc. object) vs. passive construction (nom. patient-as-subject + -ся verb +
   instrumental agent), worked example: Рабочие строят больницу. ↔ Больница строится рабочими.
   Note (p. 16): when the active construction's subject is present, it surfaces as the instrumental
   agent in the passive; the active object becomes the passive's nominative grammatical subject.
4. **Глаголы взаимовозвратного значения** (reciprocal-sense -ся verbs) — transitive verb governing
   an accusative object corresponds to an intransitive -ся verb governing "с + instrumental":
   видеть кого? ↔ видеться с кем?; встречать кого? ↔ встречаться с кем?; знакомить кого?/с кем? ↔
   знакомиться с кем?; обнимать кого? ↔ обниматься с кем?; советовать кому?/что (сделать)? ↔
   советоваться с кем?; целовать кого? ↔ целоваться с кем?.
5. **Reciprocal-only -ся verbs** (no non-reflexive transitive counterpart, still govern с + instr.):
   здороваться, прощаться, бороться, договариваться, мириться, расставаться (all "с кем?").
6. **Взаимного действия без частицы -ся** (verbs that are inherently reciprocal *without* -ся, also
   governing с + instrumental): беседовать, дружить, разговаривать, сотрудничать, спорить.

This full paradigm — plain reflexive vs. no-nonreflexive-counterpart vs. passive vs. reciprocal vs.
inherently-reciprocal-without-ся — gives a cleaner four/five-way functional split than a bare
"reflexive verbs govern X" statement; useful for later mechanics work on how a slang register might
collapse or repurpose one of these functional slots (e.g. reciprocal-without-ся verbs as a small,
closed, sociolinguistically marked class already skewing toward register-neutral/formal collocation
verbs like сотрудничать).
