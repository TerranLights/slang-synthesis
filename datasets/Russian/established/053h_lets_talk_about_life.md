## Grammar points

### A cited real-world source flags тачка as slang via quotation marks rather than an explicit tag
Unlike the `(coll.)`/`(sl.)` bracket-tags used elsewhere in this book, тачка's slang status here is
marked implicitly — the excerpted 1994 magazine article itself puts «тачка» in guillemets within
running Russian prose, a native-speaker convention for flagging informal/slang vocabulary in print.
This is a different register-marking mechanism worth distinguishing in mechanics analysis: explicit
textbook glossing vs. the source text's own internal quotation-mark convention, both equally valid
evidence per the coverage rule but via different signal types.

### Cross-referencing accumulated root families
This chapter recycles at least three root families already documented in earlier chapters
(ступ-/preступление from Урок 2's file 053b; над-/на- from Урок 5's file 053e; рв-/рыв- reusing the
Митрич/сорвать example from Урок 3's file 053c) — direct textual confirmation that this book
deliberately reinforces earlier-taught roots in new topical contexts rather than introducing fully
disjoint vocabulary each chapter, useful context for treating this book's root families as one
coherent cross-chapter morphological dataset rather than nine separate ones.

### душа as a bridge between religious and secular/emotional register
Урок 6 (file 053f) documented душа in its religious sense (soul/afterlife). This chapter's
душа болит / душу отвести idioms show the same headword operating in ordinary secular-emotional
idiom, without religious content — worth preserving as a concrete example of a single word
supporting both a "core doctrinal" and a "colloquial emotional-idiom" register simultaneously.
