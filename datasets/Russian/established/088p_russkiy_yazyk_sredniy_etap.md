## What's kept as genuinely worth noting

**Full-name ↔ hypocoristic (nickname) correspondence table** (p. 243, "Некоторые русские имена") —
a systematic 19-entry table pairing full given names with their standard short/affectionate forms,
for both genders:

Selected examples (full → short): Александр → Саша/Шура; Алексей → Алёша/Лёша; Владимир →
Володя/Вова; Дмитрий → Дима/Митя; Михаил → Миша; Николай → Коля; Александра → Саша/Шура; Евгения →
Женя; Людмила → Люда/Мила; Мария → Маша; Надежда → Надя; Наталья → Наташа; Софья → Соня.

This is directly relevant to the slang-mechanics/word-formation-analysis phase, not because it's
new information (name hypocoristics are common knowledge and likely already touched on elsewhere in
this corpus) but because it's a clean, systematic worked example of Russian's productive
truncation-plus-suffixation clipping mechanism (Александр → Саш- + -а; Николай → Кол- + -я;
Владимир → truncated-and-resegmented Вов- + -а) — the same morphological mechanism that produces
colloquial/slang clippings from common nouns, illustrated here transparently on a closed, familiar
name set. Worth cross-referencing when the mechanics-analysis phase examines clipping/hypocoristic
suffixation as a slang-formation strategy.

Two names have **doublet short forms** worth flagging as a genuine finding: Александр/Александра
both reduce to the *same* short form set (Саша, Шура) regardless of gender — a rare case of a
Russian hypocoristic system neutralizing grammatical gender distinction that the paradigm otherwise
strictly maintains everywhere else in the table.
