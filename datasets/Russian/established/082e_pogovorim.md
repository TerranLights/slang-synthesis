## Grammar points

### Reproach/blame register cluster (Урок 5)

Framed box, p. 63 — this lesson's constructions are specifically for **marital/domestic
argument register**, distinct from Урок 1's soft advice-giving register:
- **`что бы (кому) + infinitive СВ`** / **`нет бы + infinitive`** — "you should have..." — a
  retrospective reproach for an action the addressee failed to take, drilled via a full couple's
  quarrel dialogue (p. 64) that models escalating reproach-and-counter-reproach turns.
- **`взял(а) бы да (и) + past-tense СВ`** — a more forceful version of the same, implying "you
  could have simply gone and done it (and didn't)."
- **`кто мог бы + infinitive СВ`** — softer counterfactual-ability reproach.
- **`какой смысл/зачем + infinitive НСВ`** — dismissing the addressee's proposed action as
  pointless (a rebuttal move within the same argument register).
- **Comparison construction**: `кто хуже/лучше + verb-personal-form`; `кто + comparative
  adjective` — register-neutral, used for the lesson's psychological-comparison tasks (p. 70),
  contrastable with the argument-register constructions above.

### Register note: gendered-conflict vocabulary and youth slang crossover

This lesson's "young people's survey" section (p. 68) is a notable crossover point where
register-neutral relationship vocabulary (упрекать, оправдываться, возражать, уступать) sits
directly alongside youth slang (доставать, крутой) inside first-person testimonial quotes — a
useful register-contrast data point for `analysis/`: the surrounding expository/task prose stays
neutral-to-formal while first-person quoted speech switches into slang, mirroring the same
pattern seen in Урок 2's teen-mother interview (`082b_pogovorim.md`).
