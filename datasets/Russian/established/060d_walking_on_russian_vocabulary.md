# Russian — Established Vocabulary/Grammar: Walking on Russian Vocabulary, Part 4 (Chapter 3, §1: Синонимы "Near-Synonyms" and §2: Паронимы "Paronyms")

**Source:** Е.Р. Ласкарева, *Прогулки по русской лексике*, Zlatoust, 2010. This part covers the
first two sub-sections of Chapter 3 ("Темы для изучения при высоком уровне владения русским
языком" — "Topics for study at an advanced level"): "Близкие по значению слова" (Synonyms),
printed pp. 122-130 (PDF pp. 124-132), and "Паронимы" (Paronyms), printed pp. 131-141 (PDF pp.
133-143). Same +2 PDF-to-printed-page offset confirmed empirically by re-rendering PDF p.124 and
reading its visible printed folio "122"; no text layer (fully vision-read); no marginalia found on
any page sampled.

**Coverage note — heavy compression on the Synonyms sub-section, fuller extraction of Paronyms.**
The Synonyms sub-section (9 pages, ~35 exercises of 10-12 items each) is almost entirely bare
word-clusters with no book-provided answer ("Объясните различия... придумайте предложения" — the
student supplies the distinction, the book supplies none until the answer-key appendix at the very
end of the book). Per the coverage rule, this file does **not** individually catalog the ~350+
words across those clusters — most are basic near-synonym sets (туча/облако, король/царь,
метро/метрополитен) with no register/grammar payload beyond "these are treated as a confusable
cluster." Instead this file extracts: (a) the sub-section's own methodological framing (its
"lexical compatibility"/collocation-first teaching principle, directly relevant to how the project
should think about near-synonym register clusters generally), and (b) every cluster that is
genuinely distinctive — i.e., mixes register tiers (slang/colloquial terms alongside neutral or
formal ones), reflects a folklore/occupational/political register split, or the source explicitly
flags a stylistic point itself.

The Paronyms sub-section (11 pages, ~47 exercises) is different in kind: every item is a genuine
lexical-nuance pair/triplet (same root, different derivational suffix, different — sometimes
sharply different — meaning), which is exactly the kind of "constrains how slang can even form"
content the extraction spec prioritizes. This file extracts the large majority of the paronym pairs
presented, grouped by shared root where the source itself groups them (e.g. all of
экономный/экономичный/экономический together), while still skipping a small number of exercises
whose pairs duplicate an already-captured root-cluster in a different sentence frame.

## Grammar points

### Register-first pedagogical framing (Синонимы sub-section, p.122-130)

The source explicitly separates two later-chapter topics up front: this sub-section covers
*heterogeneous* near-synonyms (unrelated roots, e.g. булка/хлеб), while the *following* sub-section
(Паронимы) covers same-root/similar-sounding confusables. A recurring instruction embedded in
several exercises — "обратите внимание на стиль" (pay attention to register) — is the sub-section's
real organizing principle: near-synonym clusters are pedagogically framed as **register clines**,
not free-variation sets, e.g. its own worked contrast of "вступить в брак" (formal/bureaucratic) vs.
"пожениться" (neutral) for the same real-world event. This is directly relevant to the project's
slang mechanics: the source treats "which member of a synonym cluster gets chosen" as itself a
register signal, exactly the phenomenon slang coinage exploits.

### Paronyms as a distinct category from synonyms (p.131, opening definition)

The source's own definition: paronyms are **etymologically related** (same root) words that differ
in a prefix or suffix and have "similar sound but different meaning" (e.g.
дипломатичный/дипломатический), distinguished explicitly from true synonyms. A genuinely useful
methodological note: some pairs the book treats as paronyms are, in the strict linguistic sense,
*not* true paronyms but simply two derivationally-related words worth teaching together (its own
example: дружный/дружеский); these dual-status exercises are marked in the source with an asterisk
(*).

### Closing "three truths" about paronyms (p.141, chapter-closing note)

The source explicitly closes the sub-section with three points, paraphrased: (1) paronyms are
different words that occupy different contexts — they are not interchangeable; (2) some paronym
pairs *can* function as near-synonyms in certain contexts, and these are the asterisked exercises;
(3) reading literary fiction both helps (broadens passive vocabulary) and hinders (authors favor
unusual/non-standard word choices, which can mislead a learner trying to internalize the
*normatively expected* paronym in a given slot) — a genuinely useful methodological caution for any
future corpus-based extraction work this project does from literary sources.

### Government-pattern paronyms, not just meaning-pattern ones

A subset of the paronym pairs above differ not just in meaning but in case-government behavior
(за + accusative vs. bare accusative for заплатить/оплатить; imperative-only distributional split
for представьте/предоставьте). Worth flagging separately from the purely lexical-semantic paronym
pairs, since this is exactly the kind of grammar-constraint information the coverage rule prioritizes
extracting.
