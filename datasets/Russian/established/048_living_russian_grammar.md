## Grammar points

### Compact case-government table for common prepositions taking the genitive (Unit 8, p. 24-26)

The book groups **у** (at the place of — used with быть/находиться/отдыхать/жить, never with verbs of
motion, contrast «я был у брата» vs. «я ездил к брату»), **от** (from/from someone's place — «я пришёл
от врача»), **без** (without), **кроме** (apart from/except for/as well as), **для** (for), **около**
(near to), **напротив** (opposite), **вокруг** (around), **недалеко от** (not far from), and **от...до**
(from...to) all as genitive-governing in one worked list with parallel example sentences. Useful as a
single compact index of Russian's genitive-preposition set — the heavier grammars (Wade, Timberlake)
scatter these across separate sections by preposition rather than presenting them as one lesson-scale
government table.

### Dative-governing verbs, grouped by function (Unit 9-10, pp. 28-34)

Distinctive groupings not previously captured together as short functional lists:
- **"Giving/communicating to" verbs** taking dative: давать/дать, дарить/подарить, посылать/послать,
  рассказывать/рассказать, говорить/сказать, советовать/посоветовать, звонить/позвонить,
  объяснять/объяснить, помогать/помочь, покупать/купить (as "buy for"), предлагать/предложить,
  мешать/помешать.
- **"Seeming/wanting/liking" verbs** taking dative subject-experiencer: хотеться/захотеться,
  нравиться/понравиться, казаться/показаться — plus принадлежать (belong to), желать/пожелать
  (wish for), представлять/представить (introduce to), напоминать/напомнить (remind), посвящать/
  посвятить (dedicate to), уступать/уступить (give way to).
- **Short-form adjectives taking dative** ("X is [adj] to/for me"): нужен, полезен, вреден,
  интересен, понятен, знаком, известен, необходим — plus рад and благодарен for the object of a
  feeling.
- **Дательный + к**: verbs of habituation/orientation (готовиться/подготовиться, привыкать/
  привыкнуть, обращаться/обратиться, относиться/отнестись, стремиться) and their derived nouns
  (подготовка, привычка, обращение, отношение, стремление) share the same case-government pattern —
  paired with abstract nouns of feeling that also take к (интерес к музыке, любовь к детям, уважение
  к родителям, ненависть к врагам). The prefix при- is called out as the marker for "joining
  something on to something else" with к (приписать к письму, прибавить к четырём).
- **Дательный + по**: three distinct uses grouped together — profession/subject-of-study
  (специалист по финансам, книга по географии), means of communication (говорить по телефону,
  смотреть по телевизору, услышать по радио, послать по электронной почте), and movement-along
  (идти по улице).

### Instrumental-governing verbs, grouped by function (Unit 12-13, pp. 40-46)

- **Characterizing/becoming** (X is/becomes Y): работать, быть, являться, становиться/стать,
  оставаться/остаться, казаться, оказаться — with the explicit note that работать кем (working
  *as*) contrasts with работать с кем (working *with*).
- **Area of interest/occupation**: заниматься, интересоваться, увлекаться.
- **Skill/control**: владеть (possess a skill — «он владеет пятью языками»), управлять, руководить,
  командовать, распоряжаться.
- **Other**: рисковать, гордиться, пользоваться, обладать, торговать, болеть (fall ill with).
- **Short-form adjectives taking instrumental** (no preposition): доволен, удовлетворён, богат, беден,
  удивлён; согласен takes instrumental *with* с (согласен с вашими предложениями).
- **С + instrumental for manner/appearance**: с интересом читать, с радостью согласиться, с
  удовольствием, and physical-description use (девушка с длинными волосами, мальчик с голубыми
  глазами).
- **Prepositions of place governing instrumental**: перед, за, над, под, рядом с, между — the same
  set doubles for temporal use (перед обедом, за обедом, между часом и половиной второго).

### The где?/куда?/откуда? three-column mnemonic (Unit 16, p. 54)

A compact three-column table pairing each question word with its case and preposition pattern that
is more pedagogically condensed than the equivalent (correct, but more diffusely presented) material
in the academic grammars: **где** (location) → в/на + prepositional (быть, жить, работать); **куда**
(destination) → в/на + accusative (идти, ехать); **откуда** (origin) → из/с + genitive (приехать,
вернуться) — with the mnemonic reduction **в → из**, **на → с** for picking the correct "from"
preposition given the "to" preposition already used for a place.

### чей/чья/чьё/чьи — full possessive-interrogative paradigm (Unit 4, p. 14)

Genuinely tidy consolidated paradigm table: чей (m.) / чья (f.) / чьё (n.) / чьи (pl.) against мой/
твой/наш/ваш in all four gender/number slots in a single grid — useful as a compact cross-reference
even though each individual form is already attested elsewhere.
