# Russian — Established Vocabulary/Grammar: Е.К. Нурмухамбетов, *Шаг за шагом* (full book)

**Source:** Е.К. Нурмухамбетов, *Шаг за шагом: Учебно-методическое пособие по русскому языку как
иностранному* (Минск, БГЭУ, 2010), full 123 pages — vision-read (no text layer; ABBYY FineReader
9.0-produced PDF with an empty text layer, confirmed via `pdftotext -layout` returning only
form-feed bytes). One PDF page = one printed page throughout (no spread-scan offset found; printed
page numbers run 4–123 across PDF pages 3–122, plus an unnumbered cover/colophon).

**Coverage note — heavily redundant supplement, most content skipped by design.** This is an
absolute-beginner (subject: "Это Антон. Это Анна.") lexico-grammatical exercise workbook for a
Belarusian university's foreign-student preparatory department, structured as 18 lessons
(Уроки 1–18) of fill-in-the-blank drills covering: noun gender/plural, personal/possessive/
demonstrative pronouns, present-tense conjugation, adjective agreement, the full six-case
declension system (introduced case-by-case across the lessons via "Где?/Куда?/Откуда?"-style
drills), aspect pairs (NCB/CB), numerals, and time expressions — every one of these topics is
already covered far more systematically and completely by this corpus's 32+ prior grammar
references (Timberlake's *A Reference Grammar of Russian*, Wade's *A Comprehensive Russian
Grammar*, `040_moi_druzya_padezhi.md`'s preposition-by-case spatial map, `065_the_case_book_for_
russian` for case semantics, etc.). Per the non-redundant-supplement pattern, **all 18 lesson
chapters (pp. 6–91) were reviewed at full-lesson-boundary sampling density and confirmed to
contain zero grammar points, vocabulary items, or dialectal/register annotations not already
captured elsewhere in this corpus** — every example sentence uses the same closed set of ~150
core beginner nouns/adjectives (студент, комната, друг, окно, красивый, новый, etc.) recycled
lesson to lesson, with no register variation (no colloquial/formal/regional tags anywhere in the
book) and no slang. The answer-key section (pp. 112–123, "Ключи к упражнениям и заданиям") is pure
drill answers and was confirmed skippable per this project's established precedent (cf.
`048_living_russian_grammar.md`).

**What was kept:** the book's back-matter reference-tables appendix (pp. 92–111, "Таблицы 1–20")
is a systematic collection of paradigm and collocation tables. Most of these (case-ending paradigms
for adjectives/pronouns, в/на/из + destination-noun collocation lists, the calendar/time-expression
tables) restate material this corpus already has in more depth. **One table is a genuine, distinct
find not previously captured in this corpus: Таблица 19, a systematic full-name → hypocoristic/
diminutive-name mapping** for the ~30 most common Russian male and female given names. This is
kept below as it's directly relevant to future slang-mechanics work on affectionate/informal
address-form derivation (a productive register-shifting suffixation pattern this corpus has not
yet tabulated this comprehensively in one place). A handful of illustrative preposition-government
examples from Таблица 20 are also noted for their example sentences (some genuinely vivid/unusual
compared to typical textbook filler), though the preposition-by-case-by-meaning structure itself
duplicates `040` and other prior sources.

**Vision-reading guard:** the entire book (all 123 pages) is a clean, undamaged, unmarked scan —
no handwritten marginalia, underlining, or pencil answers were found anywhere in the file (unlike
the "used workbook copy" cases documented in `057` and `054`). All print is a clean, consistent
sans/serif typeset matching the rest of the book throughout.

**Morpheme breakdown (illustrative, hypocoristic derivation).** The table above documents a
productive register-shifting derivational pattern relevant to slang-mechanics analysis: full civil
name → truncated stem + informal/affectionate suffix.

> **Владимир → Володя** = Влади- (truncated stem, first two syllables of the full name) + -оди-
> (interfix) + -я (diminutive/hypocoristic suffix, unstressed nominal ending marking informal
> address). A second, unrelated hypocoristic **Вова** shows the same name can support two
> co-existing informal derivations built from different truncation points, not a single fixed rule.

> **Александр(а) → Шура** = a non-transparent hypocoristic (no shared onset with the full name;
> historically derived via an intermediate form no longer in productive use) — illustrates that
> this derivational pattern is not purely phonological truncation but includes a closed set of
> lexicalized, non-compositional hypocoristic forms that must be learned as pairs rather than
> derived by rule. **Олег → Алик** is a second clear example of the same non-transparent type.

## Grammar points

### Overall lesson sequence (redundant; not re-tabulated)

The 18 lessons introduce, in order: noun gender via pronoun substitution (он/она/оно, Lessons
1–3); regular plural formation including the -а/-я irregular-stress-shift plural class (брат →
братья, друг → друзья, стул → стулья, сын → сыновья, дерево → деревья, p. 11); possessive
pronouns мой/твой/наш/ваш/его/её/их and свой (Lessons 1–3, 8); present-tense conjugation of
first- and second-conjugation verbs (Lessons 3–5); adjective–noun gender/number agreement (Lesson
4); adverbial "по-русски"-type language-name adverbs (Lesson 4, with an 18-country vocabulary
list, p. 14–15 — entirely core-tier country/language nomenclature already attested throughout this
corpus); the case system introduced one case per lesson roughly in the order prepositional
(location) → genitive (source) → accusative (object/destination) → dative → instrumental (Lessons
6–13); aspect pairs and past tense (Lessons 9–10); numerals, dates, and time expressions (Lessons
14–17); and a review/conversation lesson built around ~40 questions about the student's home
country and about Belarus (Lesson 18, pp. 90–91 — pure conversation-practice content, not
extractable vocabulary or grammar).

All of this duplicates prior established files in far greater depth and with fuller paradigm
tables (see especially `002/003_comprehensive_russian_grammar`, `006/007_reference_grammar_of_
russian_cambridge`, and `040_moi_druzya_padezhi` for the case-by-preposition material specifically).
No new rule, exception, or dialectal/register annotation was found in any of the 18 lessons.

### Appendix reference tables (pp. 92–111) — redundant paradigm/collocation restatement

Таблицы 1–3 (not examined in detail, gender/number paradigms), 4–6 (adjective/demonstrative/
который declension paradigms, singular and plural, all six cases), 7–9 (systematic идти/ехать +
в/на destination-collocation lists and where/to-where/from-where three-column preposition-government
tables, ~70 nouns), and 11–18 (date/day/month/week/season/time-of-day expression tables, and a
mixed-declension-type -ь-final noun gender-disambiguation list) all restate paradigms this corpus's
prior Russian grammar references already cover, in most cases with more exceptions and more
complete paradigms (e.g. the six-case tables here give only the regular hard/soft adjective
endings, omitting the spelling-rule exceptions after ш/ж/ц that Wade and Timberlake both document).
Таблица 20 ("Русские предлоги и их значения," pp. 109–111) is a genuinely well-organized single-page
prepositions-by-case-by-meaning-by-example reference (~35 prepositions), but its content — which
preposition governs which case and what it means — again duplicates material already captured from
this corpus's core grammar references; a few of its example sentences are distinctive for being
more vivid than typical textbook filler (e.g. «Волшебник прошёл сквозь стену» — "The magician
walked through the wall"; «Снайпер выстрелил, но попал мимо цели» — "The sniper fired but missed
the target"), but these are illustrative sentences, not new grammatical or lexical content, so they
are noted here rather than tabulated as vocabulary.
