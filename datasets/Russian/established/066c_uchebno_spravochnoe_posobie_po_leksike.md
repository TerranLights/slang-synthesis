## Grammar points

### Continuation of the `-н-//-ственн-` suffix set

This shard completes the 8-pair set named on p.67 of `066b`: безответный-безответственный,
дружный-дружественный-дружеский, искусный-искусственный, умный-умственный, явный-явственный,
тайный-таинственный (a second, separately-headed instance of the same suffix pair, p.79 — the book
revisits `-н-//-ственн-` for a semantically unrelated headword set after the ordinal-numeral group),
and двойной-двойственный-двоякий-тройной-тройственный (a 5-way cluster spanning two suffix
patterns at once, treated as one entry group, p.76-78).

### New suffix set: `-н-/-ичн-//-еск-/-ическ-` (p.81 onward)

A four-way suffix contrast (rather than the simpler two-way `-н-//-Х-` pattern used earlier):
`-ичн-` forms tend to describe a concrete object/person's trait that merely satisfies or resembles
the base noun's domain (гигиеничный костюм = "a hygienic — i.e., hygiene-compliant — suit";
дипломатичный человек = "a tactful person"), while `-ическ-` forms describe the abstract
discipline/institutional domain itself or formal terminological compounds within it (гигиенический
= "of hygiene-the-practice"; дипломатический = "of diplomacy-the-institution"). This is a
productive, systematic four-way suffix family in Russian adjective derivation from Greco-Latinate
loan roots (гигиена, дипломатия, истерия, критика, логика, педагогика — all internationalisms) —
notably distinct from the native-root suffix pairs seen earlier in the section.

### Homonym-splitting as a lexicographic device (КРИТИЧЕСКИЙ¹/²)

Unlike every other multi-sense headword in this book (which lists senses 1, 2, 3... under one
headword), КРИТИЧЕСКИЙ is split into two superscript-numbered homonyms (критический¹ = "of critical
analysis," критический² = "of a crisis/dangerous juncture") — the book's authors evidently judged
these two clusters of meaning to be historically/semantically distinct enough (from критика vs.
кризис respectively, despite the identical surface adjective) to warrant separate headword status
rather than polysemy under one entry. Worth flagging for later mechanics-analysis work on how this
project's own conlang-synthesis phase might model true homonymy vs. polysemy divergence.
