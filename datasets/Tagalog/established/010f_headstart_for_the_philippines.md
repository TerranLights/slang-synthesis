(Modules I-V, 1st edition, February 1985), pp. 229-283 — Cumulative Glossary (Pilipino-English,
pp.229-258; English-Pilipino, pp.259-283) plus the Numbers appendix (pp.284-285). Continues

**Coverage note — this file is a deliberate departure from the per-chapter extraction pattern used
in files 003-003e, and the scope decision is stated here explicitly per the project's
non-redundant-supplement convention:**

The book's own Cumulative Glossary is, by its nature, a full alphabetized re-listing of
essentially every vocabulary item already taught (and already captured) across Modules I-V — it is
not new teaching content but an index back into material already extracted chapter-by-chapter in
files 003-003e. The English-Pilipino half (pp.259-283) in particular was confirmed, on direct
inspection, to be a pure reverse-sorted re-index of the same Pilipino-English entries with no new
lexical content. Reproducing the glossary's ~1,400 entries in full would be bulk duplication of
already-captured vocabulary, not a genuine coverage gain. **What follows is only the material
confirmed genuinely new** after reading the entire glossary against files 003-003e: vocabulary
items that did not appear in any unit's conversation/notes/exercises, one grammar pointer the
glossary references but the per-unit notes never actually explained, and two incidental
orthographic/register observations. The Keys section (pp.187-228, answer keys to the Self-
Evaluation Quizzes) was skipped entirely — it is drill-answer content, not new vocabulary or
grammar, per the coverage rule.

## Grammar points

### The `ay`-inversion construction (referenced, not explained, by the per-unit notes)
The glossary's entry for `ay` (p.231) describes it only as a particle "used to mark an inverted
sentence," explicitly cross-referencing "Mod. I, Unit 2, Ex. 23" for the worked example — but
Exercise 23 in that unit is an unglossed "Say in English" listening drill (no Pilipino text is
printed on the page itself), so this construction was never actually surfaced in files 003-003e's
per-unit extraction. This is a genuine grammar-coverage gap the glossary catches: Tagalog's
unmarked word order is predicate-initial (topic-final, as seen throughout this course's `Magandang
gabi po` / `Mainit sa Pilipinas` type sentences), but an `ay`-marked construction allows the topic
to front, inverting that default order (topic + `ay` + predicate) — a genuine syntactic alternation
this FSI course gestures at via its glossary cross-reference but never actually teaches with a
worked example in the units extracted.

### Register note: the abakada letter order
The glossary is alphabetized by the traditional Filipino "abakada" letter sequence (A, B, K, D, E,
G, H, I, L, M, N, NG, O, P, R, S, T, U, W, Y), not the Latin ABC order — confirmed directly by
encountering the Pilipino-English glossary's section breaks in that exact sequence (A, B, then K
before D). This is a minor but genuine orthographic/cultural convention worth noting for any future
Tagalog source that similarly alphabetizes by abakada rather than Latin order.

### Register note: C.R. as a borrowed-initialism euphemism
`kasilyas` (the plain native term for "toilet," already captured from the Module V emergency
dialogue) is glossed in the English-Pilipino direction with a second English-initialism option,
`C.R.` ("Comfort Room") — a loan-euphemism pattern distinct from the native-root euphemisms seen
elsewhere in this course, worth flagging as a `euphemism_chain`/`borrowing`-type mechanism candidate
for Phase 3 analysis.

## Numbers appendix (pp.284-285) — consolidation note, not reproduced in full

The appendix gives a clean side-by-side Tagalized-Spanish/Pilipino table for 1-100 (by tens, with
the 21-59 pattern spelled out as `[tens]+y+[units]` / `[tens]+'t+[units]`) and for the hundreds
100-2,000 (`siyento`/`sandaan` through `dos mil`/`dalawang libo`). Every individual number in this
table was already captured piecemeal across files 003b, 003d, and 003e; the only genuinely new data
point is the appendix's top end, **2,000 = `dos mil` (Tagalized Spanish) / `dalawang libo`
(Pilipino)** — one step beyond the highest number (1,000) captured in file 003e.
