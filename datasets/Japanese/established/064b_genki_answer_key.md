# Japanese — Established Vocabulary/Grammar: Genki Answer Key I and II (coverage assessment — mostly skipped)

**Source:** Eri Banno, Yutaka Ohno, Yoko Sakane, Chikako Shinagawa, Kyoko Tokashiki, *Genki: An
Integrated Course in Elementary Japanese — Answer Key* (I and II combined), The Japan Times. 73
pages, vision-read (no text layer; `pdftotext` confirmed empty).

**Coverage note / scope decision.** This is a pure answer key to a different, well-known course
(*Genki I and II*, the main textbook volumes are not present in this project's source set — only
the standalone answer-key booklet is). Per dispatch instructions, this source carries low
standalone content value and was sampled (not fully vision-read) to confirm whether it contains any
genuine explanatory content alongside the bare answers, which would have justified a fuller
representative extraction.

**Sample checked:** pp. 1–5 (PDF), p. 34 (PDF, mid-book, Genki I Workbook answers for Lesson 7–8),
and p. 60 (PDF, late-book, Workbook listening-script transcripts for Lessons 8–9).

**Finding: the book is exhaustively bare-answer/transcript content, with no grammar explanation or
vocabulary-gloss material of the kind this project's extraction targets.** Every page sampled fell
into one of two categories:

1. **Grammar/conversation-workbook answer sections** (e.g. 第1課, 第7課, 第8課): numbered fill-in
   answers only — single words, short phrases, or full sentences given as the "correct" answer to
   an exercise prompt that itself does not appear in this book (the prompts live in the separate
   *Genki* main textbook, not present in this project's source set). No paraphrase, no rule
   statement, no usage note of any kind accompanies any answer.
2. **"聞く練習" (listening practice) script transcripts** (e.g. p.60/PDF): verbatim dialogue scripts
   for the course's audio listening exercises. These are connected conversational Japanese (unlike
   the bare-answer sections) and contain some natural colloquial forms (e.g. そうね, ～と思う reported
   speech, ぜんぜん～ない), but they are **dialogue transcripts of the textbook's own scripted
   exercises** — not explanatory prose, not a vocabulary list, and not distinct from material a
   full Genki extraction would eventually capture with better context (if the main Genki textbooks
   are ever added to this project's source set). Reproducing them here would mean bulk-reproducing
   dialogue blocks, which the copyright discipline rule explicitly prohibits, for content that adds
   no grammar/vocabulary-reference value on its own (no gloss, no part-of-speech tagging, no usage
   tier — just a transcript).

**Decision: this source is documented as skipped, per the coverage rule's "otherwise document as
mostly skippable" instruction** — no vocabulary table or grammar-points section is produced because
no qualifying content was found beyond bare answers and exercise-dialogue transcripts. If the main
*Genki I* and *Genki II* textbooks (as opposed to this answer-key-only booklet) are ever acquired
for this project's source set, they would be a legitimate extraction target in their own right
(real explanatory grammar prose and a real vocabulary glossary), independent of this file.

No handwritten marginalia was observed on any of the sampled pages (all content, including a visible
third-party "Shared by Skankfish215" watermark on the cover page, is print/digital, not handwritten
annotation — the watermark itself is not source content and is noted here only for completeness).
