# Japanese — Established Vocabulary/Grammar: Writing System Foundation (superseded — see 004)

**This file is intentionally emptied of content.** An earlier pass of this dispatch vision-read
katakana-teaching and "Final Review" pages from
`source_reference/languages/Japanese/02.Japanese Writing System/A guide to writing Kanji and Kana
Book 1.pdf` and began extracting them here. Cross-checking against this folder's existing files
established that this PDF duplicates, verbatim, the content already fully and correctly extracted
from the clean standalone source at `001b_guide_to_hiragana_katakana_katakana.md` and
`001d_guide_to_hiragana_katakana_final_review.md` (Henshall & Takagaki, *A Guide to Learning
Hiragana and Katakana*, Tuttle 1990) — confirmed by direct string match on multiple entries (e.g.
テ → 天, ト → 止, ラ → 良, リ → 利; ダブル, ジグザグ, ワープロ, パチンコ, アルバイト all appear
identically in both). See `004_writing_kanji_kana_book1.md` for the full explanation of how this
PDF bundles two different books together, and `004c_writing_kanji_kana_book1.md` for this PDF's
actual unique content (the Hadamitzky & Spahn kanji-entry section).

No vocabulary/grammar tables are kept in this file to avoid shipping a redundant, lower-quality
duplicate of the 001-series extraction.
