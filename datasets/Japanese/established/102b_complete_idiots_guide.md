**Source:** Naoya Fujita, Ph.D., *The Complete Idiot's Guide to Conversational Japanese* (Alpha

**Coverage note.** Unlike Parts 1-2 (pure grammar, heavily redundant with the existing corpus),
this is genuinely new territory: a travel-phrasebook's social/register-marked everyday vocabulary

grammar-reference and textbook sources) covers far more thinly. Extracted in full, including the
book's own explicit formal/informal/casual register labels wherever it supplies them — per the
extraction spec's instruction to never skip explicit register annotation. Repeated dialogue drills
that don't introduce new vocabulary are skipped.

## Grammar points

### Register ladders as a recurring structural device in this book

Across this Part, the book repeatedly presents **explicit 2-4-tier politeness ladders for the same
communicative function** rather than a single fixed phrase: "I'm going" (Iku/Ikimasu/Mairimasu,
p.15, in the earlier cultural chapter but directly comparable), "thank you" (Arigatō → Dōmo
arigatō → Dōmo arigatō gozaimasu, with saNkyū as a youth-slang outlier, p.97), and "good-bye"
(Shitsurei shimasu [formal] → Soredewa → Sorejā → Jā/Jāne [casual], p.99). This is a recurring,
source-confirmed structural pattern — not just scattered formality notes — and is directly useful
scaffolding for later slang-mechanics work on how an invented register system could model
formal↔casual gradients for a single communicative function.

### Plain vs. polite kinship-term pairing

The family-member vocabulary table (p.123) systematically pairs every kinship term with two forms:
a plain form used when speaking of one's own family, and a polite (usually o-/-saN-marked) form
used when speaking of someone else's family — e.g. chichi (my father) vs. otōsaN (your/someone's
father). This in-group/out-group register split, applied uniformly across an entire semantic field
(kinship), is a clean structural example of a broader Japanese honorific mechanism (the uchi/soto
"in-group/out-group" distinction) and is recorded here as a vocabulary table rather than re-explained
as grammar, since the existing honorific/keigo-focused sources (e.g. `041*` "Japanese Respect
Language") already cover the underlying mechanism in more depth.

### ko-so-a-do demonstrative paradigm

Pp.109-110. All four Japanese demonstrative series (kore/sore/are/dore "this/that/that-over-there/
which," kono/sono/ano/dono + noun, koko/soko/asoko/doko "here/there/over there/where") share the
same four-way root pattern (ko-so-a-do), which the book gives as an explicit mnemonic. Standard
material, included here mainly because the vocabulary itself is given in full and ties directly
into the pronoun-drop/zero-anaphora discussion from Part 1-2.
