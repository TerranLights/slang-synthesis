# Japanese — Established Vocabulary: Japanese in Mangaland Vol. 1, Appendix IV (Vocabulary Index)

**Source:** Marc Bernabé, *Japanese in Mangaland, Vol. 1* (expanded English edition, Japan
Publications Trading Co., 2005), Appendix IV "Vocabulary index" (語彙索引), pp. 278–293. Vision-read
from the same no-text-layer DjVu file as `070_japanese_in_mangaland.md` — see that file for full
source citation and sampling methodology.

**Coverage note — representative sampling of an alphabetical index.** This appendix is a single
continuous A–Z vocabulary index covering the whole book's ~30 lessons, with part-of-speech
abbreviations and a lesson-number cross-reference per entry. Rather than extract every one of its
~800+ entries, this file samples letter-sections B, D, E, F, G, H (partial), I, J, K, M, N, O, P
(partial), R (partial), T (partial), U, V, W, Y — chosen for broad alphabetical spread and because
several of these sections are unusually register-dense (the book explicitly tags entries as
"(vulgar)", "(threat)", "(jargon)", "(childish)", "(affectionate)", "(colloquial, masc.)", etc., which
is exactly the kind of explicit register annotation this project's extraction spec prioritizes).
**Not sampled:** letters A, C (most), H (most), L, N (most), P (most), Q, R (most), S, T (most), X, Z.
This index is itself a secondary compilation (every entry cross-references back to the lesson it
first appeared in), so it substantially overlaps with vocabulary already seen in context in
`070_japanese_in_mangaland.md`; entries below are kept because the index's own register/usage-note
column surfaces several items whose connotation was not otherwise obvious from the lesson body (e.g.
yakuza/jargon/threat vocabulary from Lesson 23, which this sampling pass did not otherwise visit in
the main lesson pages).

**No marginalia found.** All sampled index pages were clean, consistently typeset print in a
two-column-per-entry tabular layout (term / kana-kanji / POS tag / lesson number / gloss); no
handwritten annotation observed. Vision reading confidence `verified` throughout — the index's own
internal structure (alphabetical order, consistent column format) make misreads self-evident, and no
ambiguous entries were encountered.

**Part-of-speech abbreviation key** (as used by the book itself): N = noun, V = verb (godan/group 1
unless marked), V1/V2 = ichidan (group 2) verb, Vn = noun that takes する, iAdj = -i adjective, naAdj
= -na adjective, PN = pronoun, Adv = adverb, Ph = fixed phrase, O = onomatopoeia, C = counter,
Sf = suffix, T = toponym/proper noun.

## Grammar points

### Register-tagged body-part idiom family (口が~, 耳が~, etc.)
The index surfaces a systematic pattern the main lesson pages sampled in
`070_japanese_in_mangaland.md` did not: a productive family of idioms built on `{body part} + が +
{-i adjective}` that shift meaning away from the literal body part toward a character trait or
state — 口が軽い/堅い/悪い ("loose-mouthed / tight-lipped / foulmouthed"), 鼻が高い ("proud"), 耳が痛い/遠い
("ashamed to hear" / "hard of hearing"). All are listed under Lesson 26's vocabulary, which this
sampling pass did not visit directly in the main lesson body — recovered only via the index.

### Explicit three/four-way register minimal sets
The index's own usage-note column repeatedly documents the same meaning realized across multiple
explicit register tiers within a single lesson — not inferred by this extraction, but directly
labeled by the book: "I'm hungry" as 腹が減った (vulgar) / お腹がぺこぺこ (childish) / お腹がすいた (neutral,
L.27); "I'm sorry" as ごめんね (colloquial) / ごめんなさい (neutral) / 申し訳ない (formal, L.27); "just as I
thought" as やっぱり (informal) / やはり (formal, L.22). This is a strong, source-internal confirmation
of the register taxonomy this project already uses (`00_Usage_Tier_Taxonomy.md`), and the clean
three/four-way splits are worth flagging as a reusable pattern for later mechanics-analysis work on
Japanese register.

### Yakuza/underworld jargon as a distinct register cluster
Lesson 23's vocabulary, recovered through the index, forms a tight thematic cluster explicitly
labeled "(jargon)" by the book: weapons (ハジキ, チャカ — two independent slang synonyms for "gun"),
people (チンピラ "small-time thug," 親分/子分 "boss/subordinate," 組/組長 "gang/gang leader"), drugs (ブツ),
and values vocabulary (任侠, 仁義 — both glossing to "yakuza code of honor/chivalry"). This is a
self-contained register/domain worth treating as a unit in later slang-synthesis mechanics work,
since it shows a real-world model for how a conlang's own underworld-slang layer might cluster
(weapons + hierarchy terms + in-group values vocabulary, not just insults).
