# Japanese — Established Vocabulary/Grammar: *A Guide to Writing Kanji and Kana, Book 2*, Kanji 779–846

**Source:** Wolfgang Hadamitzky and Mark Spahn, *A Guide to Writing Kanji and Kana, Book 2*
(Charles E. Tuttle Company, Rutland, VT and Tokyo), Tuttle Language Library self-study workbook.
PDF pages 4–23 of 310 (printed pages 7–23), covering kanji entries numbered 779–846. This volume
is the direct continuation of Book 1 (established/004): Book 1 covers kanji 1–778, Book 2 covers
kanji 779–1,945, together presenting all 1,945 Jōyō Kanji. Companion sibling volume 004 is being
extracted in parallel by a separate subagent.

**No text layer** (confirmed via `pdftotext`/`pdfinfo` — the PDF was produced by Adobe Acrobat's
Image Conversion Plug-in, a pure page-scan with no OCR text layer). **All content in this file is
vision-read from rendered page images** (`pdftoppm -r 100`). No handwritten marginalia was found
on any page processed so far — all content is clean typeset print; this note will be repeated/
updated if marginalia appears in later continuation files.

**Format of this source.** Each kanji gets one numbered entry box containing: the character itself
with numbered stroke-order; up to three "basic graphical element" (radical/component) codes; the
ON reading(s) in SMALL CAPS and kun reading(s) in *italics* with the inflecting tail in parentheses,
followed by the core gloss(es); and five (occasionally fewer) example compound words, each with
its own kana/kanji form, romanized reading, English gloss, and a cross-reference number (or
numbers) pointing to the other entry/entries in this same two-book set where a component of that
compound is itself a headword. **Those cross-reference numbers are the book's own internal index
and are not reproduced here** (they only resolve within this book's private numbering and have no
standalone research value for this project; the compound's own reading and gloss are kept in full).

**Coverage note.** This is a pure writing-practice drill book: beneath each entry's reading/compound
box is a large empty grid of writing-practice squares (3 light-gray "trace" cells followed by many
blank cells). **These grids are the repeated-drill content the coverage rule says to skip** — they
contain no new information (just repetitions of the same single character already captured from
the entry box above). Only the entry box itself (character, readings, 4–5 compounds) is extracted
per entry.

**Vocabulary-item granularity.** Per the extraction spec's "every distinct vocabulary item" rule,
each kanji headword *and* each of its example compounds are both genuine distinct vocabulary items
(the compounds are real, usable Japanese words, not just drill filler), so each gets its own table
row. Given this book's sheer scale (1,167 kanji in this volume alone, ~5 compounds each), expect
later continuation files (005b, 005c, ...) to carry the remainder — see the continuation note at
the end of this file.

**Script-form convention (Japanese-specific, per `00_Extraction_Checklist.md`):** the `Term` column
always carries the actual kanji/kana form first, followed by the romanized reading in parentheses,
e.g. `講義 (kōgi)`. Kanji headwords show their isolated character plus ON/kun readings together in
`Term`, with the full reading breakdown repeated in `Notes` since a single kanji can carry multiple
ON and kun readings that don't fit cleanly into one romanization slot.

## Grammar points

This source is a pure character-writing workbook, not a grammar textbook — it has no discursive
grammar sections of its own (beyond the front-matter Introduction, paraphrased above in the
coverage note). The closest analog to "grammar points" here is the systematic on-reading/kun-
reading/okurigana presentation pattern itself, which is a genuine piece of orthographic
information worth naming explicitly:

### ON/kun reading notation convention

Each entry marks ON (Sino-Japanese) readings in small caps and kun (native Japanese) readings in
italics, with the inflecting verb/adjective tail set off in parentheses after the reading's
invariant stem (e.g. *so(meru)* = the stem *some-* plus the dictionary-form ending *-ru*, read
together as *someru*). A bracketed reading in square brackets (e.g. `[ko]`, `[shu]`, `[sa]`) marks
a rarer/restricted-use alternate reading that the book itself flags as secondary. Multiple kun
readings on a single kanji (e.g. 染 with four: *so(meru)*, *so(maru)*, *shi(miru)*, *shi(mi)*)
reflect genuinely distinct derived verb/noun forms sharing one character, not free variation — the
book glosses each with its own distinct sense, which this file preserves per-reading in the `Notes`
column rather than collapsing to one entry.

### Graphical-element (radical) indexing

Every entry also lists up to three alphanumeric "basic graphical element" codes (e.g. `7a`, `3k`,
`3b`) directly beneath the kanji's practice box. These are the book's own component-indexing scheme
(cross-referenced to its own radical index, not reproduced here) used to group kanji sharing a
common visual/semantic building block — e.g. entries 790 (傘) and 805 (均) both carry code `2k` for
their shared "even/flat" element. This book-internal indexing system itself is noted for context but
not independently useful outside this volume's own index, so individual codes are recorded in
`Notes` per entry without further decoding.
