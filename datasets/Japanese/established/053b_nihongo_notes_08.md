# Japanese — Established Vocabulary/Grammar: Nihongo Notes 8 (Situational Japanese 3), part 1

**Source:** Osamu Mizutani & Nobuko Mizutani, *Nihongo Notes 8: Situational Japanese 3* (The Japan
Times, 1st ed. September 1987). Full volume: a compilation of 74 columns from *The Japan Times*
(Feb. 16, 1986 – Jul. 19, 1987), printed pp. 8–155 (index at p.156). This is the third volume in
the 10-volume *Nihongo Notes* series (see sibling files `established/053` for vols. 7-8's original
combined dispatch and `established/054` for vols. 9–10).

**Why this file exists:** `established/053_nihongo_notes_07_08.md` closed with a note claiming "all
148 essays (74+74)" from both vol. 7 and vol. 8 were captured, but an audit found every single row in
that file tagged "Vol.7 p.NNN" — zero rows tagged "Vol.8" anywhere. Direct inspection confirmed the
claim was false on two counts: (1) vol. 8 was never touched at all — not a citation-formatting
mistake, genuinely absent; and (2) vol. 7 itself is also incomplete within that file — its own
content stops at p.118-119 (essay 56 of 74; pages 120-155 / essays 57-74 are missing), with no
closing note reflecting this, apparently an interrupted extraction run whose header was written
aspirationally or carried over before the work actually finished. This file (053b onward) supplies
the genuinely-missing vol. 8 content. **Vol. 7's own gap (essays 57-74, pp.120-155) is a separate,
still-open problem, flagged here for the project orchestrator — it is out of this dispatch's scope
(which was specifically to resolve vol. 8), but should not be assumed fixed.**

**Coverage note:** No text layer in the PDF (`pdftotext` returns empty output; confirmed via
`pdfinfo`/`pdftotext -f 1 -l 5`). Vision-read from rendered page images (150dpi, `pdftoppm`). Each
PDF page image is a two-printed-page spread, not one page per image — confirmed empirically (image 5
→ printed pp.8-9, matching the `image i → printed pages 2i-2/2i-1` mapping already established for
vol. 7 and vols. 9-10). Front matter occupies printed pp.1-7 (images 1-4); the 74 situational-usage
essays occupy printed pp.8-155 (images 5-78), one essay per 2-page spread. This part (053b) covers
essays 1-9, printed pp.8-25 (images 5-13). Every grammar/usage point and distinct illustrative
vocabulary/phrase item in this range is captured; direct example sentences are reproduced only as
short illustrative quotes, per copyright discipline — narrative framing and explanatory prose is
paraphrased throughout.

**Vision-reading guard note:** The title page (image 1) carries handwritten/stamped library
