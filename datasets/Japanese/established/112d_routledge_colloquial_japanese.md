## Grammar points

### Indicating things (1): kore/sore/are/dore
A pronoun-level demonstrative system parallel to koko/soko/asoko/doko (Unit 3) but referring to
things rather than places: kore (this), sore (that, near listener), are (that, distant), dore
(which one, among 3+). p. 45.

### dore vs. dochira
**dore** is used when choosing among three or more items; **dochira** (introduced in Unit 3 for
places) is reused here for choosing between exactly two items — the answer correspondingly uses
kore/sore/are for a dore-question but kochira/sochira/achira for a dochira-question. p. 46.

### Indicating things (2): kono/sono/ano/dono + noun
When a demonstrative modifies a following noun directly, the pronoun forms' final "-re" is replaced
by "-no": kore→kono, sore→sono, are→ano, dore→dono (e.g. kono hon "this book", dono tokē "which
watch"). p. 48.

### Loanword clipping
Japanese freely borrows multi-word English compounds as loanwords and then clips them to two-mora
or four-mora abbreviations: konbiniensu sutoā → konbini, pāsonaru konpyūta → pasokon, dejitaru
kamera → dejikame, rimōto kontorōrā → rimokon, eā kondishonā → eakon. This is a systematic word-
formation process (not sporadic slang) worth flagging for the conlang slang-synthesis pipeline as a
model "formal register borrows a loanword, informal register clips it" pattern. p. 47.

### Numbers up to 1,000,000: hyaku/sen/man
Large numbers build on hyaku "100", sen "1,000", and man "10,000" (not "million" — Japanese counts
in units of 10,000, so 1,000,000 = hyaku man "100 × 10,000", not its own root). Several digit+hyaku
or digit+sen combinations undergo irregular sound changes (consonant gemination or voicing): san +
hyaku → sanbyaku (300); roku + hyaku → roppyaku (600); hachi + hyaku → happyaku (800); san + sen →
sanzen (3,000); hachi + sen → hassen (8,000). This irregular-combination-at-morpheme-boundary
pattern recurs across several numeral domains in this book (days of month, o'clock) and is a
recurring flag for how a "regular" numeral system still accumulates lexicalized sandhi exceptions
at high frequency. p. 51.
