## Grammar points

### 「〜と言います」(the quotative "it's said as ~")

Used to introduce a fixed idiomatic phrase as the conventional way something is expressed — e.g.
"when X happens, people say '~'." Framed in the lesson as the pattern for presenting Japanese
figurative idioms (p. 3, pattern A).

### 「たとえ〜ても」("even if ~")

Concessive construction: even granting the premise introduced by たとえ, the consequence still
doesn't follow — paraphrased example from the text: "たとえ猫が手伝ってくれても、それほど役に立つとは
思えません" ("Even if a cat helped, I don't think it would be all that useful") (p. 3, pattern B).

### 「〜ほど〜はない」("nothing is as ~ as ~")

Superlative-by-negation construction: asserts that nothing surpasses the stated item along the
given quality. Source's own illustrative example: "面白い言い方はいろいろありますが、「猫に小判」という
言い方ほど面白いものはないでしょう" ("There are many amusing expressions, but none more amusing than
'koban to a cat'") (p. 3, pattern C).
