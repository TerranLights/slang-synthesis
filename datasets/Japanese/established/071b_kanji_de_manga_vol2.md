# Japanese — Established Vocabulary/Grammar: Kanji de Manga, Volume 2

**Source:** Glenn Kardy (creator) & Chihiro Hattori (art), *Kanji de Manga: The Comic Book That
Teaches You How To Read And Write Japanese!*, Volume 2 (Manga University / Japanime Co. Ltd.,
Tokyo/San Francisco; 1st edition March 2005, 2nd edition October 2005; ISBN 4-921205-03-5), full
52-DjVu-page volume (= 108+ printed pages). Covers all 80 kanji required for JLPT Level 3 (the
old-numbering intermediate level, now roughly N4) — a second, non-overlapping 80-character set from
the same `Kanji de Manga` series already extracted as `011_kanji_de_manga_1.md` (that volume covered
the JLPT Level 4/N5 set). Together, per this book's own introduction, the two volumes' 160 kanji are
framed as the reader's complete character set going forward.

**Duplicate-check note (per dispatch instructions, cross-referenced from `071_kana_kanji_de_manga.md`).**
This file is the distinct-content counterpart flagged in that dispatch: `Kanji de manga vol 1.pdf`
(106 pages) in the same source folder was confirmed to be an identical duplicate of the
already-extracted `011_kanji_de_manga_1.md` and was **not** re-extracted. `Kanji de manga vol 2.djvu`
(52 DjVu pages, this file) is a genuinely distinct second volume — a different 80-kanji set, ISBN
4-921205-03-5, JLPT Level 3/old-numbering — and is extracted in full here.

**Coverage note — full extraction, no text layer.** This DjVu has no text layer at all (confirmed via
`djvutxt` producing zero output and `djvudump` showing JB2/IW4 image-only page structure); every page
was vision-read from rendered page images (`ddjvu -format=ppm`, re-encoded to PNG, ~1400×2000px).
**Spread-scan gotcha confirmed, same as `071`'s companion volume**: each of the 52 DjVu page-images is
a two-printed-page spread (verso+recto), not one printed page per image. The front cover and back
cover are each their own single DjVu page (not spreads); every interior page from the title page
onward is a spread. **A front-matter page-numbering gap was also found and is a book-layout fact, not
a rendering error**: the printed page footer jumps directly from "009 ページ" (page guide) to "012
ページ" (first kanji) with no content for pages 010–011 ever appearing in any rendered DjVu page —
consistent with an unnumbered "Study Section" divider spread (matching the Contents page's own listing
of "Study Section ... 11") that simply carries no printed footer, not a missing/skipped scan. Every
other page number was cross-checked directly against each page's own printed footer (`NNN ページ`)
rather than computed from a fixed offset formula, per this spec's page-range-verification guidance.
Structure: pp.1–11 front matter (covers, "Kanji Page Locator" index grid, title/copyright pages,
Manga University mission statement, Contents, Introduction, "Page Guide" legend), pp.12–91 Study
Section (one kanji per page, 80 pages total, exactly matching the book's own 80-kanji claim and its
back-of-book Kanji Index), pp.92 a "Take the Test!" JLPT background note, pp.93–107 Practice Section
(blank stroke-practice grids only — no new vocabulary/grammar content, skipped per the coverage rule),
pp.108–111 "Kanji Index" (an on-yomi/kun-yomi-to-kanji reverse-lookup table, captured as a grammar
point below), p.112 credits, p.113 a "Kanji Stroke-Order Rules" reference chart. **This stroke-order
chart is identical in content to the one already captured from Volume 1 in `011_kanji_de_manga_1.md`**
(same 8 numbered sub-rules under the same "Golden Rule," illustrated with kanji common to both
volumes) and is not re-transcribed a third time here (see `071`'s own cross-reference note for the
same deduplication). **No handwritten marginalia of any kind was found** — every page is clean
typeset printed content; a few page-images show faint scan/bleed-through discoloration near the
binding gutter (not handwriting), which did not obscure any text.

Each Study Section page follows the same fixed template as Volume 1 (per this book's own "Page
Guide," p.9, a 7-part layout nearly identical in wording to Volume 1's own version): (1) the featured
kanji in large print; (2) an English keyword gloss; (3) kun-yomi readings in hiragana and on-yomi
readings in katakana; (4) 2–3 example compounds with hiragana readings and English glosses (an
asterisk marks a compound containing a kanji not taught in this or the first volume); (5) a
stroke-order cell diagram; (6) a single-panel-or-strip manga vignette using the kanji "in action,"
with all dialogue in hiragana/katakana except the featured kanji itself (furigana given above it); and
(7) an English translation box plus any onomatopoeia. Per the coverage rule and copyright discipline,
each table row below paraphrases the manga scenario in a short, non-verbatim description rather than
reproducing the dialogue — the book's own dialogue/translation boxes are not block-quoted.

**Non-redundant-supplement note:** unlike Volume 1 (whose 80 kanji substantially overlapped in raw
character inventory with other already-extracted beginner-kanji sources), this volume's JLPT
Level 3/N4-tier 80-kanji set is itself the primary new-content payload — it is a different character
inventory from the N5-tier sets captured elsewhere in this project, not merely a different
illustration of already-captured characters. It is retained as a full, non-abbreviated extraction for
the same reason Volume 1 was: each kanji's manga scenario, onomatopoeia, and book-specific usage note
are independently authored, non-redundant content.

**Vision Reading Confidence:** `verified` throughout — every kanji, reading, and compound was
cross-checked against the page's own repeated appearances of the character (large display form,
stroke-order cells, and in-panel furigana-glossed instances all agree) and against the back-of-book
"Kanji Index" (pp.108–111), which independently lists all 80 characters by on-yomi/kun-yomi reading
alongside the same page numbers recorded below.

## Grammar points

### Two-volume framing: 160 kanji across JLPT Levels 4 and 3 (Introduction, pp.7–8)

The introduction frames this volume as a direct sequel: readers are assumed to already know the 80
kanji from Volume 1 (JLPT Level 4/N5), and this volume adds another 80 — specifically the kanji
needed to pass JLPT Level 3 (old numbering; roughly N4), taught in Japan's first through fourth
elementary-school grades. Combined, the two volumes total 160 kanji the reader will have studied by
the end of this book. The introduction explicitly promises a further sequel for higher JLPT levels.

### Page-guide template (p.9, keyed to the reused 赤 "RED" page)

Every Study Section page follows the same fixed 7-part layout already captured from Volume 1 in
`011_kanji_de_manga_1.md`: (1) the featured kanji in large display form; (2) a common English-keyword
definition; (3) kun-yomi readings in hiragana and on-yomi readings in katakana; (4) 1–3 example
compounds with hiragana readings and English glosses (an asterisk flags a compound containing a kanji
not taught in this or the first volume); (5) a stroke-order cell diagram, strokes generally ordered
top-to-bottom and left-to-right (full rule list referred to the back-of-book chart); (6) a single
manga panel/strip in which all dialogue is kana except the single featured kanji (furigana given above
it); (7) an English translation of the dialogue plus any onomatopoeia.

### Kanji stroke-order rules (back-of-book reference chart, p.113)

Identical in content to the chart already fully captured from Volume 1 (`011_kanji_de_manga_1.md`,
"Kanji stroke-order rules" grammar point) — the same "Golden Rule" (left to right, top to bottom) and
the same 8 numbered sub-rules illustrated with the same example kanji (一, 二, 三; 丿, 川; 一, 冂, 日; 亅,
小; 四; 友; 父; 十). Not re-transcribed a third time here; see that file for the full rule list.

### Kanji Index — on-yomi/kun-yomi reverse lookup (pp.108–111)

A back-of-book index lists all 80 of this volume's kanji sorted by reading (hiragana kun-yomi and
katakana on-yomi interleaved in gojūon order) rather than by the order they're taught, with each
reading's kanji and page number given — e.g. あ(う)→会(p.12), あお/あお(い)→青(p.13), か(う)→買(p.38),
かえ(る)/かえ(す)→帰(p.39). The book's own explanatory note (p.108) frames this as a tool for looking up
a character whose pronunciation is known but whose written form is forgotten; because most kanji carry
multiple readings, many characters are cross-listed more than once (e.g. 帰 appears under both かえ(る)
and かえ(す); 強 appears under both つよ(い) and つよ(まる)). This is the same reading-indexed-lookup
structure as a dictionary's on-yomi/kun-yomi index, here scoped to just this volume's 80-kanji set
rather than the full kanji inventory — a lightweight but genuine piece of reference apparatus distinct
from the page-by-page Study Section content above.

### JLPT framing ("Take the Test!", p.92)

Restates the same Japanese Language Proficiency Test background already captured in
`011_kanji_de_manga_1.md` (four levels, administered annually since 1984 by the Japanese government
and the Japan Foundation), specifying that this volume's 80 kanji are the set needed to pass Level 3,
and that subsequent volumes in the series will cover the higher levels.
