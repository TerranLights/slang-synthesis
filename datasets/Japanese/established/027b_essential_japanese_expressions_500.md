## Grammar points

### Purpose chapter's volitionality constraint on 〜ように (p.20)

The book's own usage note restricts 〜ように to clauses whose preceding verb does *not* express the
speaker's own volition — specifically non-volitional verbs or potential-form verbs (意志を表さない
動詞：意志を含まない動詞や可能の意味を表す動詞など). This is the same volitionality constraint the companion
"200" book documents for 〜ているところです (see `027_essential_japanese_expressions.md`), suggesting
volitionality is a recurring organizing axis across this publisher's/author's pattern-guide series,
not a one-off rule.

### JLPT-level tagging as an explicit register signal (chapter 2, p.20)

Chapter 2 cleanly demonstrates this book's level-tagging convention: of its four purpose-markers,
〜ように and 〜上で are tagged 2級 (N2) while 〜べく and 〜んがため(に) are tagged 1級 (N1) — and the two
1級 patterns are visibly more formal/archaic in register (べく is a literary/written form; んがため
(に) derives historically from the classical auxiliary ん(=む)+とす). This is a genuinely useful,
source-marked register signal the extraction spec asks to preserve whenever a source marks it
explicitly, and this book marks it on every single pattern, not just a few.

### Sequential-action chapter distinguishes abrupt vs. durative continuations (chapter 5, pp.40-41)

Chapter 5's own quiz design repeatedly tests whether a given sequential marker forces an abrupt,
single-moment reading (とたんに, かと思うと, 次第) versus a durative/continuing one (て以来). The
て以来 item is especially explicit: the book presents both a completed-event continuation (大学院に
入りました) and a durative one (ずっと大学院に通っています) as answer options, using the contrast itself
to teach that て以来 favors the durative reading.

### Dependency chapter separates sequential 次第 from conditioning 次第で (chapter 13, pp.100-101)

The same morpheme 次第 appears in this book in two unrelated-looking grammatical roles — a
sequential "as soon as" marker (chapter 5) and a dependency/conditioning "depending on" marker
(chapter 13, 次第で/次第だ/次第では) — and the book is careful to teach them in separate chapters with
distinct glosses rather than conflating them, which is itself worth noting for any later
mechanics-analysis phase looking at how a single bound morpheme can carry genuinely distinct
grammaticalized functions in Japanese.

### Negation chapter's register gradient from formal to very colloquial (chapter 25, p.191)

The book's final chapter deliberately contrasts two negation-pattern sets in two different register
contexts within the same page: Set I uses a polite, workplace-register dialogue (木村/ジム discussing
a speech contest) to drill まで(も)ない／はずがない／わけではない／ないものでもない／どころではない, while
Set II switches to a casual sibling argument (兄/弟 over a plastic model kit) to drill the more
colloquial はずがない-family near-synonym わけがない alongside なしに／ものか／っこない. This is an explicit,
source-built register contrast (formal workplace dialogue vs. casual family dialogue) worth flagging
as deliberate pedagogical design, not incidental.
