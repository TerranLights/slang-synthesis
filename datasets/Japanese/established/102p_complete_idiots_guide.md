# Japanese — Established Vocabulary/Grammar: The Complete Idiot's Guide to Conversational Japanese — Appendix C (Japanese to English Dictionary) — non-redundant supplement

**Source:** Naoya Fujita, Ph.D., *The Complete Idiot's Guide to Conversational Japanese* (Alpha
Books/Penguin, 2002), pp. 373-400 (Appendix C). Same source as `102_complete_idiots_guide.md`; see
that file for the full citation.

**Coverage note — non-redundant supplement, not a full re-extraction.** Appendix C is explicitly
presented by the book's own preface as the reverse-direction index of Appendix B: "This mini
Japanese-English dictionary contains most of the words introduced in this book... The Japanese
entries are listed in alphabetical order... The English meaning of each Japanese entry is listed in
the rightmost column." A full parse (793 English-headword entries already captured across
`102k`-`102o`) confirms this is overwhelmingly the same lemma set as Appendix B, just reverse-
indexed by romaji headword — re-extracting it wholesale would be almost entirely redundant with
`102k`-`102o`.

Per the extraction spec's "non-redundant supplement" dispatch pattern, this file captures only the
genuinely new structural information Appendix C supplies that Appendix B's English-to-Japanese
ordering cannot surface on its own: **homonym/homophone sets** — cases where multiple distinct
Japanese words share an identical romanized spelling but differ in meaning (and, per the source's
own preface, are distinguished by their kanji, which — per the same font-extraction limitation
noted in `102k` — could not be recovered from this PDF). Appendix C's own preface specifically
flags this as worth attending to: "There are numerous words whose pronunciations are identical,
such as hashi, 'bridge,' and hashi, 'chopsticks.' ... they are listed as separate entries." A scan
of all romanized headwords in Appendix C for duplicates surfaced the pairs below.

## Grammar points

### Not all of Appendix C's apparent homonyms are genuine — several are macron-flattening artifacts

Of the 14 homonym pairs found, at least 3 (obasaN "aunt"/"grandmother," tori "bird"/"street," and
tori-masu "take"/"pass through") are better explained as this specific appendix's own romanization
flattening a real long-vowel distinction already correctly preserved elsewhere in this book (in
Appendix B and in the main chapters) — i.e. an orthographic collision in *this table specifically*,
not genuine spoken-language homophony. The remaining pairs (atsu-i, haki-masu, hana, hashi, kaze,
ki-masu, nōto, oki-masu, shita, shū) appear to be true homonyms, consistent with the book's own
framing (the hashi "bridge"/"chopsticks" example is the book's own illustrative case). This
distinction matters for later mechanics-analysis work: a "true" homonym reflects an actual
coincidence in the spoken language's phonology, while a flattened-macron artifact is purely a
transcription-convention gap and tells us nothing about spoken Japanese itself.
