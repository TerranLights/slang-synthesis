# Japanese — Established Vocabulary/Grammar: Nihongo Hyōgen Bunkei Jiten (Dictionary of Essential Japanese Expressions)

**Source:** Tomomatsu Etsuko (友松悦子), Miyamoto Jun (宮本淳), Waguri Masako (和栗雅子), *日本語表現文型辞典 — Dictionary of Essential Japanese Expressions* (ALC Press, 2007/printed 2010 — 3rd printing per colophon, ModDate 2010-03-07), 533 PDF pages (printed pages ~2–530 + verb-conjugation/keigo appendix + 五十音順索引 index + 意味機能別リスト functional list). Clean embedded text layer (confirmed via `pdftotext`) carrying Japanese headwords/examples alongside parallel English, Chinese, and Korean translations for every entry.

**Gotcha — the two dispatched source files are byte-identical.** Both `"Nihongo Hyogen Bunkei Jiten Dictionary of Essential Japanese Expressions.pdf"` and `"Essential Japanese Expressions.pdf"` in `source_reference/languages/Japanese/05.Vocabulary, Expressions, Idioms/` have identical MD5 checksums (`c273b632e07f9c99b43bace3e832b435`), identical file size (7,589,935 bytes), and identical embedded metadata (title `日本語表現文型辞典_３刷.indb`). This is one source counted twice under two filenames, not two independent books — extracted once here.

**Coverage approach — representative sampling (standing project practice for 300+ page dictionary-style references).** The book's main body is a single gojūon-ordered (あ→ん) flat list of **521 distinct grammar-pattern/expression entries** spanning old JLPT levels 1–4 (「級」column: 1 = hardest/most advanced ≈ N1, 4 = easiest/most basic ≈ N4), each entry giving: headword (+ disambiguating 〈 〉 tag when multiple senses share a headword), a bracketed one-line Japanese paraphrase, the level number, 2–6 example sentences, the connection/conjugation rule (e.g. `Nに対して`, `Vる＋ところ`), a paraphrased explanation, and English/Chinese/Korean translations. This file samples **every 6th entry across the full headword list** (entry positions identified via the `】[1-4]` level-marker pattern that closes every entry's bracket), yielding **87 entries evenly spread from the very first headword (にたいして) to the very last (んがため)** — a genuine cross-section of the whole alphabetical range and all four level tiers, not a front-loaded or topic-clustered sample. Skipped: the remaining ~434 unsampled entries, the verb-conjugation chart and keigo appendix (pp. 442+, pure paradigm tables with no prose explanation to paraphrase), the 五十音順索引 (alphabetical index, a page-locator list with no new content), and the 意味機能別リスト (back-of-book functional-meaning grouping list, which just re-lists already-covered headwords by semantic category rather than adding new material).

**Non-redundant relative to prior Japanese extraction:** this is the first dedicated *functional-expression/sentence-pattern dictionary* extracted for Japanese (distinct from kanji dictionaries, JLPT vocabulary flashcard books, and lesson-structured textbooks already covered in Waves 1–3) — its entries are grammaticalized multi-morpheme patterns (にたいして, からいうと, んがため, etc.) rather than single lexical vocabulary items, so overlap with existing `established/` files is low; a handful of entries here (つもりだ, てはいけない, ませんか, まえに) are basic JLPT N4/N3 patterns likely already touched by textbook chapters, but this source's own paraphrased explanation, connection rule, and level-tagging are recorded here regardless since no prior file captured this book's own systematic treatment.

**Copyright discipline applied:** headwords, level tags, connection rules, and paraphrased meanings are recorded; only short illustrative example fragments are quoted (never a full example-sentence block verbatim), and explanatory prose is paraphrased in English rather than translated wholesale from the source's own Japanese/English explanatory text.

## Grammar points

This source is itself a flat gojūon-ordered dictionary of individual grammar patterns rather than a
lesson-structured textbook with discrete numbered "grammar points" — each table row above already
*is* one grammar point (headword + level + connection rule + paraphrased explanation), per this
source's own format. No separate thematic grammar-points section is added beyond the table to avoid
duplicating the same 87 entries under a different heading.

**Cross-cutting pattern observed across the sample:** this dictionary systematically pairs
near-synonymous patterns and explicitly ranks them by register/formality in its own explanatory text
— e.g. いかんで (formal/written) vs. しだいで (everyday); にせよ (harder/more formal) vs. にしろ
(same meaning, softer); たらいい／といい (softer suggestion) vs. ばいい (blunter); ものだ (formal)
vs. もんだ (explicitly flagged colloquial contraction); ようが～まいが (built on the archaic
negative-volitional まい) vs. ようと～まいと (near-equivalent, more modern-feeling). This
register-ranking habit — baked into the dictionary's own explanatory apparatus rather than inferred
by this extraction — is a useful ready-made register ladder for later mechanics-analysis work on how
formality gradients get marked in Japanese grammar.
