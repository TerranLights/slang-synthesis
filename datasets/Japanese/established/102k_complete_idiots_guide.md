# Japanese — Established Vocabulary/Grammar: The Complete Idiot's Guide to Conversational Japanese — Appendix B (English to Japanese Dictionary), part 1 of 5: able – dance

**Source:** Naoya Fujita, Ph.D., *The Complete Idiot's Guide to Conversational Japanese* (Alpha
Books/Penguin, 2002), pp. 343-372 (Appendix B). Same source as `102_complete_idiots_guide.md`; see
that file for the full citation.

**Coverage note.** Appendix B is a ~800-entry mini English-to-Japanese dictionary, organized
alphabetically by English headword, intended by the book's own preface to cover "most of the words
introduced in this book, as well as other frequently used basic words." Extracted in full per the
Wave 4 (Vocabulary/Dictionaries) mandate. Two extraction gotchas specific to this source:

1. **Kana/kanji column not recoverable.** The source table has three columns (English, romanized
   Japanese, kana/kanji). `pdftotext` (confirmed clean text layer elsewhere in this book) reliably
   extracts only the English and romaji columns — the kana/kanji column appears to rely on a font
   with no usable ToUnicode mapping and returns empty or garbled output. Entries here therefore
   carry romaji only; `Term` in this table is the romanized Japanese, `Gloss` the English headword
   (reversed from this appendix's own English-first column order, to match this project's
   Term=target-language-word/Gloss=English-meaning convention used throughout the corpus).
2. **Long-vowel macron marks split across a column-wrap line break in ~15% of entries.** When an
   entry's romaji wrapped to a second line in the PDF, the macron diacritic for a long vowel
   sometimes rendered as a stray hyphen on the *first* (headword) line, detached from the vowel it
   modifies, with the remaining letters appearing on the continuation line below. Where this
   occurred, the romaji was reconstructed using standard Japanese pronunciation (cross-referenced
   against the English gloss) rather than trusted as literally printed — consistent with this
   project's established PDF-extraction-gotcha guidance to cross-check scrambled columns rather
   than trust raw extraction order. A small number of entries (e.g. weekday names, numbers) needed
   only a stray leading artifact stripped, with no reconstruction required. Given the source's own
   simplified romanization convention (trailing hyphen marking a preceding long vowel, e.g. "kyo-"
   for kyō), reconstructed entries follow that same convention rather than standard Hepburn macrons.
