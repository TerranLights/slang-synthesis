# Ilocano — Established Vocabulary/Grammar: English-Ilocano Dictionary, Sample (PDF pp. 740-840)

**Source:** Carl R. Galvez Rubino, *Ilocano Dictionary and Grammar: Ilocano-English, English-
Ilocano* (University of Hawaiʻi Press, PALI Language Texts series, 2000), English-Ilocano section,
PDF pages 740-840 of 868 total. This is the first-ever Phase 1 extraction for Ilocano in this
project (file 018; sibling files cover other page ranges). Source has a genuine, clean `pdftotext`
OCR text layer (two-column dictionary layout) — read via `pdftotext -layout`, not vision-reading;
Vision Reading Confidence is `n/a` throughout.

**Coverage note — this is a deliberate SAMPLE, not exhaustive coverage.** Per this project's
standing convention for oversized dictionaries, this file samples 26 individual PDF pages at
roughly even intervals across the assigned range (740-840), each read in full with `-layout`, then
hand-selected for the most distinctive/informative entries rather than transcribing every headword
— the raw page density here (60-90 headwords/page) is far higher than a full-transcription approach
would allow while staying within a representative sample. Within each sampled page, priority was
given to: idioms and multi-sense entries, culturally specific vocabulary (kinship, rice/food, folk
religion), register-tagged entries, and — as specifically flagged in the dispatch brief — any
slang/taboo/informal entries and any Hawaii-related content (none of the latter were found; see
below).

**Font-cipher / OCR gotcha (flag for future extractions from this PDF):** this source exhibits a
systematic character-substitution pattern consistent with gotchas already logged for other
languages' PDFs in this project — digits substitute for accented vowels in some runs (`6`→`ó`,
`4`→`á`, occasional `1`→`í`), and a few word-final vowels render as stray consonants (e.g. `pitd`
for `pitó` "seven"). Entries exhibiting this are marked Transcription Confidence `moderate (digit/
accent substitution)` below; clean entries are marked `verified`.

**Hawaii check:** `grep -i "hawai"` across the full extracted text of PDF pp. 738-840 returned **zero
matches**. No Hawaii/Hawaiian-diaspora content appears in this specific page range (the triage
catalog's flagged Hawaii-contact material for Ilocano is evidently located elsewhere in the book,
outside this assignment).

**Back-matter boundary — CONFIRMED (task for next dispatch, file 019):** probed PDF pp. 800-850 in
steps of ~5-10 pages, then narrowed page-by-page. **The English-Ilocano dictionary ends precisely
on PDF p. 840**, whose final two entries are `yucca`/`Yuletide`/`zeal`/`zealous`/`zebra`/`zenith`/
`zero`/`zest`/`zigzag`/`zit`/`zither`/`zone` — i.e., the alphabet runs cleanly through X, Y, and Z to
completion, ending with `zone: n. las-ud, sakup, sóna.` **PDF p. 841 is a dedicated title page
reading "APPENDIXES"**, and PDF p. 843 begins "Grammatical Charts, Table 1. Articles" (internal book
page 755) — confirming the Appendixes/back-matter section starts at **PDF p. 841**. (PDF p. 842 is a
near-blank page with only a stray OCR artifact.) **File 019 should start its back-matter extraction
at PDF p. 841, not p. 850 as originally estimated** — there are ~9 pages of grammatical appendix
tables (841-850ish) before the "Traditional Ilocano Songs / Kankanta Nga Iloko" section confirmed
starting at PDF p. 850.

**Slang/taboo/register findings — substantial, flagged per dispatch brief.** This book's
English-Ilocano section includes plain, undisguised entries for body-slang, sexual, and
profanity-adjacent vocabulary throughout the letter range sampled (c, d, f, g, i, l, m, o, p, s, t,
v, w) — see the Notes column throughout, and the dedicated discussion after the tables. Highlights:
an explicit **"(lesbian)"** register tag on the *dike* entry (p. 760); a **"(homosexual)"** sense
split on the *gay* entry (p. 772); full anatomical/taboo entries for *clitoris*, *vagina*, *vulva*,
*penis*, *genitals*, *coitus*, *masturbate*, *fart*; and direct entries for *curse*, *damn*,
*profane*, *obscene*, *vulgar*, *impolite*, *insult*, *prostitute*, *whore*, *taboo*, and *swear*.

## Notable register findings (summary)

This sample confirms the dispatch brief's expectation that Ilocano lexicography of this era treats
body/sex/profanity vocabulary with the same plain, systematic lexicographic treatment as any other
semantic domain — no euphemistic avoidance, no omission, and often *more* granularity than the
English headword itself needs (e.g. *clitoris* gets 4 synonyms, *vulva* distinguishes inner/outer
lips and a large-variant term, *penis* has a dedicated small-size compound). Three cross-entry
lexical families recur across the sampled range and are worth carrying forward into any
slang-derivation work on this language:

1. **Profanity/irreverence family** — "lunod/ilunod" (curse/damn/malediction), "tabbaaw"
   (curse/profane/swear) — the same 1-2 roots cover English *curse*, *damn*, *profane*, and *swear*.
2. **Vulgarity/irreverence-of-conduct family** — "gubal/gubsang/sabrak/rasaw/kuspag" — covers
   English *vulgar*, *impolite*, *impious*, *insolent*, *arrogant*.
3. **Sex-worker family** — "pampam/balangkantis" shared verbatim between *prostitute* and *whore*.
4. **Folk-supernatural family** — "al-alia/pugot" shared across *spirit* (evil sense), *spook*,
   and used to translate the foreign concept *voodoo* via "mangkukulam"-type witch vocabulary.

**Hawaii-related content:** none found in this page range (PDF pp. 738-840); confirmed via full-range
grep, not just the sampled spreads.
