# Ilocano — Established Vocabulary/Grammar: Ilocano-English Dictionary, Representative Sample 3 (PDF pp. 523-737)

**Source:** Carl R. Galvez Rubino, *Ilocano Dictionary and Grammar: Ilocano-English,
English-Ilocano* (PALI Language Texts, University of Hawaiʻi Press, 2000). Ilocano-English
section, assigned PDF page range 523-737 — the late alphabet, running from mid-**P** (panggot)
through the final Ilocano-English entry on PDF p.735 (yuét / -ysa) and across the section-break
pages (736-738) into the opening of the English-Ilocano section (PDF p.739).

**This is a deliberate representative sample, not exhaustive coverage**, per this project's
standing convention for oversized dictionaries. Ten page-spreads (three consecutive PDF pages
each) were sampled at roughly even ~27-page intervals across the 215-page assigned range — PDF
pages 523-525, 550-552, 577-579, 604-606, 631-633, 658-660, 685-687, 712-714, 720-722, and
731-735 (the last spread extended to five pages to capture the Ilocano-English section's actual
end-of-alphabet closeout) — and read in full. Within each spread, entries were selected to
prioritize (a) distinctive derivational morphology (productive affixes, numeral-distributive
prefixes), (b) culturally-specific vocabulary (folk medicine, folk belief, historical/wartime
references, native games and crafts), (c) idioms and proverbs quoted in-source as illustrative
example sentences, and (d) the dictionary's own explicit register tags — `(obs.)`, `(slang)`,
`(fam.)`, `(coll.)`, `(reg.)`, `(fig.)`, `(vulg.)`, `(Pil.)` — rather than row-for-row
completeness of every entry on every sampled page. This is the **first-ever extraction for
Ilocano's Ilocano-English dictionary body** in this project (file 002 covered the companion
reference grammar's articles/pronouns chapters; this is the first dictionary-proper sample).

**Register-tag key, observed directly in this sample's page range** (no separate front-matter
"Abbreviations" section was found in PDF pp. 1-22; the tags below are the dictionary's own
bracketed/parenthetical markers as they appear inline on entries, confirmed by direct
observation rather than copied from a key page):
- `(obs.)` — obsolete; mapped to usage tier `archaic` below.
- `(slang)` — the dictionary's own explicit slang marker (e.g. *pisti*, *tukkol*² below); mapped
  to usage tier `slang`.
- `(fam.)` / `(coll.)` — familiar / colloquial register; when the headword's content is itself
  taboo (genitalia, sex, drugs), mapped to usage tier `taboo` with the source's own tag preserved
  in Notes; otherwise mapped to `colloquial`.
- `(reg.)` — regional variant; mapped to usage tier `regional`.
- `(fig.)` — figurative sense of a literal headword; tier follows the specific sense's register.
- `(vulg.)` — explicit vulgar marker (only one instance found this sample, *yuninam*, a curse
  phrase); mapped to usage tier `taboo`.
- `(Pil.)` — borrowed from Pilipino/Tagalog as a national-language register word rather than a
  plain Tagalog cognate note; mapped by content.
- Language-comparison brackets (`[Tag. ..., Kal. ..., Png. ..., Knk. ..., Ibg. ..., Ivt. ...,
  Kpm. ..., Bon. ...]`) are the dictionary's cognate/contrast apparatus across Northern Luzon
  languages (Tagalog, Kalinga, Pangasinan, Kankanaey, Ibanag, Ivatan, Kapampangan, Bontoc) — not
  register tags, but reproduced selectively below where they illustrate a cognate set worth
  flagging for comparative typology.

## Boundary confirmation: Ilocano-English → English-Ilocano switchover

Per the dispatch's additional task, `pdftotext -f 736 -l 739` was run to pin down the exact
switchover page. Findings:

- **PDF p.735** (included in this sample's range) is the genuine last content page of the
  Ilocano-English section: it runs through the final alphabetized Ilocano headwords (*yuét* "a
  kind of small, scaly snake," *Yógad* "ethnic group from Isabela Province," *yugayog*, ...,
  down to the closing enclitic entry *-ysa*, "variant of *maysá*, used with certain prefixes").
- **PDF p.736** — `pdftotext` returns pure OCR garbage (unreadable fragments like "sais", "oe",
  "me"). This is almost certainly a mostly-blank transitional/verso page that the scanner's OCR
  layer misread; no genuine Ilocano or English lexical content was recoverable from it.
- **PDF p.737** — this is the actual **section-divider title page**: `pdftotext` returns cleanly
  "ENGLISH-ILOCANO / INGGLES-ILOKO" — the printed section header for the second half of the
  dictionary.
- **PDF p.738** — OCR garbage again (similar unreadable fragments), almost certainly the blank
  verso facing the title page.
- **PDF p.739** — the actual first page of English-Ilocano entries: original book pagination
  "651," headed "A," opening with `a: art. maysa nga.` and continuing `aback`, `abandon`, etc.

**Conclusion for file 018's dispatch:** the Ilocano-English dictionary body ends content-wise on
**PDF p.735**. **PDF p.737** is the formal section-break title page ("ENGLISH-ILOCANO"). The
first actual English-Ilocano lexical entries begin on **PDF p.739**. File 018 should start
reading at PDF p.739 (or p.737 if it wants to capture/cite the section title itself) — not p.740
as the original estimate assumed. PDF pp.736 and 738 can be skipped entirely; they contain no
recoverable lexical content.

**Morphological typology note:** consistent with Ilocano's documented Western Austronesian
verbal morphology (affix-rich, non-concatenative voice/focus system), this sample's P-Y span is
dense with productive derivational machinery: the instrumental/locative nominalizing circumfix
*pangi- -an* (for *mangi-* class verbs), the general causative/intensifying prefix *pangpa-*, at
least three distinct numeral-distributive prefix patterns (*sagpami(n)-*, *sagt(um)unggal*,
*papi(n)-*), the Spanish-sourced but fully Ilocano-inflecting prefix *para-* ("one responsible
for X"), and pervasive *ag-*/*mang-*/*-en*/*-an*/*i-* verbalizing affixation on virtually every
root encountered. Reduplication (full-root doubling, e.g. *sakasaka* "barefoot," *rapokrapok*
"commotion," *yegyeg* "tremble") recurs as a productive intensifying/iterative device throughout,
consistent with typology already noted for other Austronesian languages in this project
(Tagalog). This is a provisional, sample-scale observation, not a final Ilocano typology claim —
no dedicated Ilocano typology-profile file exists yet in this project to cross-check against.

## Morpheme breakdown (compositionally transparent forms worth flagging, per the spec)

> **pangidaliasatan** = *pangi-* (instrumental/locative nominalizing prefix) + *daliasat*
> ("travel, transport" root, inferred) + *-an* (locative suffix) — a four-morpheme nominal
> derivation naming "the means by which transport happens," illustrating the *pangi- -an*
> circumfix's full productivity even on a root not independently glossed in this sample's page
> range (the root itself must be looked up under *d-*, outside this sample).

> **mawayawayaan** = *ma-* (stative/involuntary passive prefix) + *wayawaya* ("freedom," itself
> built on root *waya* "leisure time, opportunity, freedom") + *-an* (locative/goal suffix) — "to
> be liberated, emancipated" — a doubly-derived stative passive on an already-derived noun.

> **mannakaturay** = *mannaka-* (agentive/capability prefix, itself analyzable as *mang-* +
> *naka-*) + *turay* ("rule, authority") — "powerful, influential (one who is capable of
> ruling)" — illustrates a capability-agentive derivational layer distinct from the simple
> agentive *mang-* seen elsewhere (e.g. *mangiturong* "leader, director").

> **agtitinamnay** = *ag-* (verbalizing/habitual prefix) + reduplicated-infixed *ti-tinamnay*
> (from root *tamnay* "tasteless, insipid") — names a specific post-wedding ritual meal
> deliberately made of flavorless food; shows reduplication marking a specialized/ritualized
> sense distinct from the plain adjective *natamnay* "tasteless."

> **sagpamindua** = *sagpami(n)-* (distributive-multiplicative numeral prefix) + *dua* ("two")
> — "each two times." Directly contrastable with **sagtunggal maysa** = *sagt(um)unggal-*
> (distributive-cardinal numeral prefix) + *maysa* ("one") — "each one," and **papiduam** =
> *papi(n)-* (iterative-numeral verbalizing prefix, triggers *-ko*-set pronouns) + *dua* ("two")
> + *-am* (2nd person actor enclitic) — "have it done twice." Three distinct, non-interchangeable
> numeral-derivation morphemes captured within this one sample, each with a different
> grammatical behavior (adverbial distribution, cardinal distribution, and verbalization with a
> specific pronoun paradigm respectively) — a genuinely rich morphological finding worth flagging
> for whoever writes Ilocano's own typology profile.

> **yuninam** = *yut* (root, "copulate," taboo register) + *ni* (personal-noun-marking particle)
> + *ínám* ("your mother," possessive form of *ina* "mother") — a transparent three-morpheme
> curse phrase, the dictionary's only `(vulg.)`-tagged entry in this sample, built compositionally
> from an otherwise unremarkable possessive-phrase structure.

## Grammar points

*(This source is a dictionary, not primarily a grammar text, so no formal grammar chapter is
being summarized here — file 002 already covers the companion reference-grammar's
articles/pronouns chapters. The points below are structural patterns directly observable across
this sample's P-Y entries.)*

### Three distinct numeral-distribution/iteration affix paradigms

As detailed in the morpheme-breakdown section above, this sample alone surfaced *sagpami(n)-*
(distributive-multiplicative adverbs), *sagt(um)unggal* (distributive-cardinal adverbs), and
*papi(n)-* (iterative numeral verbalization with a dedicated *-ko*-set pronoun trigger) as three
non-overlapping numeral-affixation slots. This is a richer numeral-morphology inventory than has
been flagged for most other languages in this project so far and is worth a dedicated note in
any future Ilocano typology profile.

### The *para-* prefix as a fully nativized Spanish loan-affix

*para-* ("for," from Spanish) has been fully absorbed into Ilocano's productive derivational
system to the point of forming native-feeling agentive/purpose compounds (*paraluto* "cook,"
*parabomba* "well-pump operator," *paratimid* "chin strap," *paramanada* "fighting cock") on both
loan and native roots alike — a clear case of a function-word loan being re-analyzed as a
productive bound affix rather than staying a free preposition (contrast the separate, non-bound
preposition *para₂* "for" and the interjection *para₁* "Stop!", both homophonous but
grammatically distinct, all three listed as separate headwords in-source).

### Figurative-sense tagging (`(fig.)`) as a systematic dictionary convention

The dictionary consistently marks a headword's metaphorical/extended sense with an explicit
`(fig.)` tag distinct from its literal sense, rather than leaving the figurative reading
implicit — seen here on *paragos/paragot* ("sled" → "playboy"), *sabong* ("flower" →
"[taboo] female genitalia"), *tamburog* ("hump" → "to grow breasts"), *werret* ("fan noise" →
"racing thoughts"), *sudak* ("coconut-scraping tool" → "hurt feelings"), *pis-it* ("crush" →
"abort an embryo"), and *rarem* ("immerse" → "get involved deeply [in politics]"). This is a
systematic, source-internal register-tagging convention, not an inference by this extraction.

### Named folk-practice and folk-belief vocabulary as a recurring cluster

Several entries in this sample name specific, discrete cultural practices rather than general
concepts: *tugkel* (a named bibliomancy/divination technique using a stick and a divination
book), *tandok* (dry-cupping with a water-buffalo horn to draw out poison/illness), *sakada*
(the holy-water-sprinkling first stage of a solemn burial), *tukno* (temporary insanity
attributed to failure to make a spirit-offering, *atang*), and *tani* (the now-obsolete custom of
parents contractually betrothing their unborn children). These cluster thematically with the
folk-belief entries already flagged in the Hawaiian and Tagalog Phase-1 extractions as a
recurring cross-language pattern worth tracking project-wide: dictionaries of this kind
frequently preserve named folk-practice vocabulary in far more procedural detail than general
encyclopedic sources do.
