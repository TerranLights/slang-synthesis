# Ilocano — Established Vocabulary/Grammar: Ilocano-English Dictionary, Representative Sample 2 (PDF pp. 308–522)

**Source:** Carl Ralph Galvez Rubino, *Ilocano Dictionary and Grammar: Ilocano-English,
English-Ilocano* (PALI Language Texts, General Editor Byron W. Bender, University of Hawaiʻi
Press, 2000), Ilocano-English dictionary section. PDF pages 308–522 (printed page numbers,
where recoverable from the running headers captured by `pdftotext`, are noted in `Notes`; this
range runs roughly printed pp. 220–434). File has a genuine OCR text layer (Internet Archive
Scribe scan) — `pdftotext -f <start> -l <end>` was used throughout, no vision-reading needed.

**Coverage note — this is a deliberate representative sample, not exhaustive coverage.** This is
the second dictionary-sampling file for Ilocano's first-ever Phase 1 extraction (continuing from
file 015's range, PDF pp. 92–307). Per dispatch instructions, this file samples across the full
308–522 span rather than transcribing every entry on every page. The range spans from mid-letter-I
(`impate`, picking up right after file 015 leaves off) through most of **K** (by far the largest
letter in this dictionary — roughly 40 of the 214 pages), **L**, **M**, **N**, the merged **NG**
section, the merged **O/U** section (see finding below), and into the first few pages of **P**
(ending at `panggo`, "to use beasts of burden to pull a load," PDF p. 522). Entries were pulled
from entries flagged by the dictionary's own register abbreviations (`coll.`, `slang`, `Pil.`,
`obs.`, `reg.`) found via full-range keyword search, plus additional samples drawn from ~20 evenly
spaced points across the entire 214-page span to capture ordinary core vocabulary, closed-class
morphology (affixes/infixes/circumfixes), and Spanish-loanword strata alongside the register-tagged
items.

**Register abbreviations used below** (per the dictionary's own "Abbreviations Used in This
Dictionary" key, PDF p. 88, covered in file 014): `coll.` = colloquial, `slang` = slang, `Pil.` =
Pilipino/Philippine-wide (not Ilocano-specific), `obs.` = obsolete, `reg.` = regional, `fig.` =
figurative, `f.` = derived from, `var.` = variant of, `syn.` = synonym of, `Sp.` = Spanish loanword,
`Eng.` = English loanword, `Jap.` = Japanese loanword, `Tag.` = Tagalog (cross-reference or
loanword).

**Flagship findings in this sample:**
1. **Hawaii-specific entry confirmed inside this range:** `kanaka: (Hawaiian use only) n. Native
   Hawaiian. (Hawayano, taga-Hawait)` — PDF p. ~399 (K section). This matches the triage catalog's
   earlier finding of this entry. No other Hawaii-tagged entries (`Purgi`, `Aloha`, `Haway`, the
   demographic paragraph, the *Naar-aringanen* example sentence) fall inside this file's 308–522
   range — those sit in other letters' ranges (A-, under file 015, or front-matter sections under
   files 013/014) and were confirmed absent here by a full-range case-insensitive search for
   `hawai|kanaka|aloha|purgi|haway|sakada|plantation` across the whole 214-page extracted text. A
   near-miss: `kano: (f. Amerikano) n. term for American males` (not Hawaii-specific, general
   American-contact term, included below for comparison) and a red herring: `sakada` appears once
   in this range only as part of an unrelated example sentence meaning "bullets," not as a
   headword for the Hawaii-plantation-labor sense — no such headword exists in this range.
2. **The O/U alphabetization merge.** This dictionary interleaves **O** and **U** headwords on the
   same pages in a single alphabetical run (e.g. PDF p. 490 moves `orador` → `uray` (wait) →
   `uraga` → `orakulo` → `oral` → `uram` back and forth within one page) rather than keeping O and
   U as separate letter-sections. This is almost certainly because Ilocano's unstressed /o/ and /u/
   are historically/phonemically the same vowel with conditioned height alternation (raising in
   closed/final position), so the compiler treats O-initial and U-initial spellings as orthographic
   variants of one underlying slot rather than as different letters — a genuine phonological finding
   worth flagging for the morphological-typology checklist, parallel to how some Ilocano speakers
   reportedly waver between treating `isu`/`maysa` alternants as the "true" root (see the `-on`
   entry below).
3. **Rich slang/vulgar/colloquial seam, concentrated but spread across every letter sampled.**
   Roughly 50 distinct register-tagged headwords were found (see table) — sexual slang (`maho`,
   `ma-l`, `kindó`, `uttot`-adjacent idiom), insult/derogatory ethnic terms (`panggalatot` for
   Pangasinan people/language, `ungas` for stupid/crude males), insult-register body-part slang
   (`kimmapo`, `kawitan` 'penis' sense), euphemism-for-virginity clusters (`kaddigal`, `marasintok`,
   `muréd`, `paggalsém`, `mariaklara`, `libnós`), and a cryptolect-adjacent reversal/word-play
   coinage (`uriab`, from *barrio* reversed; `kalay`, *baliktad* 'reversed' of *lakay* 'old man').
4. **A full proverb/saying with an explicit comparative structure**, under `uttot` (fart): "Better
   is the water buffalo thief than the farting bachelorette, better is the horse thief than the
   farting bachelor. *Bungbungtot sino ti immuttot, isurom ti nagkauttot.*" (an Ilocano-specific
   rhyming version of the idea, text truncated by a page break in the OCR before its own gloss is
   given) — a vivid example of taboo-adjacent social shaming humor encoded in a fixed saying.

### Observed phonological/orthographic finding: O/U alphabetization merge

As noted in the flagship findings above, this dictionary alphabetizes **O**- and **U**-initial
headwords as a single interleaved run rather than as separate letter sections (confirmed directly
by reading PDF pp. 485–498 in sequence, where *umay* → *upaz/ungas* → *orador* → *uray* → *uraga*
→ *orakulo* → *oral* → *uram* alternate within a few consecutive pages). This is consistent with
Ilocano's historical/phonemic treatment of unstressed-position /o/ and /u/ as realizations of one
underlying vowel rather than as fully contrastive phonemes — worth flagging for this language's
`00_Extraction_Checklist.md` morphological-typology profile once created, and for cross-checking
against the dedicated reference grammar's phonology chapter (file 001).
