**Coverage note:** this is a genuinely new, previously uncaptured resource for this project's
Dutch coverage — no prior established/ file tabulates a comprehensive verb+fixed-preposition
inventory. The full a–z list is captured below (the source's own framing: "Hier volgt een lijst
van de meestvoorkomende [combinaties] met een voorbeeldzin. Voor de betekenis verwijs ik naar het
van Dale Pocketwoordenboek NT2" — i.e. the source itself doesn't claim exhaustiveness, only "most
common"). Per copyright discipline, the source's own full illustrative example sentence for each
entry is **not reproduced**; each entry's Gloss column instead gives a short paraphrased sense
derived from that example, and the Notes column, where useful, adds a compressed paraphrase rather
than a verbatim quote. All entries are **verb + fixed preposition** collocations — a closed,
non-productive pairing where the preposition doesn't vary freely by the speaker's intended meaning
(e.g. *wachten op* "to wait for" always takes *op*, never *voor* or *naar*, in this sense).
