# Dutch — Established Vocabulary: A Dutch Vocabulary (complete topical wordlist)

**Source:** Bruce Donaldson, *A Dutch Vocabulary* (AE Press, Melbourne, 1983) — the entire book,
PDF pp. 1–95 (source's own printed pagination pp. 3–96), sections 1–266, covering all topical
groups from "Clothing" through "Interrogatives" (the book's full Table of Contents, p. 95).

**Coverage note:** this source is a dedicated topic-organized vocabulary primer (≈2860 items per
the author's own preface), not a grammar textbook with drill exercises — there is no padding to
skip, so every distinct vocabulary item in the book is in scope per the coverage rule, and this
file attempts genuinely comprehensive coverage of it. Footnoted usage/grammar notes attached to
specific sections are captured in the Grammar points section below rather than duplicated per row.

**OCR-quality caveat (read before trusting any single row).** This PDF's text layer was produced by
Adobe Acrobat's "Paper Capture" OCR plug-in (per `pdfinfo`) over a 1983 scanned book, and the raw
extraction is materially noisier than a typical clean text layer: frequent single-character
substitutions (`e`↔`a` is the single most common pattern — e.g. printed `hat`/`fen` decode to `het`/
`een`, `broak`→`broek`, `gasp`→`gesp`, `riam`→`riem`), `d`↔`cl`/`ii`↔`u` confusions, stray spaces
inside single words (`unifo rm`→`uniform`), and occasional case/character garbling on less-common
words. This does **not** meet the "no text layer, must vision-read" threshold — `pdftotext` recovers
real, mostly-decodable text throughout — so per the spec's Vision Reading Confidence rule this is
`n/a` for every row (no page was rendered to an image and read visually). Every `Term` and `Gloss`
below has been corrected against the raw OCR using Dutch-lexical judgment and cross-checking the
`-layout` extraction against the non-layout extraction where a decode was ambiguous. A small number
of items where a confident decode was not possible are flagged individually in that row's Notes
column as `[OCR: uncertain]` rather than silently guessed — treat those as needing a check against
the physical/scanned book before relying on them.
