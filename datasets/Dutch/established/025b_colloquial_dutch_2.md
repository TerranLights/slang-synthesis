## Grammar points

### Language point 1 — Stating preferences

Preference is expressed via **de voorkeur geven aan**, **leuker vinden**, **liever hebben**, or
**liever doen**. **Liever** (used for preferring to *do* something) is in fact the comparative of
**graag** — e.g. **Ik lees graag romans maar ik lees liever korte verhalen** ("I like reading
novels, but I prefer reading short stories"). The corresponding superlative is **het liefst**
("most of all"), as in **Ik blijf gewoon het liefst thuis**. To prefer one thing *to* another,
**verkiezen boven** is used: **Hij verkiest juli boven juni**. p.20.

### Language point 2 — Handy expressions built from comparative/superlative forms

A set of fixed idiomatic constructions built on comparative/superlative morphology, catalogued
together because they don't follow productively from the base adjective rule (see full list in
the vocabulary table above — **hoe X-er hoe Y-er** doubling constructions, **op z'n
vroegst/minst**, **ten strengste**, substantivized superlatives like **het bovenste/onderste**,
etc.). Two synonymous "the more X the more Y" constructions require *different* word order: **Hoe
meer hij eet, des te dikker wordt hij** vs. **Hoe meer hij eet, hoe dikker hij wordt** — the
**des te** variant requires verb-second inversion in its own clause where the **hoe** variant does
not. pp.23-24.

### Language point 3 — More on adjectival endings

Reviews the base rule (an attributive adjective takes no **-e** ending only before an indefinite
singular neuter noun; takes **-e** in all other cases) and then catalogues its exceptions:

- A closed list of largely-neuter noun phrases (particularly institutional/technical compounds)
  where the adjective stays uninflected even in definite-article position, because adjective +
  noun function as a single compound-like unit: **het Stedelijk Museum**, **het centraal
  station**, **het openbaar vervoer**, **het academisch ziekenhuis**, **het menselijk lichaam**,
  **het noordelijk halfrond**, **het dagelijks leven**, **het stoffelijk overschot**, **het
  koninklijk gezin**, **het zelfrijzend bakmeel**, **het zelfstandig naamwoord**. Critically, when
  these same phrases are *pluralized*, the adjective **is** inflected normally (**de stedelijke
  museums**, **de centrale stations**) — the exception is specifically tied to the singular
  definite-neuter slot. There is no general rule for which nouns belong on this list; the source
  explicitly instructs learners to acquire them one at a time by exposure.
- Adjectives preceding nouns referring to human beings — particularly masculine
  profession/function nouns — are also sometimes left uninflected after an article: **de
  waarnemend burgemeester**, **een bekwaam musicus**, **een vroom man**, **een beroemd
  schrijfster**. Same "only copy what you've heard/read, apply the rule otherwise" guidance.
pp.26-28.
