## Grammar points

### "Hoe X, hoe Y" correlative comparative

Les 12's vocabulary flags a correlative-comparative construction: **hoe beter... hoe meer**
("the better... the more"), a fixed pattern pairing two comparative clauses with "hoe" rather
than English "the... the...". Paraphrase: this is a real, productive Dutch syntactic frame (not
just idiom), reappearing later in Les 49's oefeningen as "hoe meer... hoe beter."

### "toen" restricted to past-tense clauses

The source explicitly annotates (p.25) that **toen** ("when") is used *only* with past-tense
clauses — a genuine grammar constraint (Dutch uses **als** for present/habitual "when," reserving
**toen** for a single past occasion), worth noting for the mechanics-analysis phase since register
misuse of toen/als is a documented learner-error marker that could plausibly feed into a stylized
"non-native slang" register later.

### Dative residue in fixed idiom: "van harte"

**Van harte gefeliciteerd** ("hearty congratulations") preserves **harte**, an old dative singular
form of **hart** ("heart") — flagged explicitly by the source itself (p.24) as a fossilized
historical case-form surviving only in this fixed idiom, consistent with the checklist's note that
Dutch case marking has "almost entirely collapsed except in pronouns." This is a concrete example
of that collapse being *incomplete* at the idiom level.
