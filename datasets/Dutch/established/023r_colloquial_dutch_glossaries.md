# Dutch — Established Vocabulary/Grammar: Colloquial Dutch (Donaldson) — English-Dutch and
Dutch-English Glossaries

**Source:** Bruce Donaldson, *Colloquial Dutch* (Routledge, 1996), back-matter English-Dutch glossary
(pp. 262-280, PDF pp. 137-146) and Dutch-English glossary (pp. 281-305, PDF pp. 146-158). The book's
Index (pp. 306+, PDF pp. 159-162, end of the 162-page scan) was skipped — pure page-locator content,
no linguistic data of its own.

**Coverage note:** Vision-read, no text layer, `verified` confidence throughout (clean print, no
marginalia; multi-column layout read directly via vision rather than `pdftotext -layout`, so no
column-scrambling risk applies here). These two glossaries together run to several thousand entries
and are overwhelmingly **redundant with vocabulary already captured** across `established/001`-`021`
and this book's own `established/023`-`023q` lesson-by-lesson extractions — they exist as an
alphabetical index/lookup aid to the same core vocabulary the lessons already teach, not as a
separate corpus. Following this Dutch corpus's established representative/curated approach for large
reference lists (per the coverage rule and copyright discipline against bulk-reproducing a vocabulary
box), this file does **not** re-transcribe the glossaries wholesale. Instead it records: (1) domain
coverage confirmed present (so a future search knows what's there), and (2) every genuinely new item
spotted during a representative multi-page sampling pass (pp.262-263, 266-267, 280-281, 284-285,
304-305 of the English-Dutch and Dutch-English glossaries) that was **not** already captured in an
earlier lesson file — mostly colloquial idioms, register-marked interjections, and a few cultural/
phonetic notes that don't appear in the lesson-by-lesson dialogues.

**Domain coverage confirmed present (not itemized further, already well-represented via the lesson
files' own vocabulary tables):** numerals, days/months, colors, family-relation terms (including
`achterkleinkind`-type "great-grand-" compounds), clothing, food/kitchen items, animals, body parts,
weather terms, transport terms, basic verbs of motion/perception/cognition — i.e. the glossaries'
core function of indexing the entire book's running vocabulary alphabetically in both directions.
