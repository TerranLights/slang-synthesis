## Grammar points

### Impersonal passive ("er wordt/werd + past participle")

Les 25's vocabulary preserves a genuine impersonal-passive construction: **er wordt tegenwoordig
heel wat gereisd** ("a lot of travelling is done at present," lit. "there is a lot travelled").
This construction — an agentless, subjectless passive built on an intransitive verb — has no
direct English equivalent and recurs as a real grammatical pattern (also seen with **bellen** in
`024`: "er wordt gebeld," "there is a ring at the door"). Paraphrase: Dutch can passivize
intransitive verbs using dummy **er** + **worden**, expressing that an activity is generally
happening without naming who does it.

### Fossilized genitive "der"

Les 33's **der** (= *van de*) surfaces as an explicit genitive-plural relic (source's own gloss),
in the fixed phrase "in de loop der jaren" ("in the course of the years"). Consistent with `024b`'s
"van harte" finding: Dutch's lost case system leaves scattered fossils in set phrases rather than
being fully regular or fully absent.
