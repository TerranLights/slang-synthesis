# Hungarian — Established Vocabulary: Szólások és közmondások, Part 2 (F–L sample)

**Source:** *Magyar szólások és közmondások* (Hungarian Sayings and Proverbs), 835-page numbered
proverb/idiom dictionary, clean text layer (`pdftotext -layout`, no vision-reading needed). PDF
pages 211–420 of 835 (second quarter of the book), corresponding to entry numbers **f1028 through
l783** in the source's own per-letter numbering scheme (each Hungarian alphabet letter — including
the digraph letters `gy`, `ly`, `ny`, `sz`, `ty`, `zs`, which are separate letters in Hungarian
collation — restarts its own entry count from 1; cross-references in the source use a
letter-prefix + number code, e.g. `f1033`, `k1821`, `l627`, confirming this).

**Coverage note — this is a deliberate sample, not exhaustive transcription.** This page range
alone holds roughly **5,595 individual numbered entries**, spanning headword groups under (in
order) **fül** "ear" / **füst** "smoke" / **fürj** "quail" (finishing out a letter-F run that began
before p. 211) → **G** (`gabona` "grain," `gát` "dam," `gazda` "farmer," `gége` "throat," `göncöt`
"clothes/rags," `gyöp/gyökér` region) → **GY** (as its own alphabet letter, `gyakorlat` "practice"
onward) → **H** (`ha` "if," `hagyma`, `halál` "death," `hangya` "ant," `haszon` "profit," `haza`
"home/lying," `hazugság` "lie," `hely` "place," `Heves" placename, `hisz` "believe," `hold` "moon,"

"to walk/go," `jó` "good," `jótett` "good deed") → **K** (a very long letter — `Kaba` placename,
`kakas` "rooster," `kalitka` "cage," `kancsó` "pitcher," `káposzta` "cabbage," `karácsony`

"horse" (entries 340–783 of the L-letter run, still in progress at p. 420, the end of this
dispatch's assigned range).

Given that scale, this file extracts **50 representative entries** hand-selected for (a) clear
figurative derivation from a literal image (animal behavior, body parts, food/drink, weather,
craft objects), (b) an explicit source register tag (`rég` archaic, `táj` dialectal, `nép`
folk/popular, `biz` bizalmas/familiar-colloquial, `durva` coarse/vulgar, `tréf` jocular, `ritk`
rare, `gúny` ironic, `elavulóban` "falling out of use"), or (c) a recurring idiomatic pattern (see
below). This mirrors how this project handled SCB's large glossaries — a genuine sample, not
coverage of the full ~5,600 entries in this page range.

## Register-tag → Usage Tier mapping (established for this book, apply consistently to future
Szólások chunks)

The source's own bracketed tags map onto this project's `00_Usage_Tier_Taxonomy.md` as follows:

- `(rég)` "régies," archaic-flavored → **`archaic`**. The source itself explicitly marks the
  expression as old-fashioned/no-longer-current, which is stronger evidence than a book's mere
  publication date, so it's also carried into the **Attested Era** column below as
  `archaic (source-marked rég)`.
- `(táj)` "tájszó/tájnyelvi," dialectal → **`regional`**. The source does *not* name which
  region/dialect (unlike a B/C/S-style comparative tag), so **Attested Region**/**Geographic
  Scope** stay `—` per the spec's column rule — only the Usage Tier records the dialectal marking.
- `(nép)` "népies," folk/popular speech → **`colloquial`**. Distinguished here from `regional`
  because `nép` in this dictionary marks *register* (common, unpolished popular usage) rather than
  a *place*-bound dialectal form — worth flagging if a later chunk finds evidence this should
  instead be a `colloquial.folk` subcategory.
- `(biz)` "bizalmas," familiar/informal → **`colloquial`**.
- `(durva)` coarse/vulgar → **`taboo`**.
- `(ritk)` rare → kept as a **Notes** qualifier alongside whatever base tier applies (rare usage
  is an orthogonal axis to register); no dedicated tier since only 2 sample entries carry it here.
- `(tréf)`/`(gúny)` jocular/ironic and `(elavulóban)` "falling out of use" are **tone/status**
  qualifiers, not register tiers — recorded in Notes, layered on top of whatever base tier the
  co-occurring tag (or absence of one) supplies.
- **No tag at all** → **`core`**: several sample entries below (e.g. *füstbe megy*, *az se kutya*)
  carry no register tag in the source and read as fully current standard idiom.

## Recurring idiomatic/figurative patterns worth flagging for future slang-mechanics analysis

1. **Placename-anchored fixed similes.** At least four sample entries (*Kerüli, mint Gálos
   Taksonyt*; *Fülep a fülit!*; *Rendben van, mint Kaba az árokba(n)*; *Kénytelen vele, mint a
   kiliti legény*) build their figurative force entirely around a proper name (a person or a small
   village) whose original referent is now lost — the idiom survives as a fixed, semantically
   opaque unit long after its founding anecdote is forgotten. This looks like a genuinely
   productive Hungarian proverb-formation pattern (a `metaphor_productivity`/fossilization
   candidate) worth a dedicated look once enough of the alphabet has been sampled to see whether
   it clusters regionally.
2. **Wordplay/homophone-based idioms.** *Nem Hevesen vagyunk!* (placename *Heves* vs. adjective
   *heves* "vehement") is an explicit, source-flagged pun. Worth watching for more of these — they
   are a distinct derivation mechanism from pure metaphor and would need their own
   `slang-derivation type` if they recur (closest existing taxonomy entry is
   `phonological_reduction`/`semantic_shift`, but neither quite captures deliberate homophone
   punning — possibly a candidate for a new `homophone_pun` type if 2+ languages surface it).
3. **A single vehicle splitting into a positive and a negative figurative reading.** *Fűrészporból
   aranyat szed* ("picks gold from sawdust") reads as either uncanny good luck *or* insatiable
   greed depending on context — the same literal image supporting opposite moral valence. Several
   other entries skimmed but not tabled here showed the same a/b-split structure. Worth checking
   whether this is a structural feature of the dictionary's own entry format (it explicitly lists
   multiple senses per headword) rather than a deeper linguistic pattern — but even so, it's a
   useful model for how synthesized slang could deliberately support dual/ironic readings.
4. **Drinking-euphemism cluster.** *Megáztatja a gégéjét* ("wets the throat") and *Kancsó a komája*
   ("the pitcher is his buddy") both softly euphemize habitual drinking via liquid/vessel imagery
   rather than naming it directly — worth watching for more entries in this semantic domain
   (`euphemism_chain`) as later chunks are sampled.
5. **"Bread"/subsistence-object metonymy for life-status.** *Maga kenyerén van* ("is on his own
   bread" = financially independent) and, more loosely, *Kontyot tesz vkinek a fejére* ("puts the
   married-woman's hair-knot on her head" = marries her) both use a everyday
   material-culture object (bread, a hairstyle) as a compressed stand-in for an entire life-stage
   or social status. This `metaphor_productivity` pattern (concrete household/domestic object →
   abstract social-status marker) recurred often enough in the skimmed-but-untabled entries that
   it's worth a dedicated `analysis/` pass once more of the alphabet is sampled.
6. **Register and vulgarity are orthogonal, not correlated.** *Ugass, kutyám, ugass* is a folksy
   rhyming couplet (`(táj)`) that is *also* explicitly flagged `(durva)` coarse — a reminder not to
   assume "folk/dialectal" automatically means "polite" or vice versa when building
   `derivation_type`/`usage_tier` combinations for synthesis work.
7. **A rare explicit "falling out of use" flag.** *Csak úgy füstölt* is tagged `(biz, elavulóban)`
   — the dictionary itself marking an idiom as actively obsolescing, not just already archaic. This
   is a genuinely rare, valuable data point distinct from the binary `archaic` tier: a documented
   mid-decline idiom, useful if the synthesis phase ever wants to model slang *decay* rather than
   only slang *formation*.
