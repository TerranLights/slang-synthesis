# Hungarian — Established Vocabulary: Szólások és közmondások, Sample Part 3 (PDF pp. 421–625)

**Source:** O. Nagy Gábor, *Magyar szólások és közmondások* [Hungarian Sayings and Proverbs] (4th
ed., Gondolat, Budapest, 1985; 1st ed. 1966), a large alphabetically-organized dictionary of
Hungarian idioms and proverbs, PDF pages 421–625 of 835 total (the book's third quarter by PDF
page count). This range runs alphabetically from the tail of the **l** section (`ló`/`lúd`
"horse"/"goose" entries, l784–l893 approx.) through **m** (`meg-`, `méh`, `mell`, `mente`,
`menyasszony`, `mennykő`), **n/o/ö** (`ostor`, `otthon`, `öböl`, `ökör`), **p** (`patika`, `patkó`,
`pecsenye`, `pék`, `példa`, `polyva`, `pendely`, `penna`, `péntek`), **r** (`rend`, `rest`,
`részeg`, `retek`, `rétes`, `rézgálic`), to the middle of **sz** (`szem`-idioms — a very large
cluster — through `szurok`, `szuszog`, `szűcs`, `szükség`, `szülő`, `szűr`), ending mid-page 625.

**Coverage note — deliberate sample, not exhaustive.** This book contains several thousand
numbered entries across 835 pages; per this project's coverage rule, this file extracts a
representative sample rather than transcribing the full range. **~50 entries** were selected from
across the assigned pages (sampled directly at PDF pp. 421, 450, 500, 525, 550, 600, 625, with the
book's own alphabetical/entry-number sequence used to infer what falls between), prioritizing
entries that (a) show clear figurative derivation from a literal statement, (b) carry one of the
source's own register tags, or (c) reveal a recurring idiomatic pattern. This mirrors how SCB's
large glossaries were handled elsewhere in this project. Entry numbering in this source restarts
per letter-section and is cross-referenced by the source itself with a letter prefix (e.g. `l844`,
`m574`, `ö76`, `p315`, `sz579`) — that convention is preserved in the **Term** column's bracketed ID
below so entries can be relocated in the source.

**Source has a real text layer** — `pdftotext -layout` output was clean and unambiguous throughout
the sampled pages; no vision-reading was needed anywhere in this file.

## A genuinely valuable find: the source's own register-tag legend (PDF p. ~1013, "A rövidítések
jegyzéke")

Unlike most reference sources handled so far, this dictionary prints its own precise definitions
for its register abbreviations, rather than leaving them for the extractor to infer. This is worth
flagging explicitly for future slang-mechanics work — it's a rare case of a source self-describing
its register taxonomy with enough precision to map cleanly onto this project's `Usage Tier`
taxonomy:

| Source tag | Source's own definition (paraphrased) | Mapped Usage Tier |
|---|---|---|
| `rég` | "old-language" — flags a term for which the source's evidence is **only attested from more than 100 years before compilation** (1st ed. 1966, so roughly pre-1860s) | `archaic` |
| `táj` | "dialectal" — known only in a **small part** of the Hungarian language area | `regional` |
| `nép` | "folk-language" — known **across a large part of the country**, gives the style a folksy color, but *not* geographically restricted the way `táj` is | `colloquial.folk` (new subcategory — distinct from `regional` precisely because it's nationwide, not local; distinct from plain `colloquial` because the source itself marks it as carrying a rural/folk stylistic flavor) |
| `biz` | "used in confidential/familiar speech," the familiar stylistic layer | `colloquial` |
| `argó` | explicitly "argotic, used in argot" | `slang` |
| `vál` | belongs to the "choice/elevated" stylistic layer | `formal` |
| `irod` | used in literary language (not seen in this file's sample, listed for completeness) | `literary` |
| `Sp` | used in sports-specific language | `technical.sports` |
| `ritk` | **not a register tag** — flags a term still alive in standard language but only rarely used | tier taken from context; frequency-flagged as `rare (source-flagged, still standard)` |
| `tréf`, `gúny`, `rosszalló` | tone/attitude markers (joking, mocking, disapproving) — not registers on their own | recorded in Notes, tier taken from any co-occurring register tag or `core` if none |
| `durva` | "coarse/vulgar" — **not in the source's own legend**, appears written out in full rather than abbreviated in a handful of entries, i.e. an ad hoc intensifier beyond the codified tag system | `taboo` |
| `szépítő`, `kissé rég`, `elavulóban` | free-text qualifiers ("euphemistic," "somewhat archaic," "becoming obsolete") also outside the codified legend | recorded in Notes; `kissé rég`/`elavulóban` treated as `archaic` with the qualifier noted |

## Recurring patterns worth flagging for future slang-mechanics analysis

1. **A precise, source-defined register taxonomy exists and can be mapped cleanly** — see the
   legend table above. This is unusually good ground truth compared to sources that use register
   labels without defining them; future `analysis/` work on Hungarian's real historical
   register-stratification could lean on this dictionary's own definitions rather than reconstructing
   them from usage alone.

2. **Register-doubled proverb variants**: at least two entries in this sample (`[m598]`, `[p338]`)
   show the *same* proverb printed with a polite variant and an explicitly `durva`-tagged coarser
   variant swapped in for one word/phrase — i.e. the same figurative structure deliberately
   re-skinned at a different taboo register. This is a directly useful, source-attested model for a
   `taboo_inversion`/`euphemism_chain`-style synthesis mechanism: take an established figurative
   frame and swap in a taboo lexical item at the same syntactic slot.

3. **Domain-specific metaphor clusters are dense and recurring**, not one-off: draft-animal/plow
   husbandry (`ló`, `ökör`, `abrak` "feed" — `[l786]`, `[ö20]`, `[ö22]`, `[ö33]`), poultry/goose
   husbandry (`lúd` — the whole `[l852]`–`[l893]` stretch), and clothing/textile-quality-as-social-
   status (`szűr`/`köpönyeg`/`mente`/`pendely` — `[sz1289]`, `[p396]`, `[p389]`) each generate large
   families of idioms drawing on the same source domain. This matches this taxonomy's
   `metaphor_productivity` derivation type well and gives concrete Hungarian-specific candidate
   source-domains (rather than the taxonomy's generic examples of "military, agriculture, cooking")
   for future synthesis work.

4. **A native-language proverb can carry its own internal register history**: `[r118]` and `[r144]`
   are each tagged as slang (`argó`) *and* archaic/obsolescing (`rég`/`elavulóban`) simultaneously —
   i.e. yesterday's slang, aging into obsolescence, rather than graduating into neutral/core usage.
   Worth keeping in mind for any synthesized slang's own projected lifecycle.

5. **At least one clear loanword-derived idiom** (`[sz639]`, built on `reszkíroz` < risk/risqu-)
   shows a borrowed verb stem naturalized into an idiom slot exactly like a native verb — a concrete
   Hungarian `borrowing`-type example for future mechanics analysis.
