# Korean — Established Vocabulary/Grammar: *Easy to Learn Korean Language* (full book)

**Source:** Chad Meyer & Moonjung Kim, *Easy to Learn Korean Language* (in association with Korea
Times / "Easy to Learn Korean Language Skills"), picture-phrasebook format, 53pp. Covers all 50
printed topic pages (the book's own page headers run 1-50; its table-of-contents collapses some
multi-part topics — Numbers I/II, Transportation I-III, Asking Directions I-II, Shopping I-II,
Street Food I-III, Baseball I-III, Occupations I-II, ATM Machine I-III — into 36 named entries, so
header numbers and TOC numbers diverge after topic 8; this file follows the book's own page
headers, 1-50).

**Coverage note / non-redundant-supplement scoping:** This is a survival/practical picture-
phrasebook, not a grammar reference, so it overlaps only lightly with Korean's existing 50+
established files (001-053), which are overwhelmingly grammar textbooks, slang dictionaries
(030 Dirty Korean, 032 Making Out in Korean), and academic descriptions. Specifically:
- **Skipped as redundant:** detailed Numbers I/II table (1-10 Sino-Korean and Pure Korean sets,
  money units) — exhaustively covered already in 001-029's grammar textbooks. Detailed basic
  Greetings table and basic Colors table — likewise already covered extensively. Only the
  genuinely new grammar-adjacent observations from these pages (the leaving/staying goodbye
  distinction, the ordinal `-번째` pattern) are kept as grammar points below, not full vocab rows.
- **Kept in full:** everything else. This book's real value is concrete, practical, often
  culturally-specific vocabulary that grammar textbooks don't reach — bus color-coding, ATM/
  banking terminology, a full 11-rank corporate office hierarchy, butcher-shop cuts, street-food
  vendor culture, baseball fan-culture terms, shoe-repair vocabulary, recycling categories, a
  gendered in-law/kinship terms, and specific food-dish names with short cultural notes. None of
  this is duplicated in the existing 53 files to any meaningful degree.

**Text layer:** Confirmed zero text layer — `pdftotext -f 1 -l 5` returns ~3-4 bytes across the
whole book. **Not a font-substitution cipher case either**: `pdffonts` shows only one non-embedded
Latin font (Calibri, used for the title-page metadata) and `pdfimages -list` shows every page's
actual content is a raster JPEG (the book was produced with "pdfFactory Pro," a print-driver PDF
tool, and embeds each page as a flattened image, not as text/glyphs at all) — so there was no
Hangul-codepoint cipher to even attempt decoding; this source went straight to vision-reading.
All 53 pages were rendered at 150 DPI and read directly. No handwritten marginalia was present
anywhere in this copy — every page is clean original print (picture-phrasebook boxes, word banks,
and "TIP" callouts), so the vision-reading marginalia guard did not need to exclude anything.
**Vision Reading Confidence** is `verified` throughout this file — every Hangul/romanization pair
below was read directly from a full-resolution rendered page image, cross-checked against the
book's own printed romanization line (never inferred or reconstructed), and several multi-page
batches were independently re-read a second time during this extraction to confirm accuracy after
an early mid-session image-delivery hiccup.

## Grammar points

### Goodbye depends on who is staying vs. leaving

Korean doesn't have one generic "goodbye" — the choice of phrase depends on the speaker's own
status as the one leaving or the one staying, not on who the listener is. 안녕히 가세요
(annyeonghi gaseyo, roughly "go in peace") is said by the person who is staying, to the person
who is leaving. 안녕히 계세요 (annyeonghi gyeseyo, roughly "stay in peace") is said by the person
who is leaving, to the person(s) who remain. If all parties are leaving together, everyone uses
안녕히 가세요. (p.4) This is a genuinely useful grammar-adjacent distinction not framed this
explicitly in the prior established corpus's greeting sections, kept despite greetings generally
being skipped as redundant.

### Dual number system and the `-번째` ordinal suffix

The book states explicitly that Korean uses two parallel number systems — Sino-Korean (하나, 둘,
셋... derived from Chinese) and Pure Korean (일, 이, 삼... — the book's own labeling here is
reversed from the conventional pairing found elsewhere in the corpus, worth flagging as a
possible labeling inconsistency in the source itself rather than a new finding) — and that
*anything countable requires picking one set, not mixing them* (p.5-6). Separately, **ordinals**
are formed by suffixing `-번째` (-beonjjae) to the Pure Korean cardinal stem: 첫번째 "first,"
두번째 "second," 세번째 "third," 네번째 "fourth," 다섯번째 "fifth," continuing regularly through
열한번째 "eleventh." This regular, transparent ordinal-formation pattern is presented more
systematically here (11 full forms shown) than in several of the general grammar textbooks
already in the corpus, which tend to show only the first 3-5 ordinals before summarizing the
pattern.

### Singular-only pluralization

An explicit TIP box (p.17) states that Korean uses only the singular form of a noun to describe
one or more objects — no English-style `-s` pluralization is required. This is consistent with
what's already documented in the grammar-reference files, but the book's own plain-language
phrasing ("Korean uses only one form, the singular form, to describe one or more objects") is a
clean, source-citable restatement worth having on record from a second, independently-authored
source.

### Topic-pronoun optionality and the single-verb conflation of "sick"/"hurt"

On the Express Feelings page (p.22), the book's sentence patterns habitually drop the topic
pronoun 나는/저는 ("I") when the speaker is self-evident from context — consistent with Korean's
general pro-drop behavior already well documented elsewhere in the corpus. More specifically
useful: the single verb 아프다 (apeuda) is shown covering both "to be sick/ill" and "to hurt" (as
in physical pain at a location) — English splits these into two distinct predicates ("I'm sick"
vs. "my head hurts"), but Korean uses one verb for both senses, with the subject/location simply
determining which reading applies. This is a concrete example of a semantic domain where Korean
draws its category boundary differently than English — useful raw material for the mechanics-
analysis phase's cross-linguistic predicate-mapping work.

### Vocative name + `-아/야` for addressing someone younger

The Family page's TIP box (p.16) notes that older family members can address a younger relative
simply by appending the vowel-conditioned suffix `-아` (-a) to their given name — e.g., Moon-jung
becomes Moon-jung-a when addressed by a parent or older sibling. (The standard allomorphy —
`-아` after a consonant-final name, `-야` after a vowel-final name — isn't spelled out explicitly
in the source beyond this one example, so only the attested `-a` form is recorded here; the `-ya`
counterpart is a standard pattern already documented elsewhere in the corpus, not independently
confirmed by this source.)

### A "self-elevated" question-form pattern on the Describing Yourself page

The Describing Yourself page's phrase set (p.42) consistently uses the `-(으)세요?` polite-
honorific question ending — normally reserved for honoring the *addressee* — even for simple
self-descriptive adjective questions like asking someone to describe their own appearance,
rather than a plainer `-아/어요?` form. This reads as the book defaulting every phrase in the
section to its most broadly "safe"/polite register for a foreign learner, rather than illustrating
a deliberate self-elevation mechanism — flagged here as a pattern observed in the source's own
phrase choices, not a claim about a distinct grammatical construction.
