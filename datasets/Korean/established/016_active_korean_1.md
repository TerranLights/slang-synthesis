# Korean — Established Vocabulary/Grammar: Active Korean 1 (Full Book)

**Source:** Language Education Institute, Seoul National University, *Active Korean 1* (Moonjinmedia,
2006, 1st ed.), all 151 PDF pages (printed pp. 16-162+back matter): Unit 1 (Hangeul), Unit 2
(Greetings & Introductions), Unit 3 (Restaurant), Unit 4 (Shopping), Unit 5 (Daily Life), Unit 6
(Time), Unit 7 (Appointment), Unit 8 (Locations & Directions), Unit 9 (Phone Call), Grammar
Reference (printed pp. 142-156), Listening Transcript (p. 157), and Glossary (pp. 158-162).

**PDF-text-layer note:** this source has **no usable text layer at all** — `pdftotext` extracts
badly-garbled English-only OCR output (e.g. "Univei6ity," "d3velop") with **zero Hangul codepoints**
anywhere in the extracted stream (verified: 0 characters in the Hangul syllable/jamo Unicode ranges
across the full 3,372-line dump). This is not the `+36266`-offset font-substitution cipher confirmed
on 4 other Korean PDFs in this corpus (Basic Korean pt. 2, both Intermediate Korean halves, Using
Korean pt. 1) — there is no cipher to decode here, the Korean text was simply never captured by
whatever OCR process produced this PDF's text layer. **This entire book was vision-read** (rendered
to 151 PNG page images at 150 dpi via `pdftoppm`, read directly). No handwritten marginalia was
found anywhere in the sampled pages — all content read is clearly typeset/printed, consistent
throughout (this is a clean personal-copy scan, not a used/annotated library copy). Vision Reading
Confidence is marked `verified` for entries cross-checked against the book's own Glossary appendix
(which restates every item with its introducing unit number) and `plausible_unverified` for the
handful of entries read only once from a single page.

**Non-redundant-supplement dispatch note:** this is a beginner-level survival-Korean course
(Units 1-9 take a learner only through present/past tense, basic particles, demonstratives, numbers,
counters, location words, and phone-call language) — territory that **already-extracted
`established/001_basic_korean_part1.md`** (Byon, *Basic Korean*, Units 1-15) covers more
systematically and in greater depth. Every grammar point taught in this book — topic particle
은/는, copula -이에요/예요, object particle 을/를, subject particle 이/가, existential 있다/없다,
demonstratives 이거/그거/저거, both number systems (Sino-Korean 일이삼사... and native
하나둘셋넷...) with counters (개/병/잔), location particles 에/에서, position nouns
위/아래/앞/뒤/옆/안, past tense -았/었어요, and the polite-request ending -(으)세요 — is the same
territory `established/001` and `established/002` (*Basic Korean* Units 1-15) already extracted in
more systematic paradigm form, unit by unit, with fuller exception handling. **This file therefore
skips full re-extraction of that grammar** and instead: (1) captures this book's own vocabulary as a
single deduplicated set via its own Glossary appendix (which is more complete and reliable than
piecing vocabulary boxes together unit-by-unit, since it restates every item introduced anywhere in
the book), (2) notes only the handful of grammar/register points that are genuinely new relative to
`established/001` — mainly small pragmatics/register notes this book's dialogue-driven format
surfaces that a paradigm-first grammar like *Basic Korean* doesn't foreground the same way, and (3)
explicitly flags what was skipped as pure redundant drilling. No sibling `established/015` (a
prospective "Korean Through English 1" extraction) existed at the time of this dispatch — the
checklist's `established/` table runs only to `010` — so no cross-check against that book was
possible; this file was diffed only against `001`/`002` (*Basic Korean*).

**What was skipped as redundant:** the entire Hangeul unit's *pedagogical mechanism* (Unit 1, PDF pp.
7-32) — writing-order strokes, the batchim/vowel-combination drill grids, and the ~100 repeated
listen-and-write exercise items — since Hangeul's letter inventory and syllable-block structure are
already exhaustively covered in `established/001`'s own Hangul section. Also skipped: all
Conversation Drills, Tasks & Activities, and Listening sections across every unit (pure fill-in-the-
blank/pair-practice drilling reusing vocabulary already captured), the Listening Transcript appendix
(verbatim restatement of audio-exercise dialogues, no new vocabulary), and the book's own Grammar
Reference appendix (pp. 142-156) — its per-unit paradigm boxes (e.g. the full 1-100 Sino-Korean
number table, the 7-denomination 원 currency table, N위/아래/앞/뒤/옆/안 position-noun list) restate
grammar points already captured either here or in `established/001`/`002` at equal or greater depth,
with no dialect/register annotation anywhere in it. Back matter (Audio Tracking Information, ISBN/
copyright page, author-committee bios) has zero linguistic content and was not extracted.

### Grammar-pattern morpheme breakdowns (agglutinative attachment)

Per the typology guide, the handful of inflected/compositional forms actually encountered in this
book's dialogues (as opposed to the citation-form vocabulary above) get a breakdown here rather than
being treated as atomic:

> **안녕하세요?** = 안녕하- (peaceful/well, adjective stem) + -세요 (-(으)세요 polite-request/
> question ending, vowel-stem allomorph) — literally "are you well?," lexicalized as the general
> greeting "Hello."
>
> **만나서 반가워요.** = 만나- (meet, verb stem) + -서 (sequential connective, "having done X") +
> 반갑- → 반가우- (glad, irregular ㅂ-stem adjective) + -어요 (present casual-polite ending) —
> "having met, [I'm] glad," i.e. "Nice to meet you."
>
> **갔어요** = 가- (go, verb stem) + -았어요 (past-tense casual-polite ending, back-vowel-stem
> allomorph) — the Grammar Reference appendix's own worked example for the vowel-harmony-governed
> `-았어요/었어요` allomorphy (ㅏ/ㅗ stems take -았어요, all others -었어요, and -하다 verbs
> contract to -했어요, e.g. 공부하다 → 공부했어요).
>
> **한국 사람이에요?** = 한국 (Korea) + 사람 (person) + -이에요 (copula, consonant-stem allomorph
> of -이에요/예요) + rising question intonation (no word-order change) — "Are [you] a Korean
> person/Korean?"
>
> **시계가 있어요?** = 시계 (watch/clock) + -가 (subject particle, vowel-stem allomorph of 이/가) +
> 있- (exist/have, stem) + -어요 (present ending) — "Is there a watch? / Do you have a watch?"

## Grammar points (genuinely new relative to `established/001`/`002`)

### Honorific-tier distinction in third-person introductions: 여기는 vs. 이분은 (Unit 2)

When introducing a third person to someone else, the speaker's choice of introductory pronoun
tracks the referent's social rank relative to the *speaker* (not the addressee): **여기는** ("here
is...") is used for someone younger than or at the same level as the speaker, while **이분은**
("this person is...") is required when the person being introduced is older or higher in position
than the speaker. This is a lexical-choice honorific distinction layered directly onto an
introduction formula, distinct from (and narrower than) the six-speech-level system covered
exhaustively in `established/001`/`003`/`008` — it concerns which *demonstrative-plus-pronoun*
lexical item to reach for, not verb-ending selection. 이분 also appears standalone in the Glossary
as "this person (honorific)."

### Topic-marker omission when the referent is contextually obvious (Unit 2)

When it is already obvious to the listener what the topic under discussion is, Korean speakers
routinely omit the topic marker (은/는) and its host noun entirely rather than repeating it — the
book's own worked example is a reply consisting only of **(저는) 아니에요** ("[I'm] not"), with 저는
parenthesized as omittable. The book frames this as a default politeness-neutral discourse economy
(distinct from the deliberate omission-for-formality patterns `established/010` documents for
written/formal registers) but flags the reverse case too: when the topic needs to be made
unambiguous, it is *not* omitted, even in casual speech.

### 좀 as a politeness softener, stacking with 더 for "more" requests (Unit 3)

**좀** ("a bit / please") is explicitly framed by the source as a softening particle with no literal
semantic content of its own in a request like **물 좀 주세요** ("please give me [some] water") — it
makes an imperative-shaped request sound gentler and more polite without changing its meaning. When
asking for *more* of something already received, **더** ("more") is inserted directly in front of
주세요: 물 좀 더 주세요 ("please give me some more water"). This two-slot softening-plus-quantity
request template (좀 [+더] 주세요) is a compact, dialogue-native illustration of a politeness
mechanism that `established/008` (*Using Korean*) treats at a more systematic, cross-construction
level (its own chapter 6 softening-strategy grammar) — this book's version is narrower but gives the
literal worked phrase-template a beginner course would actually drill.

### 여기요 as a restaurant/service attention-getter (Unit 3)

**여기요** literally means "here" but is used idiomatically at a restaurant (or similar service
context) purely to get a waiter's or waitress's attention before making a request — functionally
equivalent to English "Excuse me!" in that context, not a literal locative statement. Distinct
lexical use from 여기 "here" (Unit 2 vocabulary) and from the honorific-tier 여기는 introduction
marker above.

### Hangeul batchim neutralization: the 7 representative syllable-final sounds (Unit 1)

Every Korean consonant, when it occurs as a syllable-final consonant (**batchim**, "supporting
floor"), is neutralized to one of only 7 representative sounds regardless of which of the 19
consonant letters is actually written — this is a genuine phonological rule, not just an alphabet-
teaching simplification, and is presented here more explicitly as a single consolidated table than
`established/001`'s own Hangul-mechanics section:

| Written batchim(s) | Pronounced as |
|---|---|
| ㄱ, ㅋ, ㄲ | [ㄱ] |
| ㄴ | [ㄴ] |
| ㄷ, ㅅ, ㅈ, ㅊ, ㅌ, ㅎ, ㅆ | [ㄷ] |
| ㄹ | [ㄹ] |
| ㅁ | [ㅁ] |
| ㅂ, ㅍ | [ㅂ] |
| ㅇ | [ŋ] (silent as an *initial* consonant, but a real nasal [ŋ] sound as a batchim) |

The source's own worked example: 박, 밖, 밬 (hypothetical spellings with ㄱ/ㄲ/ㅋ batchim
respectively) are all pronounced identically as [박] — the batchim consonant's own place/manner
distinctions collapse under this neutralization.

### Currency denominations and the price-asking pattern (Unit 4, Grammar Reference)

Korean currency (원, KRW) has 7 conventional denominations drilled together as a set: 10원, 50원,
100원, 500원, 1,000원, 5,000원, 10,000원 — read with the Sino-Korean number system (오십 원, 오백
원, 오천 원, 만 원, etc.), reusing the same 일/이/삼/사... numerals already core vocabulary from
Unit 4's shopping context. The price-asking exchange pattern **이 N은/는 얼마예요?** ("How much is
this N?") pairs with an answer stating the price as a bare Sino-Korean-numeral-plus-원 phrase (e.g.
삼만 오천 원이에요 "It's 35,000 won") — worth noting because it's the source's most concrete
worked illustration of the Sino-Korean number system scaling cleanly from single digits into the
ten-thousands (만) range via simple concatenation, which `established/001`/`002` treat more
abstractly as a paradigm rule without this specific priced-goods framing.

### Useful Korean service phone numbers (Unit 9, Additional Expressions)

The source lists six real-world Korean short-code service numbers as practical/cultural content:
**114** (telephone directory), **112** (police emergency), **119** (fire emergency), **131**
(weather information), **116** (current time), **1330** (tourist information). This is
contemporary-real-world cultural/practical content rather than grammar or core vocabulary, but is
flagged here since no other Wave-1/Wave-2 Korean source captured it and it is the kind of concrete
sociocultural detail (Korean phone-number readout conventions: 823-5760 is read digit-by-digit as
팔이삼의 오칠육공, with 0 read as 공) useful for grounding later slang/register analysis.
