# Language Corpus

Collected slang corpora, one folder per real-world language, gathered via web research.

**Start here:** [`00_Corpus_Collection_Index.md`](00_Corpus_Collection_Index.md) — tracks which
languages have collection started/complete and where each one's folder lives.

**Starting a new language:** copy [`_TEMPLATE/`](_TEMPLATE/) into a new `<Language>/` folder here,
then add a row to the index in the same commit.

**Using subtitles/transcripts as a source:** read
[`00_Source_Reliability_Guide.md`](00_Source_Reliability_Guide.md) first — AI-auto-generated
captions can be confidently wrong about slang specifically, and every entry sourced from one needs
a reliability flag.
