# Russian Slang Corpus — *Dermo!*'s Closing Alphabetical Glossaries

**Source:** Edward Topol, *Dermo! The Real Russian Tolstoi Never Used* (Russian Information
Services, 2011). Physically sits at `source_reference/languages/Russian/Russian Learning Pack
[up-to-date as of 2012]/Vol 1 of 3/100.Dermo! The Real Russian Tolstoi Never Used.pdf` (160 PDF
pages) but its content is a genuine slang/profanity phrasebook-dictionary, not grammar/vocabulary
reference — per this project's Hungarian-precedent routing rule (a dedicated slang dictionary goes
to `language_corpus/`, not `datasets/<Language>/established/`), extracted from where it physically
lives but written here instead.

**No text layer** — `pdftotext` returns nothing for this file; every page was rendered with
`pdftoppm` and read visually. Scanned as **one printed page per PDF-page image** (not a two-pages-
per-spread scan like some other vision-only sources in this project) — offset confirmed
empirically at multiple spot-checks across the whole book: **printed page = PDF page − 18** (e.g.
PDF page 20 = printed p. 2, PDF page 158 = printed p. 140). No handwritten marginalia found
anywhere in this book — all pages are clean print scans.

**This is research only — nothing here is canon** until worked into actual setting material by
explicit decision.

## Coverage of this file

This file covers the book's two closing glossary sections in full:

1. "An Additional Alphabetical Glossary of Real Russian, Which Is Far from Complete" — printed pp.
   124–138 (PDF pp. 142–156), organized by Cyrillic initial letter (А through Я).
2. "A Brief Glossary of Essential English Terms Accompanied by Russian Translations" — printed pp.
   139–140 (PDF pp. 157–158), organized alphabetically by English headword.

**Sampling decision: essentially exhaustive, not a representative sample.** Unlike this project's
usual "hundreds of entries, sample only" situation with large slang dictionaries (cf. Hungarian's
*Magyar Szlengszótár*), this source's own author already curated and thinned the list — the
section's own title flags it as "far from complete," i.e., already a selection rather than an
exhaustive corpus dump. Given that, and given its total size (~230 + ~30 entries, well within a
single file's scope), every entry from both sections was captured rather than sub-sampled further.
A handful of purely repetitive "go to hell" variant-phrase entries already covered by an earlier,
fuller example elsewhere in the same glossary were compressed into one row with variants noted
rather than duplicated — flagged per-row in Notes where this happened.

**Transliteration convention:** the source gives its own English transliteration in parentheses
after each Cyrillic headword; this is preserved in the Term column as `<cyrillic> (<translit>)`
matching the source's own romanization exactly (its system is a general phonetic one, not a
formal standard like BGN/PCGN — e.g. it writes `ь` as an apostrophe, does not distinguish я/йа
contexts specially, etc.).

## Register note

This entire book, and therefore this entire glossary, sits at the `taboo`/`slang` end of the
register spectrum by design — it is explicitly a book about swearing and vulgar/informal speech.
Usage Tier is assigned per-entry based on the term's actual semantic content and the source's own
framing (a handful of glossary entries are genuinely just neutral vocabulary the author included
for context, e.g. `гинеколог` "gynecologist," `аборт` "abortion" — these are tagged `core` or
`technical.medical`, not `taboo`, despite appearing inside a "profanity" glossary).

## Cross-cutting patterns worth flagging for Phase 3/mechanics analysis

- **Productive "go to X" dismissal template**: иди/пошел + в/на/к + [taboo or euphemized noun] generates
  a large open paradigm (жопа, хуй, пизда, ебаная мать, черт, леший, шуты, фиг) spanning the full
  register range from mild to maximally taboo, all from one syntactic frame.
- **Root-bleaching into pure intensifiers/discourse markers**: хуй, пизда, and ебать-family verbs each
  independently bleach from literal taboo/sexual meaning into general astonishment (охуеть,
  охуительно), idle-chat (попиздеть), or plain motion (попиздюхать) senses — the same mechanism
  recurring on multiple independent roots.
- **Euphemism-gradient triplets on a single concept**: e.g. хуёвина (taboo) / херовина (taboo-adjacent)
  / хреновина (euphemized) all mean "thingamajig" off effectively the same root, spanning a clean
  taboo→euphemized register ladder useful for a conlang's own register-substitution mechanics.
- **Reduplicated rhyming-doublet nonsense phrases**: фигли-мигли, штучки-дрючки, хуё-моё — a small
  productive word-formation pattern (echo-reduplication with a rhyming nonsense partner) used for
  "shenanigans/whatever" meanings, independent of register.
- **Small-animal-substitution mock-oath template**: ядрёна мать/вошь/мышь shows an open slot for a
  small creature noun softening an otherwise taboo мать-based oath through absurdist substitution.
